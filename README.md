# 안녕하세요! <!-- omit in toc -->

> [!IMPORTANT]
> 안녕하세요!
> **Altsis(Alternative School Information System)는** 모든 학교를 위한 대안적인 학교 정보 시스템입니다!

> [!TIP]
> <img width="100px" src="https://github.com/user-attachments/assets/5ca2ed76-8aca-400c-900e-97d065690102" align="center" alt="Altsis 로고" />
>
> - **Alt** : 대안적이고 수준높은 교육을 지향하는 **교육적인 시스템**
> - **Function Key** : 다양한 기능으로 커스텀 할 수 있는 **맞춤형 시스템**
> - **Keyboard** : 정보를 체계적으로 다룰 수 있는 **전문적인 시스템**

## 역사

> [!IMPORTANT]\
> 2016년 별무리 고등학교 맞춤형 교육 과정을 운영하기 위해 개발한 BLMS를 2022년 같은 학교 교사와 졸업생이 힘을 모아 다양한 학교의 정보를 체계적으로 설계하여 관리 할 수 있는 Altsis를 개발하였습니다. 지금은 AEG를 운영하여 대안적인 학교 관리 시스템이 필요한 많은 학교들에게 보급하기 위해 힘쓰고 있습니다!

> [!NOTE]
> - 2016 [별무리학교](http://bmrschool.net) 수강 신청을 위한 맞춤형 학습 관리 시스템 [BLMS](https://github.com/devgoodway/BLMS_OSV) 개발 [@devgoodway](https://github.com/devgoodway)
> - 2022 BLMS를 발전시킨 [ALTSIS](https://github.com/bmrdevteam/Altsis) 개발 [@devgoodway](https://github.com/devgoodway) [@jessie129j](https://github.com/jessie129j) [@seedlessapple](https://github.com/seedlessapple) and [@O-ye](https://github.com/Yeonwu)
> - 2023 [ALTSIS](https://github.com/bmrdevteam/Altsis) 오픈 소스 프로젝트 시작 [@devgoodway](https://github.com/devgoodway)
> - 2024 [AEG](./AEG_README.md) Altsis Educator Group 시작 [@devgoodway](https://github.com/devgoodway)

## 특징

> [!IMPORTANT]
> - 대안학교에서 만든 대안교육을 위한 **대안적인 학교 정보 시스템**
> - 다양한 학교와 교육과정에 적용 할 수 있는 **유연하고 독창적인 시스템**
> - 미래 지향적인 교육철학을 실현하는 **교육적인 시스템**

> [!NOTE]
> - :school: **아카데미 시스템** : 단 하나의 아카데미에서 복수의 학교 단위 교육 과정 운영 가능
> - :computer: **맞춤형 시스템** : 시스템 설정과 에디터 그리고 보드를 이용해 필요에 맞는 맞춤형 시스템 구성
> - :student: **학생 중심 시스템** : 학생이 수업 개설, 신청, 평가 및 다양한 학습 활동에 능동적으로 참여 할 수 있는 학생 중심 시스템
> - :motorway: **통합 시스템** : 학생의 수업, 평가, 기록, 출력, 학습 활동까지 하나의 시스템에서 관리
> - :electron:: **지능형 시스템** : 인공지능을 활용해 코칭, 생성, 검토 등 모든 시스템을 지원하는 지능형 시스템

# 어떻게 사용하나요?

> [!IMPORTANT]
> 시스템을 운영하기 위한 관리자 기능과 데이터를 활용하는 사용자 기능이 있습니다.

## 관리자

> [!IMPORTANT]
> :gear: 관리자 : ⚫ 시스템 관리자(owner), 🔴 아카데미 관리자(admin), 🔵 학교 관리자(manager)

> [!TIP]
> 아카데미·학교·사용자·학기·양식·권한 설정은 [관리자 가이드](./documentation/admin-guide/README.md)를 참고하세요.
> 기능별 사진·영상 안내는 관리자 가이드에 정리되어 있습니다.

## 사용자 (교사 · 학생)

> [!IMPORTANT]
> :smile: 사용자 : 학생(student), 교사(teacher)

> [!TIP]
> 강의계획서, 수강신청, 평가, 기록, 문서 조회와 일정·보드·채팅·알림은 [사용자 가이드](./documentation/user-guide/README.md)를 참고하세요.

# 시작하기

> [!IMPORTANT]
> 배포·실행 환경
>
> - :floppy_disk: **Server** : MongoDB, Redis, AWS EC2, AWS S3
> - :arrow_backward: **Backend** : Express REST API
> - :arrow_forward: **Frontend** : React

## 직접 설치하기 어려운 경우 (AEG)

> [!IMPORTANT]
> Altsis는 오픈 소스 프로젝트이기 때문에 사용자가 직접 서버에 설치하여 이용 할 수 있습니다. 하지만 직접 설치하기 어려운 경우 이미 서버를 이용하고 있는 관리자에게 요청하여 아카데미를 발급받아 이용 할 수도 있습니다.

> [!TIP]
> AEG(Altsis Educator Group)는 별무리학교에서 운영하는 Altsis 서버([https://altsis.org](https://altsis.org))를 임대하여 학교(또는 단체)에서 제공하는 역할을 합니다. 자세한 사항은 [AEG 안내](./AEG_README.md)를 확인하세요.

## 직접 설치 · 로컬 실행

> [!NOTE]
> **필요 환경:** Node.js 20 LTS, Yarn 3.x, MongoDB, Redis  
> **(선택)** AWS S3, Google OAuth Client ID

```bash
git clone https://github.com/bmrdevteam/Altsis.git
cd Altsis

# 백엔드
cd backend
yarn
# backend/.env 작성 후
yarn dev   # 또는 yarn local (.env.local)

# 프론트엔드 (다른 터미널)
cd frontend
yarn
# frontend/.env 작성 후
yarn start
```

> [!TIP]
> 환경 변수와 초기 `root` 아카데미·관리자 설정은 아래 문서를 따라 주세요.

> | [시스템 요구사항](./documentation/getting-started/requirements.md) | 소프트웨어·외부 서비스 |

# 기여하는 방법

> [!IMPORTANT]
> 이 프로젝트의 주요 목적은 Altsis의 주요 기능을 더욱 발전 시키고 많은 사람들이 더욱 쉽게 사용하도록 하기 위함입니다. Altsis는 Github를 통해서 개발하게 되는데 이는 오류를 수정하고 코드를 발전시키기 위해 좋은 도구가 됩니다. 반드시 아래 문서를 자세히 읽고 프로젝트에 동참해주세요.

> [!NOTE]
