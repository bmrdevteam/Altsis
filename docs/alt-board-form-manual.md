# Alt Board 양식 기능 매뉴얼

Alt Board의 **양식**은 설문·신청·퀴즈·결석계·승인 워크플로 등을 만들고, 응답을 **기록(시트)** 에 쌓은 뒤 **문서**로 출력하는 기능입니다.

> 대상: Alt Board 관리자·작성자(양식 생성) / 응답자(제출)  
> 위치: 보드 → 탭 **양식** / **기록** / **문서**

---

## 1. 전체 구조

```
양식(AltForm)  ──제출──►  기록/시트(AltSheetRow)  ──머지──►  문서(게시글)
     │                         │
     │ 필드·설정·퀴즈           │ 행 = 한 번의 응답
     └─────────────────────────┘
```

| 탭 | 역할 |
|----|------|
| **양식** | 양식 목록, 만들기/수정, 응답하기, 제출 현황, 링크 복사 |
| **기록** | 시트처럼 응답을 표로 보고 편집·필터·CSV·승인 |
| **문서** | 게시글 + `{{#sheet}}` / `{{#form}}` 으로 기록 출력·입력 |

양식을 저장하면 자동으로 연결된 **시트**가 생기고, 응답은 그 시트의 **행**으로 저장됩니다.

---

## 2. 시작하기

### 2.1 양식 만들기

1. Alt Board에서 **양식** 탭으로 이동합니다.
2. **새 양식**을 누릅니다.
3. **양식 제목**(필수), **양식 설명**(선택)을 입력합니다.
4. **양식 설정**을 펼쳐 기간·공개·퀴즈 등을 정합니다.
5. **+ 항목 추가**로 필드를 넣습니다.
6. **저장**을 누릅니다.

### 2.2 응답 받기

- 양식 목록에서 **응답하기** 또는 공유 링크로 엽니다.
- 시작일 전·마감일 후에는 제출할 수 없습니다(설정한 경우).
- 제출된 내용은 **기록** 탭에서 확인합니다.

### 2.3 역할

| 역할 | 할 수 있는 일 |
|------|----------------|
| 보드 admin / writer | 양식 생성·수정, 기록 관리, 문서 작성 |
| 양식 작성자 | 본인 양식 수정(보드·시스템 권한에 따름) |
| 응답자 | 양식 제출, (설정 시) 본인 응답 확인 |

## 3. 양식 설정

양식 편집 화면의 **양식 설정** 카드에서 설정합니다.

### 3.1 시작일 / 마감일

- 양식이 열리는 시각·닫히는 시각입니다.
- 비우면 제한 없이 열려 있습니다.
- 목록에서 상태가 **예정 / 진행 / 마감**으로 표시됩니다.

**예시:** 신청 기간을 `2026-03-01 09:00` ~ `2026-03-07 18:00`으로 두면, 그 밖에는 제출이 막힙니다.

### 3.2 재제출 허용

| 값 | 의미 |
|----|------|
| **비허용** | 한 번 제출하면 수정 불가(기본) |
| **허용** | 본인 응답을 다시 열어 수정 가능 |

> **복수 응답 허용**이 켜져 있으면 재제출은 자동으로 꺼지고 비활성화됩니다. (여러 행을 새로 쓰는 모드와 겹치지 않도록)

**예시:** 자기소개서 초안을 고치게 하려면 재제출 **허용**.

### 3.3 복수 응답 허용

| 값 | 의미 |
|----|------|
| **비허용** | 사용자당 응답 1건 |
| **허용** | 같은 사용자가 여러 번 제출 → 시트에 여러 행 |

**예시:** 매일 출석 체크, 매번 장비 대여 신청 → **허용**.

### 3.4 퀴즈 모드

켜면 필드에 **배점·정답**을 넣을 수 있고, 제출 후 점수를 계산합니다.

퀴즈 모드 ON 시 추가 설정:

| 항목 | 옵션 |
|------|------|
| **점수 공개** | 제출 즉시 / 마감 후 / 비공개 |
| **정답 공개** | 제출 즉시 / 마감 후 / 비공개 |

자동 채점이 되는 타입: **라디오, 드롭다운, 숫자** 등(채점 가능 타입).  
서술형은 **수동 채점**입니다.

**예시:** 생활교육 퀴즈 24문항 → 퀴즈 모드 ON, 점수·정답은 마감 후 공개.

### 3.5 직접 입력 모드

- ON이면 **응답 화면 제출**이 아니라, 관리자가 **기록(시트)** 에서 직접 행을 넣는 용도입니다.
- 안내 문구: *모든 필드가 관리자 입력으로 설정됩니다. Sheet에서 직접 데이터를 입력하세요.*

**예시:** 교사가 학생별 관찰 기록을 표에 직접 입력할 때.

### 3.6 본인 응답 확인

| 값 | 의미 |
|----|------|
| **허용**(기본) | 응답자가 본인 제출 내용을 다시 볼 수 있음 |
| **비허용** | 제출 후 본인 응답 숨김 |

### 3.7 응답 결과 공유

| 값 | 의미 |
|----|------|
| **비공개**(기본) | 다른 사람 응답은 관리자만 |
| **공개** | 응답자들도 (권한 범위 내) 결과를 볼 수 있음 |

**예시:** 익명 투표 집계를 학생에게 보여 주려면 **공개**.

### 3.8 관리자 필드 공개

관리자 전용 필드(`permission: owner`)를 응답자에게도 보여줄지 여부입니다.

| 값 | 의미 |
|----|------|
| **비공개**(기본) | 관리자만 승인·메모 등 확인 |
| **공개** | 응답자도 관리자 필드 값을 볼 수 있음 |

필드별로 **응답자에게 보이기**를 켠 경우와도 함께 동작합니다(시트/렌더러 권한 규칙).

## 4. 필드(항목) 종류

**+ 항목 추가**로 필드를 넣고, 카드를 클릭해 편집합니다.

### 4.1 공통 옵션

모든 필드에서 대체로 설정할 수 있는 항목:

| 옵션 | 설명 |
|------|------|
| **라벨** | 화면에 보이는 이름(문서 머지에서도 이 이름 사용) |
| **타입** | 아래 표 참고 |
| **필수** | 비우면 제출 불가 |
| **권한** | `응답자` = 제출자가 작성 / `관리자` = 시트·관리자만 작성 |
| **응답자에게 보이기** | 관리자 필드일 때, 제출자에게 표시 여부 |
| **조건부 표시** | 다른 필드 값에 따라 이 항목 보이기/숨기기 |
| **중복 검사** | 같은 값이 너무 많이 제출되지 않게 제한 |
| **퀴즈 배점·정답** | 퀴즈 모드일 때 |

### 4.2 타입 목록

#### 텍스트

| 타입 | UI 라벨 | 용도 |
|------|---------|------|
| `text` | 단답형 | 이름, 한 줄 답 |
| `textarea` | 장문형 | 사유, 소감 |
| `number` | 숫자 | 점수, 개수(퀴즈 정답 가능) |

#### 선택

| 타입 | UI 라벨 | 용도 |
|------|---------|------|
| `radio` | 라디오 | 하나만 선택(퀴즈에 적합) |
| `checkbox` | 체크박스 | 여러 개 선택 |
| `select` | 드롭다운 | 목록에서 하나 |
| `multiSelect` | 다중 선택 | 목록에서 여러 개 |

선택형은 **옵션 1, 옵션 2…** 를 직접 편집합니다.

#### 날짜/시간

| 타입 | UI 라벨 | 추가 설정 예 |
|------|---------|--------------|
| `date` | 날짜 | 최소/최대 날짜, 선택 가능 요일 |
| `multiDate` | 복수 날짜 | 여러 날 선택(예약·일정) |
| `time` | 시간 | 시각 |

날짜 필드에는 **며칠 전 몇 시부터 ~ 당일(또는 N일 전) 몇 시까지** 선택 가능 구간을 둘 수 있습니다.  
(예: 체험학습은 **3일 전 09:00까지**만 신청)

#### 특수

| 타입 | UI 라벨 | 용도 |
|------|---------|------|
| `content` | 문서 | 양식 안 안내·설명용 마크다운(메일머지 없음). 응답값·시트 컬럼에 저장되지 않음 |
| `docResponse` | 문서 응답 | 관리자가 만든 마크다운 템플릿을 응답자가 편집·제출. 필수 항목일 때만 템플릿 그대로 제출 불가(수정 필수). 응답값으로 시트에 저장됨 |
| `rating` | 별점 | 만족도(최대 별 1~10) |
| `scale` | 척도 | 리커트(최소~최대 값·라벨) |
| `counter` | 카운터 | 수량 증감 |
| `file` | 파일 | 첨부 |
| `userSelect` | 사용자 선택 | 학교 사용자 고르기 |
| `approval` | 승인 | 대기/승인/반려(관리자 처리) |
| `link` | 링크 | URL(+ OG 미리보기 지원) |

### 4.1 문서(마크다운) 색상·하이라이트

문서·문서 응답 등에서 쓰는 에디터는 **텍스트 색**과 **하이라이트**를 HTML 인라인 스타일로 저장합니다.

| 환경 | 색/하이라이트 |
|------|----------------|
| Altsis 앱 에디터·뷰어 | 유지됨 |
| GitHub 등 순수 마크다운 뷰어 | 빠질 수 있음 |

외부 도구로 반출·복사할 때는 색이 보이지 않을 수 있으니 참고하세요. 앱 안에서는 색 기능을 그대로 사용해도 됩니다.

## 5. 고급 필드 기능

### 5.1 조건부 표시

다른 필드 값에 따라 문항을 보여 줍니다.

| 설정 | 설명 |
|------|------|
| 논리 | **AND** / **OR** |
| 조건 | 대상 필드 + 연산자 + 값 |
| 연산자 | 같음, 다름, 포함, 비어있음, 비어있지 않음, (날짜) 이전/이후 |

시스템 변수: **현재 날짜 / 현재 시간 / 현재 요일**도 조건에 쓸 수 있습니다.

**예시:**  
- 「참석 여부」= `아니오` 일 때만 「불참 사유」(장문) 표시  
- 「요일」이 토·일일 때만 「주말 프로그램」필드 표시  

### 5.2 중복 검사

같은 필드 값이 허용 횟수를 넘지 못하게 합니다.

| 모드 | 의미 |
|------|------|
| `free` | 제출된 값 기준 카운트 |
| `preRegistration` | 사전 등록(허용 목록) 방식 |

**allowedCount:** 같은 값을 몇 번까지 허용할지(기본 1).

**예시:** 「좌석 번호」중복 검사 ON, allowedCount=1 → 같은 좌석 이중 신청 방지.

### 5.3 관리자 필드 + 승인

1. 필드 권한을 **관리자**로 둡니다.
2. 타입을 **승인**으로 두면 시트에서 승인/반려할 수 있습니다.
3. **관리자 필드 공개** 또는 필드별 **응답자에게 보이기**로 결과를 학생에게 보여줄 수 있습니다.

**예시:** 결석계 양식  
- 응답자: 날짜, 사유  
- 관리자: 승인(대기→승인/반려), 담당 교사 메모

## 6. 기록(시트) 탭

양식에 쌓인 응답을 표로 관리합니다.

### 6.1 주요 기능

| 기능 | 설명 |
|------|------|
| 표 / 문서 보기 | 행을 표 또는 문서형으로 표시 |
| 필터 | 응답자·필드값·날짜 범위 |
| 정렬 | 컬럼 헤더 정렬 |
| 셀 편집 | 권한 있는 필드만(관리자 필드 포함) |
| 행 추가 | 직접 입력·관리자용 빈 행 |
| CSV 다운로드 | 엑셀 호환(BOM) |
| CSV 업로드 | 일괄 가져오기 |
| 승인 처리 | 승인 필드에서 승인/반려 |
| 삭제 | 권한에 따라 행 삭제 |

### 6.2 퀴즈가 켜진 양식

시트/응답 화면에 점수·정오 표시가 나타날 수 있습니다(공개 설정에 따름).

### 6.3 사용 예시

1. **신청 마감 후** 기록 탭에서 학년으로 필터 → CSV로 명단 추출  
2. **승인** 컬럼에서 일괄 검토  
3. 문서 탭의 머지 게시글로 가정통신문 출력

## 7. 문서 탭과 메일머지

문서(게시글) 본문에 문법을 넣으면 **시트 데이터**가 채워집니다.  
게시글 작성 화면의 도움말에 문법이 정리되어 있습니다.

### 7.1 읽기 전용 머지 (`{{#sheet}}`)

시트 내용을 문서에 **출력**합니다.

```text
{{#sheet 체험학습 신청}}
{{#filter 학년 == "10학년"}}
{{#sort 이름 asc}}

총 {{_count}}건

{{#table _index, 이름, 날짜, 사유}}
```

| 문법 | 설명 |
|------|------|
| `{{#sheet 양식제목}}` | 사용할 양식(시트) 선언 |
| `{{필드이름}}` | 필드 값 |
| `{{필드\|date:YYYY.MM.DD}}` | 날짜 포맷 |
| `{{필드\|number:,}}` | 숫자 천 단위 |
| `{{_respondentName}}` 등 | 응답자·제출일·건수 |
| `{{#each}}` … `{{/each}}` | 행 반복 |
| `{{#table 열1, 열2}}` | 표 |
| `{{#filter …}}` / `{{#sort …}}` | 필터·정렬 |
| `{{#sum}}` `{{#avg}}` `{{#min}}` `{{#max}}` `{{#unique}}` | 집계 |
| `{{#if …}}` … `{{#else}}` … `{{/if}}` | 조건부 문장 |
| `{{#group 필드}}` … `{{/group}}` | 그룹핑 |

### 7.2 입력 문서 (`{{#form}}`)

문서 안에서 바로 입력받아 **시트에 한 행을 제출**합니다.

```text
{{#form 결석계}}
본인 {{#input 이름}} 은(는) {{#input 날짜}} 에
{{#input 사유}} 의 사유로 결석합니다.
```

- `{{#form 양식이름}}` 은 `{{#sheet}}` 대신 사용합니다.
- 관리자는 “전체 응답 보기”로 전환할 수 있습니다.

### 7.3 문서 사용 팁

- 머지 변수는 **양식 필드 라벨**과 같아야 합니다.
- 게시글 작성 도움말에서 양식·필드 이름을 **클릭해 복사**할 수 있습니다.
- 문서 탭 블로그 보기에서는 `{{#sheet` 가 있는 글에 merge를 적용해 보여 줍니다.

## 8. 양식 목록의 부가 기능

양식 카드/메뉴에서 할 수 있는 일(권한에 따라):

| 기능 | 설명 |
|------|------|
| 응답하기 | 제출 화면 열기 |
| 수정 | 빌더로 편집 |
| 링크 복사 | 응답 URL 공유 |
| 제출 현황 | 제출/미제출자, 미제출 알림 |
| JSON보내기/가져오기 | 양식 정의 백업·복제 |
| 조합 생성기 | (지원 시) 선택지 조합 관련 도구 |

상태 뱃지: **예정 / 진행 / 마감**, **퀴즈** 표시 등.

## 9. 시나리오별 설정 예시

### 예시 A. 체험학습 신청

| 설정 | 값 |
|------|-----|
| 시작·마감 | 신청 기간 |
| 재제출 | 허용(마감 전 수정) |
| 복수 응답 | 비허용 |
| 필드 | 이름(단답), 희망일(날짜), 장소(단답), 보호자 연락처(단답) |
| 관리자 필드 | 승인 |
| 문서 | `{{#sheet 체험학습 신청}}` + 표로 명단 출력 |

### 예시 B. 생활교육 퀴즈

| 설정 | 값 |
|------|-----|
| 퀴즈 모드 | 사용 |
| 점수/정답 공개 | 마감 후 |
| 복수 응답 | 비허용 |
| 필드 | 문항마다 라디오 + 정답·배점 |
| 확인 | 본인 응답 확인 허용 → 마감 후 점수 확인 |

### 예시 C. 장비 대여(좌석/물품 1개만)

| 설정 | 값 |
|------|-----|
| 복수 응답 | 상황에 따라 |
| 필드 | 물품명(드롭다운) + **중복 검사** allowedCount=1 |
| 기록 | CSV로 대여 현황 관리 |

### 예시 D. 교사가 직접 넣는 관찰 기록

| 설정 | 값 |
|------|-----|
| 직접 입력 모드 | 사용 |
| 필드 | 학생(사용자 선택), 날짜, 관찰 내용(장문) |
| 사용처 | 기록 탭에서만 입력, 문서로 학기말 출력 |

### 예시 E. 문서에서 쓰는 결석계

1. 양식 `결석계` 생성(이름·날짜·사유).  
2. 문서 게시글:

```text
{{#form 결석계}}
본인 {{#input 이름}} 은(는) {{#input 날짜}} 에
{{#input 사유}} 의 사유로 결석하고자 합니다.
```

3. 학생이 문서에서 제출 → 기록에 행 생성 → 교사가 승인 필드 처리.

## 10. 자주 하는 질문

**Q. 양식과 학교「관리 > 양식(출력 양식)」의 차이는?**  
A. 이 매뉴얼의 양식은 **Alt Board 양식**(설문·기록·문서 머지)입니다.  
학교 **출력 양식 에디터**(생활기록부 레이아웃, `데이터 연결`)는 별도 기능입니다.

**Q. 필드 이름을 바꾸면 문서가 깨지나요?**  
A. 머지는 **필드 라벨**을 씁니다. 라벨을 바꾸면 `{{예전이름}}` 문서를 함께 수정해야 합니다.

**Q. 퀴즈 UI를 HTML로 예쁘게 만들었는데?**  
A. 네이티브 퀴즈 모드가 기록·채점과 바로 연결됩니다. 커스텀 HTML 앱은 별도 API 연동이 필요합니다.

**Q. 응답이 안 보여요.**  
A. 시작/마감, 본인 응답 확인, 응답 결과 공유, 관리자 필드 공개, 필드 권한을 확인하세요.

**Q. 양식 필드를 삭제했더니 예전 답이 안 보여요.**  
A. 응답은 필드 ID에 묶여 시트에 남습니다. 필드를 삭제하면 양식 UI에는 안 보일 수 있고, 본인 응답 화면에는 **이전 응답**으로 표시됩니다. 삭제 전 빌더에서 확인 경고가 뜹니다.
