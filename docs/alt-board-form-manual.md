# Alt Board 양식 기능 매뉴얼

Alt Board의 **양식**은 설문·신청·퀴즈·결석계·승인 워크플로 등을 만들고, 응답을 **기록(시트)** 에 쌓은 뒤 **문서**로 출력하는 기능입니다.

> 대상: Alt Board 관리자·작성자(양식 생성) / 응답자(제출)  
> 위치: 보드 → 탭 **활동** / **기록** / **문서** / **채팅**(옵션)

---

## 1. 전체 구조

```
양식(AltForm)  ──제출──►  기록/시트(AltSheetRow)  ──머지──►  문서(게시글)
     │                         │
     │ 필드·설정·퀴즈           │ 행 = 한 번의 응답
     └─────────────────────────┘
```

| 탭 | 역할 |
|----|------|
| **활동** | 양식·승인 등 할 일 (뱃지: 미제출+승인해야 함+승인 진행). 기본 진입 탭 |
| **기록** | 시트처럼 응답을 표로 보고 편집·필터·CSV·승인 |
| **문서** | 게시글 목록·블로그 + `{{#sheet}}` 머지 (뱃지: 안 읽은 공개 글) |
| **채팅** | 보드 채팅 (활성화 시, 뱃지: 안 읽은 메시지) |

### 보드 목록 페이지 (`/boards`)

사이드바에서 보드로 들어오면 **할 일 / 보드** 두 탭이 있습니다. 사이드바 「보드」에도 할 일 수가 뱃지로 표시됩니다.

| 탭 | 역할 |
|----|------|
| **할 일** | 가입한 **모든 Alt Board**의 할 일만 모아서 표시 (승인해야 함 · 승인 진행 · 미제출). 카드에 보드명이 함께 보입니다. 클릭 시 해당 보드로 이동합니다. |
| **보드** | 가입한 보드 리스트(기존 목록·갤러리·즐겨찾기) |

**기본 탭:** 할 일이 있으면 **할 일**, 없으면 **보드**. URL 해시(`#할 일` / `#보드`)가 있으면 해시를 따릅니다. 예전 `#활동` 해시는 `#할 일`로 호환됩니다. 할 일이 비어 있을 때는 「할 일이 없습니다」와 **보드 목록 보기** 버튼이 나옵니다.

### 보드 범위 (학교 / 시즌)

보드 생성 시 **범위를 선택**합니다. 생성 후에는 변경할 수 없습니다.

| 범위 | 동작 |
|------|------|
| **학교 전체** | 해당 학교의 모든 시즌에서 목록에 보입니다. (기존 보드·기본 공지사항과 동일) |
| **이번 시즌만** | **현재 시즌**일 때만 목록·할 일에 보입니다. 시즌을 바꾸면 이전 시즌 보드는 숨겨집니다. |

**시즌 보드 멤버십 (규칙 B)**

- 해당 시즌에 **활성화된 등록(Registration)** 이 있는 사용자만 초대·접근할 수 있습니다.
- 개별 초대·역할(`altBoardRole`)이 있어도 시즌 미등록이면 접근할 수 없습니다.
- 예외: 시스템 admin, 학교 manager, 보드 생성자(creator)는 운영을 위해 Registration 없이도 접근·관리할 수 있습니다.

**시즌 없이 학교 보드 이용 (규칙 A)**

쿼터(시즌)를 만들지 않고 보드 중심으로 학교를 쓸 수 있습니다.

- 아카데미 관리자가 사용자를 **학교에 배정**(`User.schools`)하면 됩니다.
- **학교 전체** 보드에서 멤버 그룹에 교사 또는 학생이 켜져 있으면, 시즌 등록이 없어도 학교 소속자는 보드에 접근할 수 있습니다.
- 시즌 등록이 없으면 사이드바의 **수업·기록·문서**와 우측 상단 **쿼터 선택**은 숨겨지고, **일정·보드**는 그대로 보입니다.
- **시즌 보드**는 여전히 해당 시즌 등록이 필요합니다.

양식을 저장하면 자동으로 연결된 **시트**가 생기고, 응답은 그 시트의 **행**으로 저장됩니다.

## 2. 시작하기

### 2.1 양식 만들기

1. Alt Board에서 **활동** 탭으로 이동합니다.
2. **새 양식**을 누릅니다.
3. **양식 제목**(필수), **양식 설명**(선택)을 입력합니다.
4. **양식 설정**을 펼쳐 기간·공개·퀴즈 등을 정합니다.
5. **+ 항목 추가**로 필드를 넣습니다.
6. **저장**으로 비공개 상태로 두고, **공개**로 활동 목록에 올립니다. 비공개는 **작성자만** 보이며, **비공개**로 다시 숨길 수 있습니다. **삭제는 비공개 상태에서만** 가능합니다.
7. 시작일·마감일은 공개 후에도 “응답 가능 기간”으로 동작합니다(예정/마감 뱃지).

### 2.2 응답 받기

- 활동 목록에서 **작성** 아이콘(또는 행 클릭)이나 공유 링크로 엽니다.
- **비공개** 양식에는 응답할 수 없습니다. 공개 후, 시작일 전·마감일 후에도 제출할 수 없습니다(설정한 경우).
- 제출된 내용은 **기록** 탭 또는 활동 행의 **기록** 아이콘으로 확인합니다.

### 2.3 역할

| 역할 | 할 수 있는 일 |
|------|----------------|
| 보드 admin / writer | 양식 생성·수정, 기록 관리, 문서 작성 |
| 양식 작성자 | 본인 양식 수정(보드·시스템 권한에 따름) |
| 응답자 | 양식 제출, (설정 시) 본인 응답 확인 |

## 3. 양식 설정

양식 편집 화면의 **양식 설정** 카드에서 설정합니다.

### 3.1 시작일 / 마감일

- 양식이 열리는 시각·닫히는 시각입니다.
- 비우면 제한 없이 열려 있습니다.
- 목록에서 상태가 **예정 / 진행 / 마감**으로 표시됩니다.

**예시:** 신청 기간을 `2026-03-01 09:00` ~ `2026-03-07 18:00`으로 두면, 그 밖에는 제출이 막힙니다.

### 3.2 재제출 허용

| 값 | 의미 |
|----|------|
| **비허용** | 한 번 제출하면 수정 불가(기본) |
| **허용** | 본인 응답을 다시 열어 수정 가능 |

> **복수 응답 허용**이 켜져 있으면 재제출은 자동으로 꺼지고 비활성화됩니다. (여러 행을 새로 쓰는 모드와 겹치지 않도록)

**예시:** 자기소개서 초안을 고치게 하려면 재제출 **허용**.

### 3.3 복수 응답 허용

| 값 | 의미 |
|----|------|
| **비허용** | 사용자당 응답 1건 |
| **허용** | 같은 사용자가 여러 번 제출 → 시트에 여러 행 |

**선택**(비필수) + 복수 허용이면 횟수 제한 없이 추가 제출할 수 있습니다.

### 3.3.1 필수 모드

| 값 | 의미 |
|----|------|
| **필수** | 미제출 뱃지·활동 탭 카운트에 포함 — 사용자에게 제출을 요구 |
| **선택**(기본·기존 양식) | 미제출로 표시하지 않음. `requiredMode` 필드가 없는 양식도 선택으로 취급 |

**필수 + 복수 응답**이면 **목표 제출 횟수**를 지정합니다.

| 동작 | 설명 |
|------|------|
| 진행 표시 | 목록·응답 화면에 `n/N` (예: 1/3) |
| 제출완료 | 내 제출 수 ≥ 목표 횟수일 때 |
| 추가 제출 | 목표에 도달하면 더 이상 제출할 수 없음 |

**예시:** 강의실 신청을 3회까지 받으려면 → 복수 허용 + 필수 모드 + 목표 제출 횟수 **3**.

### 3.4 퀴즈 모드

켜면 필드에 **배점·정답**을 넣을 수 있고, 제출 후 점수를 계산합니다.

퀴즈 모드 ON 시 추가 설정:

| 항목 | 옵션 |
|------|------|
| **점수 공개** | 제출 즉시 / 마감 후 / 비공개 |
| **정답 공개** | 제출 즉시 / 마감 후 / 비공개 |

자동 채점이 되는 타입: **라디오, 드롭다운, 숫자** 등(채점 가능 타입).  
서술형은 **수동 채점**입니다.

**예시:** 생활교육 퀴즈 24문항 → 퀴즈 모드 ON, 점수·정답은 마감 후 공개.

### 3.5 직접 입력 모드

- ON이면 **응답 화면 제출**이 아니라, 관리자가 **기록(시트)** 에서 직접 행을 넣는 용도입니다.
- 안내 문구: *모든 필드가 관리자 입력으로 설정됩니다. Sheet에서 직접 데이터를 입력하세요.*

**예시:** 교사가 학생별 관찰 기록을 표에 직접 입력할 때.

### 3.6 본인 응답 확인

| 값 | 의미 |
|----|------|
| **허용**(기본) | 응답자가 본인 제출 내용을 다시 볼 수 있음 |
| **비허용** | 제출 후 본인 응답 숨김 |

허용일 때 활동 「할 일」의 제출완료 카드에서 **내 응답**으로 들어가, 작성했던 양식 모양으로 제출 내용을 볼 수 있습니다. 복수 응답이 켜져 있으면 `< 1 / N >`으로 건별로 넘깁니다(개별 보기). 응답 화면 상단의 **작성 / 내 응답**으로도 전환할 수 있습니다.

### 3.7 응답 결과 공유

| 값 | 의미 |
|----|------|
| **비공개**(기본) | 다른 사람 응답은 관리자만 |
| **공개** | 응답자들도 (권한 범위 내) 결과를 볼 수 있음 |

**예시:** 익명 투표 집계를 학생에게 보여 주려면 **공개**.

### 3.8 관리자 필드 공개

관리자 전용 필드(`permission: owner`)를 응답자에게도 보여줄지 여부입니다.

| 값 | 의미 |
|----|------|
| **비공개**(기본) | 관리자만 승인·메모 등 확인 |
| **공개** | 응답자도 관리자 필드 값을 볼 수 있음 |

필드별로 **응답자에게 보이기**를 켠 경우와도 함께 동작합니다(시트/렌더러 권한 규칙).

## 4. 필드(항목) 종류

**+ 항목 추가**로 필드를 넣고, 카드를 클릭해 편집합니다.

### 4.1 공통 옵션

모든 필드에서 대체로 설정할 수 있는 항목:

| 옵션 | 설명 |
|------|------|
| **라벨** | 화면에 보이는 이름(문서 머지에서도 이 이름 사용) |
| **타입** | 아래 표 참고 |
| **필수** | 비우면 제출 불가 |
| **권한** | `응답자` = 제출자가 작성 / `관리자` = 시트·관리자만 작성 |
| **응답자에게 보이기** | 관리자 필드일 때, 제출자에게 표시 여부 |
| **조건부 표시** | 다른 필드 값에 따라 이 항목 보이기/숨기기 |
| **중복 검사** | 같은 값이 너무 많이 제출되지 않게 제한 |
| **퀴즈 배점·정답** | 퀴즈 모드일 때 |

### 4.2 타입 목록

#### 텍스트

| 타입 | UI 라벨 | 용도 |
|------|---------|------|
| `text` | 단답형 | 이름, 한 줄 답 |
| `textarea` | 장문형 | 사유, 소감 |
| `number` | 숫자 | 점수, 개수(퀴즈 정답 가능) |

#### 선택

| 타입 | UI 라벨 | 용도 |
|------|---------|------|
| `radio` | 라디오 | 하나만 선택(퀴즈에 적합) |
| `checkbox` | 체크박스 | 여러 개 선택 |
| `select` | 드롭다운 | 목록에서 하나 |
| `multiSelect` | 다중 선택 | 목록에서 여러 개 |

선택형은 **옵션 1, 옵션 2…** 를 직접 편집합니다.

#### 날짜/시간

| 타입 | UI 라벨 | 추가 설정 예 |
|------|---------|--------------|
| `date` | 날짜 | 최소/최대 날짜, 선택 가능 요일 |
| `multiDate` | 복수 날짜 | 여러 날 선택(예약·일정) |
| `time` | 시간 | 시각 |

날짜 필드에는 **며칠 전 몇 시부터 ~ 당일(또는 N일 전) 몇 시까지** 선택 가능 구간을 둘 수 있습니다.  
(예: 체험학습은 **3일 전 09:00까지**만 신청)

#### 특수

| 타입 | UI 라벨 | 용도 |
|------|---------|------|
| `content` | 문서 | 양식 안 안내·설명용 마크다운(메일머지 없음). 응답값·시트 컬럼에 저장되지 않음 |
| `docResponse` | 문서 응답 | 관리자가 만든 마크다운 템플릿을 응답자가 편집·제출. 필수 항목일 때만 템플릿 그대로 제출 불가(수정 필수). 응답값으로 시트에 저장됨 |
| `rating` | 별점 | 만족도(최대 별 1~10) |
| `scale` | 척도 | 리커트(최소~최대 값·라벨) |
| `counter` | 카운터 | 수량 증감 |
| `file` | 파일 | 첨부 |
| `userSelect` | 사용자 선택 | 학교 사용자 고르기 |
| `approval` | 승인 | 결재선(지정/고정 혼합)·대기/승인/반려 |
| `link` | 링크 | URL(+ OG 미리보기 지원) |

### 4.1 문서(마크다운) 색상·하이라이트·제목·콜아웃

문서·문서 응답 등에서 쓰는 에디터는 **텍스트 색**, **하이라이트**를 HTML 인라인 스타일로 저장합니다. 글자 크기는 마크다운 **제목(h1~h6)** 으로 조절합니다.

| 환경 | 색/하이라이트 | 제목(h1~h6) | 콜아웃 |
|------|---------------|-------------|--------|
| Altsis 앱 에디터·뷰어 | 유지됨 | 유지됨 | 유지됨 |
| GitHub 등 순수 마크다운 뷰어 | 빠질 수 있음 | 유지됨 | GitHub Alerts로 표시될 수 있음 |

툴바 제목 메뉴 또는 `/` 슬래시 명령으로 **본문 / 제목 1~6**을 선택할 수 있습니다.

툴바 **더보기(⋯) → 마크다운 단축 문법**에서 `**`, `#`, `-`, `/` 등 **타이핑만으로 되는 마크다운 단축 문법**을 확인할 수 있습니다.

**콜아웃(알림 박스)** 은 아래 마크다운 문법으로 작성합니다. (에디터 전용 버튼 없음 — 조회 시 박스로 표시)

```markdown
> [!NOTE]
> 참고 안내

> [!TIP]
> 팁

> [!IMPORTANT]
> 중요

> [!WARNING]
> 경고

> [!CAUTION]
> 주의
```

표에서는 행·열 추가·삭제, **헤더 행 토글**, 셀 **배경색**, 셀 **가로·세로 정렬**을 사용할 수 있습니다.

외부 도구로 반출·복사할 때는 인라인 서식(색·하이라이트)이 보이지 않을 수 있으니 참고하세요. 앱 안에서는 그대로 사용해도 됩니다.

## 5. 고급 필드 기능

### 5.1 조건부 표시

다른 필드 값에 따라 문항을 보여 줍니다.

| 설정 | 설명 |
|------|------|
| 논리 | **AND** / **OR** |
| 조건 | 대상 필드 + 연산자 + 값 |
| 연산자 | 같음, 다름, 포함, 비어있음, 비어있지 않음, (날짜) 이전/이후 |

시스템 변수: **현재 날짜 / 현재 시간 / 현재 요일**도 조건에 쓸 수 있습니다.

**예시:**  
- 「참석 여부」= `아니오` 일 때만 「불참 사유」(장문) 표시  
- 「요일」이 토·일일 때만 「주말 프로그램」필드 표시  

### 5.2 중복 검사

같은 필드 값이 허용 횟수를 넘지 못하게 합니다.

| 모드 | 의미 |
|------|------|
| `free` | 제출된 값 기준 카운트 |
| `preRegistration` | 사전 등록(허용 목록) 방식 |

**allowedCount:** 같은 값을 몇 번까지 허용할지(기본 1).

**예시:** 「좌석 번호」중복 검사 ON, allowedCount=1 → 같은 좌석 이중 신청 방지.

### 5.3 관리자 필드 + 승인(결재선)

1. 필드 권한을 **관리자**로 두거나, 응답자 권한으로 두고 **승인** 타입을 씁니다.
2. 타입을 **승인**으로 두면 **결재선**을 구성할 수 있습니다. 결재선은 **양식에 저장**되며 복제·JSON 가져오기 시 함께 이동합니다.
3. 각 단계는 **지정(제출 시 선택)** 또는 **고정(미리 지정)** 이며 혼합할 수 있습니다. 순차 승인되며 반려 시 종료됩니다.
4. **활동** 탭 **할 일**에서 확인할 수 있습니다.
   - **승인해야 함**: 내가 처리할 요청 → 승인/반려
   - **승인 진행**: 내가 제출해 두고 기다리는 건 → 결재선 진행 확인(읽기 전용)
   - **기록** 시트에서도 승인 처리 가능합니다.
5. **관리자 필드 공개** 또는 필드별 **응답자에게 보이기**로 결과를 학생에게 보여줄 수 있습니다.
6. 보드 알림 설정:
   - **승인 요청**: 제출·다음 단계 시 현재 승인자에게
   - **승인 결과**: 단계 승인·최종 승인/반려 시 제출자에게

**예시:** 결석계 양식  
- 응답자: 날짜, 사유 + 1차 담당교사(지정)  
- 결재: 2차 교감(고정)  
- 활동 「할 일」에서 차례인 사람이 처리하고, 제출자는 「승인 진행」으로 상태를 확인

## 7. 문서 탭과 메일머지

문서 탭 기본 목록은 **테이블(카드형)** 입니다. 보드 관리(또는 학교 관리 → 보드 → 관리)에서 **문서 목록 보기**를 테이블/블로그로 바꿀 수 있습니다. 카드를 누르면 게시글을 열고, 작성 권한이 있으면 수정·.md 다운로드·복제 아이콘을 씁니다. 상단 **+** 옆 **업로드**로 `.md`/`.txt` 파일을 가져오면 글 작성 화면에 제목·내용이 채워집니다. 작성 화면에서는 **저장**(비공개, 작성자만)·**공개**(멤버 공개·알림)·**비공개**(다시 숨김)를 쓰고, **삭제는 비공개 문서만** 가능합니다. 표에서 여러 글을 체크해 일괄 작업하던 방식은 없습니다.

문서(게시글) 본문에 문법을 넣으면 **시트 데이터**가 채워집니다.  
게시글 작성 화면의 도움말에 문법이 정리되어 있습니다.

### 7.1 읽기 전용 머지 (`{{#sheet}}`)

시트 내용을 문서에 **출력**합니다.

```text
{{#sheet 체험학습 신청}}
{{#filter 학년 == "10학년"}}
{{#sort 이름 asc}}

총 {{_count}}건

{{#table _index, 이름, 날짜, 사유}}
```

| 문법 | 설명 |
|------|------|
| `{{#sheet 양식제목}}` | 사용할 양식(시트) 선언 |
| `{{필드이름}}` | 필드 값 |
| `{{필드\|date:YYYY.MM.DD}}` | 날짜 포맷 |
| `{{필드\|number:,}}` | 숫자 천 단위 |
| `{{_respondentName}}` 등 | 응답자·제출일·건수 |
| `{{#each}}` … `{{/each}}` | 행 반복 |
| `{{#table 열1, 열2}}` | 표 |
| `{{#filter …}}` / `{{#sort …}}` | 필터·정렬 |
| `{{#timetable date=… period=…}}` … `{{/timetable}}` | 주간 시간표 격자 (아래 7.2) |

**누가 어떤 행을 보나요?** 기록(시트)과 같습니다.

| 역할·설정 | 머지에 포함되는 행 |
|-----------|-------------------|
| 보드 admin / writer | 전체 행 (CSV·직접입력으로 응답자 없는 행 포함) |
| 응답자 + 양식 **응답 공유(shareResponses)** ON | 전체 행 |
| 그 외 응답자 | **본인** 제출 행만 (+ 승인자로 지정된 행) |

응답자(`_respondent`)가 비어 있는 행(CSV 업로드·교사 직접 입력 등)은, 위 표에서 **전체 행**을 볼 수 있는 경우에만 머지에 포함됩니다. 본인만 보는 모드에서는 `_respondent`가 본인인 행만 나가므로 응답자 없는 행은 나오지 않습니다. 칸에 `{{_respondentName}}`을 쓰면 그런 행은 이름이 비어 보일 수 있으니, 이름 필드(`{{이름}}` 등)를 쓰는 편이 안전합니다.

지원하지 않는 문법(`{{#form}}`/`{{#input}}`, `{{#if}}`, `{{#group}}`, `{{#sum}}`/`avg`/`min`/`max`/`unique`)은 렌더 시 **자동 제거**됩니다.  
대량 행·긴 출력에는 서버 상한이 있어 일부만 표시될 수 있습니다.

### 7.2 주간 시간표 (`{{#timetable}}`)

날짜·교시 필드가 있는 신청/예약 시트를 **요일 × 교시** 격자로 출력합니다.  
**칸에 무엇을 넣을지는 템플릿 본문**에서 `{{필드}}`로 직접 정합니다. (제품이 강의실·이름 등을 고정하지 않습니다.)

```text
{{#sheet 강의실 신청 프로그램}}

{{#timetable date=날짜 period=시간표}}
{{강의실}}
{{이름}}
{{/timetable}}
```

| 속성 | 필수 | 설명 |
|------|------|------|
| `date=` | O | 날짜 필드 라벨 (`date` 또는 `multiDate`) |
| `period=` | O | 교시/타임슬롯 필드 라벨 (`select`/`radio`/`multiSelect`/`time` 등) |
| `week=` | X | `YYYY-MM-DD`(그 주 월요일 권장). 없으면 **데이터가 있는 모든 주**를 순서대로 출력 |
| `days=` | X | 요일만 표시. 예: `days=월,화,수,목,금` |

동작 요약:

- `multiDate`는 **날짜마다** 칸에 펼칩니다.
- `multiSelect` 교시는 **선택한 교시마다** 펼칩니다.
- 한 칸에 여러 건이 있으면 본문을 여러 번 이어 붙입니다.
- 컴퓨터 신청처럼 칸 내용만 바꾸면 됩니다: `{{컴퓨터}}` / `{{_respondentName}}` 등.

### 7.3 문서 사용 팁

- 머지 변수는 **양식 필드 라벨**과 같아야 합니다.
- 게시글 작성 화면에서 양식·필드 이름을 **클릭해 복사**할 수 있습니다.
- 문법 설명은 이 매뉴얼을 참고하세요.
- 문서 탭 블로그 보기에서는 `{{#sheet` 가 있는 글에 merge를 적용해 보여 줍니다.

## 8. 양식 목록의 부가 기능

활동 탭은 **하나의 활동 목록**입니다. 같은 양식이 「할 일」「양식」으로 중복 표시되지 않으며, 행 오른쪽 아이콘으로 기능에 바로 들어갑니다.

| 아이콘 | 동작 | 보이는 조건 |
|--------|------|-------------|
| 작성 | 응답(제출) 화면 | 직접입력이 아닌 양식 |
| 내 응답 | 내가 제출한 내용 보기 | 제출 후·설정 허용 시 |
| 양식 | 양식 빌더(편집) | 수정 권한자 |
| 기록 | 해당 양식의 기록(시트) | 보드 멤버 (기록 탭과 동일) |
| 더보기(⋮) | 링크 복사·JSON·복제·조합 생성·삭제 | 관리 권한자 |

목록 상단에 **미제출·제출완료·예정·마감**(및 관리자용 총 응답) 요약이 표시됩니다. 보드 전원 대비 미제출 인원은 목록이 아니라 제출 현황에서 봅니다.

행을 클릭하면 기본으로 **작성**(직접입력 양식은 **기록**)으로 이동합니다. **기록 탭**도 그대로 두어 전체 시트를 한곳에서 볼 수 있습니다.

상태 뱃지: **미제출 / n/N(필수+복수) / 제출완료 / 예정 / 마감 / 직접입력**, **퀴즈** 표시 등.

## 10. 자주 하는 질문

**Q. 양식과 학교「관리 > 양식(출력 양식)」의 차이는?**  
A. 이 매뉴얼의 양식은 **Alt Board 양식**(설문·기록·문서 머지)입니다.  
학교 **출력 양식 에디터**(생활기록부 레이아웃, `데이터 연결`)는 별도 기능입니다.

**Q. 필드 이름을 바꾸면 문서가 깨지나요?**  
A. 머지는 **필드 라벨**을 씁니다. 라벨을 바꾸면 `{{예전이름}}` 문서를 함께 수정해야 합니다.

**Q. 퀴즈 UI를 HTML로 예쁘게 만들었는데?**  
A. 네이티브 퀴즈 모드가 기록·채점과 바로 연결됩니다. 커스텀 HTML 앱은 별도 API 연동이 필요합니다.

**Q. 응답이 안 보여요.**  
A. 시작/마감, 본인 응답 확인, 응답 결과 공유, 관리자 필드 공개, 필드 권한을 확인하세요.

**Q. 양식 필드를 삭제했더니 예전 답이 안 보여요.**  
A. 응답은 필드 ID에 묶여 시트에 남습니다. 필드를 삭제하면 양식 UI에는 안 보일 수 있고, 본인 응답 화면에는 **이전 응답**으로 표시됩니다. 삭제 전 빌더에서 확인 경고가 뜹니다.
