세 가지 키, 세 가지 플랜

영상과 같은 메시지입니다. Alt는 학사, Shift는 소통과 활동, Ctrl은 Alter입니다. 학교는 필요한 모듈만 켭니다.

Alt⌥

ALT · 기본 학사

교육적 시스템

대안적이고 수준 높은 교육을 지향하는 기본 학사입니다. 일정, 수업, 기록, 문서를 한 학교에서 운영합니다.

  • 일정 월·주·일 보기. 수업과 행사가 캘린더에 모입니다.
  • 수업 시간표, 개설, 수강. 학기의 수업을 한 흐름으로 봅니다.
  • 기록 학교 양식 기반 생활기록. 앱 메뉴 이름은 기록입니다.
  • 문서 출력 양식을 미리보고 인쇄합니다.

학기 설정과 양식 에디터는 ALT를 쓰기 위한 도구입니다.

Shift⇧

SHIFT · 소통과 활동

맞춤형 시스템

직접 다양한 기능을 구현할 수 있는 맞춤형 층입니다. 채팅, 보드, 활동으로 학교 안의 일을 모읍니다.

  • 채팅 DM, 그룹, 보드 채팅으로 구성원이 바로 이야기합니다.
  • 보드 학교·수업 단위 공간. 활동, 문서, 채팅 탭이 한 보드에 있습니다.
  • 활동 설문, 퀴즈, 평가 등 양식 응답과 할 일을 처리합니다.
활동문서채팅
현장학습 신청 · 미제출 3
프로젝트 평가 · 채점 대기
주간 성찰 · 승인됨

학교 소개 페이지를 외부에 공개할 수도 있습니다.

Ctrl⌃

CTRL · Alter

지능형 시스템

인공지능을 교육에 활용하는 층입니다. 상단 Alter로 질문하고, 화면 맥락에 맞는 스킬로 초안을 받습니다.

  • 챗봇 지금 보고 있는 화면을 바탕으로 질문하고 설명을 듣습니다.
  • 작성 스킬 수업(강의계획서), 평가, 기록, 문서, 활동·응답 초안.
  • 점검·채점 문서 점검과 채점 초안. 미리보기 후 확인해야 반영됩니다.

교사의 판단을 대신하지 않습니다. 기록을 돕습니다.

요금과 제공 기능

ALT가 기본입니다. SHIFT와 CTRL은 필요할 때 더합니다. 아래는 AEG 기본 단가이며, 아카데미마다 한도와 단가를 조정할 수 있습니다.

ALT

좌석

30,000원 / 100명 · 월

연 360,000원 · 활성 학기 고유 사용자

  • 일정, 수업, 기록, 문서
  • 학기 · 양식 · 권한 등 기본 학사

AEG 연회비 (선입금, 중단 시 1할 환불)

  • 100명 이하 · 연 360,000원
  • 101–200명 · 연 720,000원
  • 201–300명 · 연 1,200,000원

SHIFT

저장 용량

10,000원 / 100GB · 월

  • 채팅, 보드, 활동
  • 공개 웹사이트 (보조)

켠 뒤에도 채팅·보드·사이트는 아카데미와 학교에서 따로 켭니다. 기록·프로필 파일은 SHIFT가 꺼져도 올릴 수 있고, 용량 한도가 있으면 그 한도는 적용됩니다.

CTRL

Alter 사용량

10,000원 / 10,000 Alt · 월

  • Alter 챗봇과 스킬
  • 초안 · 점검 · 채점 (확인 후 반영)

1 Alt = 10,000 토큰. API 키와 모델은 관리자가 등록합니다. 학교 AI 탭에서 교사·학생 권한과 1인당 일일 Alt 한도를 정합니다.

ALT만 학사 운영
ALT + SHIFT 학사 + 채팅 · 보드 · 활동
ALT + SHIFT + CTRL 위 + Alter

예시 산식 · 100명 + SHIFT 100GB + CTRL 10,000 Alt = 월 30,000원 + 10,000원 + 10,000원

AEG 이용 안내

AEG(Altsis Educator Group)는 별무리학교가 운영하는 Altsis 서버(altsis.org)를 학교에 임대합니다.

  1. 1AEG 담당자에게 서비스 신청을 요청합니다.
  2. 2학교 관리자로 AEG 관리자 연수 이수자를 둡니다.
  3. 3규모에 맞는 연회비를 입금합니다.
  4. 4아카데미를 만들고 관리자 계정을 발급받습니다.

관리자 연수는 30차시, 1인 300,000원입니다. 시스템을 학교에 맞게 설계하고 운영하기 위한 과정입니다. 운영·오류 문의는 AEG 담당자 구본길 (bmrlove@bmrschool.org)에게 합니다. 입금 안내는 문의 이후 전달합니다.
