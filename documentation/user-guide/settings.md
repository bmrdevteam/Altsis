## 개요

설정 페이지에서는 개인 프로필, 보안, 알림, 테마 등 사용자 환경을 맞춤 설정할 수 있습니다. 페이지 왼쪽 목록에서 섹션을 고릅니다.

### 설정 페이지 접근

좌측 사이드바 **맨 아래 프로필**에서 **설정**을 누릅니다. (프로필 사진을 누르면 **내 정보**(나의 정보)로 갑니다. 설정과 다릅니다.) 상단 검색(`⌘K` / `Ctrl+K`)에서도 설정을 찾을 수 있습니다.

### 설정 섹션 구성

| 섹션 | 아이콘 | 설명 |
|------|:------:|------|
| 사용자 정보 | 프로필 | 프로필 사진, 이름 등 기본 정보 |
| 소셜 로그인 | Google | Google 계정 연동 |
| 보안 | 톱니바퀴 | 비밀번호 변경 |
| 알림 | 알림 | 알림 유형별 설정 |
| 등록된 학교 | 학교 | 소속 학교 정보 확인 |
| 테마 | 그리드 | 화면 테마 설정 |
| Altsis 안내 | 문서 | 이 사용자·관리자 가이드 (`/guide`) |

## 사용자 정보

프로필 사진과 이름 등 기본 사용자 정보를 관리합니다.

### 프로필 사진 변경

1. 설정 페이지에서 **사용자 정보** 섹션을 선택합니다.
2. 현재 프로필 사진을 클릭합니다.
3. 새 이미지 파일을 선택합니다.
4. 이미지가 업로드되고 프로필 사진이 변경됩니다.

> [!TIP]
> 프로필 사진은 정사각형 비율의 이미지를 권장합니다. 업로드된 이미지는 자동으로 원형 프레임에 맞게 잘려서 표시됩니다.

### 이름 변경

1. **사용자 정보** 섹션에서 이름 입력란을 찾습니다.
2. 새 이름을 입력합니다.
3. **저장** 버튼을 클릭합니다.

> [!NOTE]
> 사용자 아이디(ID)는 변경할 수 없습니다. 아이디 변경이 필요한 경우 관리자에게 문의하세요.

## 소셜 로그인

Google 계정을 Altsis 계정에 연동하여 소셜 로그인을 사용할 수 있습니다.

### Google 계정 연동

1. 설정 페이지에서 **소셜 로그인** 섹션을 선택합니다.
2. **Google 계정 연동** 버튼을 클릭합니다.
3. Google 로그인 창이 열립니다.
4. 연동할 Google 계정으로 로그인합니다.
5. 연동이 완료되면 이후 로그인 시 Google 계정으로 로그인할 수 있습니다.

### Google 계정 연동 해제

1. **소셜 로그인** 섹션에서 현재 연동된 Google 계정 정보를 확인합니다.
2. **연동 해제** 버튼을 클릭합니다.
3. 확인 대화상자에서 **확인**을 클릭합니다.

> [!WARNING]
> Google 계정 연동을 해제하면 Google 계정으로 로그인할 수 없게 됩니다. 아이디와 비밀번호를 기억하고 있는지 확인한 후 해제하세요.

## 보안

비밀번호 변경 등 계정 보안 설정을 관리합니다.

### 비밀번호 변경

1. 설정 페이지에서 **보안** 섹션을 선택합니다.
2. 다음 정보를 입력합니다.

| 항목 | 설명 |
|------|------|
| 현재 비밀번호 | 현재 사용 중인 비밀번호 |
| 새 비밀번호 | 변경할 새 비밀번호 |
| 새 비밀번호 확인 | 새 비밀번호를 다시 한번 입력 |

3. **변경** 버튼을 클릭합니다.

> [!IMPORTANT]
> 비밀번호 변경 후에는 기존 세션이 유지되지만, 다음 로그인 시 새 비밀번호를 사용해야 합니다. 새 비밀번호를 안전한 곳에 기록해 두세요.

### 비밀번호 보안 권장 사항

- 8자 이상의 비밀번호를 사용하세요.
- 영문 대/소문자, 숫자, 특수문자를 조합하세요.
- 다른 서비스와 동일한 비밀번호를 사용하지 마세요.
- 주기적으로 비밀번호를 변경하세요.

## 알림 설정

알림 유형별 수신 여부와 알림음을 설정합니다. 상세한 내용은 [알림 - 알림 설정](notifications.md#알림-설정) 문서를 참고하세요.

### 빠른 설정 안내

설정 페이지의 **알림** 섹션에서 다음 항목을 개별적으로 설정할 수 있습니다.

| 설정 항목 | 설명 |
|-----------|------|
| 수업 초대 | 수업 초대 알림 ON/OFF |
| 수업 초대 취소 | 수업 초대가 취소되었을 때 |
| 수업 승인 | 강의계획서 승인 알림 ON/OFF |
| 수업 승인 취소 | 승인 취소 알림 ON/OFF |
| 일정 시작 | 캘린더 일정 시작 알림 ON/OFF |
| 리마인더 | 리마인더 알림 ON/OFF |
| 새 게시글 | 보드 새 글 알림 ON/OFF |
| 보드 초대 | 보드에 초대되었을 때 |
| 승인 요청 / 결과 | 활동(양식) 승인. 결재 알림 켜는 순서는 [결재](approval.md#알림-앱--푸시--이메일) |
| 채팅 메시지 | 잠금화면 알림이 켜진 경우 새 채팅 |
| 알림음 | 알림 수신 시 소리 재생 ON/OFF |
| 잠금화면 알림 | Web Push (옵트인). 허용한 유형이 잠금화면에도 표시 |
| 이메일 알림 | 아카데미가 허용한 학교에만 표시. 프로필/Google 메일로 수신 |

## 등록된 학교

현재 계정에 등록된 학교 정보를 확인합니다.

### 학교 정보 확인

1. 설정 페이지에서 **등록된 학교** 섹션을 선택합니다.
2. 소속 학교 목록과 각 학교의 기본 정보가 표시됩니다.
   - 학교 이름
   - 학교 소속 아카데미
   - 등록 상태

> [!NOTE]
> 학교 등록 및 해제는 관리자만 가능합니다. 학교 등록에 관한 문의는 학교 관리자에게 하세요.

## 테마 설정

화면의 시각적 테마를 변경할 수 있습니다. 프리셋 테마를 선택하거나 나만의 커스텀 테마를 만들 수 있습니다.

### 프리셋 테마

사전에 정의된 테마를 선택하여 즉시 적용할 수 있습니다.

| 테마 | 설명 |
|------|------|
| 라이트 (Light) | 밝은 배경에 어두운 텍스트를 사용하는 기본 테마 |
| 다크 (Dark) | 어두운 배경에 밝은 텍스트를 사용하는 테마. 눈의 피로를 줄여줌 |
| 고대비 (High Contrast) | 배경과 텍스트의 대비를 극대화한 테마. 시인성이 높음 |
| 세피아 (Sepia) | 따뜻한 갈색 톤의 테마. 독서에 적합한 부드러운 색감 |
| 시스템 (System) | 운영체제의 테마 설정을 자동으로 따르는 모드 |

#### 프리셋 테마 적용

1. 설정 페이지에서 **테마** 섹션을 선택합니다.
2. 프리셋 테마 목록에서 원하는 테마를 클릭합니다.
3. 테마가 즉시 적용되어 미리보기를 확인할 수 있습니다.

> [!TIP]
> **시스템** 테마를 선택하면 운영체제의 다크 모드/라이트 모드 설정에 따라 자동으로 전환됩니다. 예를 들어, macOS나 Windows에서 다크 모드를 활성화하면 Altsis도 자동으로 다크 테마로 전환됩니다.

### 커스텀 테마

7가지 키 컬러를 직접 지정하여 나만의 고유한 테마를 만들 수 있습니다.

#### 커스텀 테마 생성 절차

1. **테마** 섹션에서 **커스텀** 옵션을 선택합니다.
2. 7가지 키 컬러를 설정합니다.

**키 컬러 구성:**

| 키 컬러 | 역할 | 적용 범위 |
|---------|------|-----------|
| 배경색 1 | 주요 배경색 | 페이지 전체 배경 |
| 배경색 2 | 보조 배경색 | 카드, 패널 등 보조 영역 |
| 텍스트색 1 | 주요 텍스트색 | 제목, 본문 텍스트 |
| 텍스트색 2 | 보조 텍스트색 | 부가 정보, 힌트 텍스트 |
| 강조색 1 | 주요 강조색 | 버튼, 링크, 활성 상태 |
| 강조색 2 | 보조 강조색 | 호버 효과, 보조 강조 |
| 테두리색 | 테두리 및 구분선 | 카드 테두리, 구분선 |

3. 각 컬러를 클릭하면 컬러 피커가 열립니다.
4. 원하는 색상을 선택합니다.
5. 선택한 7가지 키 컬러를 바탕으로 50개 이상의 CSS 변수가 자동 생성됩니다.

#### 실시간 미리보기

커스텀 테마를 설정하는 동안 변경 사항이 실시간으로 화면에 반영됩니다. 색상을 변경할 때마다 전체 화면이 즉시 업데이트되므로, 최종 결과를 미리 확인하면서 색상을 조절할 수 있습니다.

#### 커스텀 테마 저장

1. 원하는 색상 설정을 완료합니다.
2. **저장** 버튼을 클릭합니다.
3. 커스텀 테마가 서버에 저장되어 다른 기기에서도 동일한 테마가 적용됩니다.

> [!NOTE]
> 커스텀 테마는 브라우저의 localStorage와 서버 데이터베이스 모두에 저장됩니다. 서버에 저장된 테마가 우선 적용되므로, 어느 기기에서 접속하든 동일한 커스텀 테마를 사용할 수 있습니다.

### 테마 자동 생성

7가지 키 컬러를 선택하면 시스템이 자동으로 다음과 같은 파생 색상을 생성합니다.

- 상태 색상 (성공, 정보, 경고, 오류)과 그에 따른 배경색, 테두리색
- 현재 시간 표시색 (캘린더)
- 하이라이트 색상
- 체크박스 활성 색상
- 그 외 UI 전반에 걸친 세부 색상

이를 통해 최소한의 색상 설정으로도 전체 UI에 일관된 테마가 적용됩니다.

### 테마 초기화

커스텀 테마를 초기화하고 기본 테마로 돌아가려면 프리셋 테마 중 하나를 선택하면 됩니다.

> [!TIP]
> 커스텀 테마를 만들 때는 배경색과 텍스트색의 명도 대비를 충분히 확보하세요. 대비가 낮으면 텍스트 가독성이 떨어질 수 있습니다. WCAG 접근성 기준에서 권장하는 대비 비율은 4.5:1 이상입니다.

## 기능 켜기 (관리자)

채팅·보드·AI·목표·공개 웹사이트는 **개인 설정이 아니라** 아카데미 플랜과 학교 관리 화면에서 켭니다.

| 기능 | 어디서 | 기본 |
|------|--------|------|
| 채팅 | 학교 상세 **채팅** / 아카데미 `chatEnabled` | 아카데미 OFF |
| 보드 | 학교 상세 **보드** / 아카데미 `boardEnabled` | 보드 메뉴는 학교 미설정 시 표시 |
| AI | 소유자·**플랜**에서 키·모델, 학교 **AI** 탭에서 지침·권한 | 아카데미 OFF |
| 목표 | 학교 **목표** 탭 | 켜짐 |
| 공개 웹사이트 | 아카데미 `sitePublishEnabled` 후 관리 **공개 웹사이트** | OFF |

자세한 내용은 [아카데미 관리](../admin-guide/academy-management.md#ai-설정), [학교 관리](../admin-guide/school-management.md)를 참고하세요. 켜진 뒤 사용자는 상단 **Alter**에서 AI를 씁니다 ([채팅 — Alter](chat.md#alter-전역-ai-어시스턴트)).
