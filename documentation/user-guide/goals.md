# 목표 ⚪

수강·평가·보드 할 일 등 진행 상황을 한곳에서 보는 기능입니다. 학교 관리자가 표시 항목과 목표 숫자를 정하면, 구성원 사이드바와 **목표** 페이지에 반영됩니다.

## 개요

| 항목 | 내용 |
|------|------|
| 사이드바 | 접힌 상태에서도 아이콘으로 진행을 볼 수 있는 **목표** 위젯 |
| 전체 보기 | 위젯을 눌러 목표 대시보드로 이동 |
| 언제 보이나 | 학교 **목표** 기능이 켜져 있을 때 (기본 켜짐) |
| 역할 | 교사·학생에 따라 보이는 항목이 다름 (수강 / 담당·개설 / 보드 할 일 등) |

학점 상한·수강 조건은 학교 설정에서 관리합니다. 목표 숫자는 채워진 칸(fill bar)으로 표시됩니다.

---

## 사이드바 위젯

좌측 사이드바 하단에 목표 요약이 있습니다.

- 선택한 항목의 현재 값 / 목표를 바로 볼 수 있습니다.
- **항목 고르기**로 본인 화면에 보일 항목만 고를 수 있습니다. (학교 관리자가 허용한 항목 안에서)
- 기능을 꺼 둔 학교에서는 「목표 설정」만 보이고, 관리자는 학교 설정으로 다시 켤 수 있습니다.

---

## 목표 페이지

사이드바에서 목표를 눌러 전체 보기로 이동합니다.

역할에 따라 예를 들어 다음 묶음이 나타납니다.

| 묶음 | 예시 항목 |
|------|-----------|
| 수강 | 수강 과목, 총 학점, 주간 수업 시수 |
| 담당·개설 (교사) | 담당 수업, 개설 수업, 평가 입력 현황 |
| 보드 | 미제출·승인 대기 등 할 일, 체크박스가 여러 개인 양식의 진행(체크 수/전체 칸) |

항목을 누르면 관련 화면(수업, 보드 할 일 등)으로 이동합니다.

---

## 관리자 설정

> **필요 권한**: 🔵 Manager (또는 🔴 Admin)

**관리** → 학교 상세 → **목표** 탭에서 다음을 설정합니다.

1. **목표 기능 활성화**: 끄면 구성원 사이드바와 목표 페이지가 숨겨집니다.
2. **역할별 표시 항목**: 교사/학생에게 보여줄 요약을 켭니다. 보드 양식의 응답자용 체크박스(양식 도구의 체크박스=다중 선택 선택지, 또는 켜짐/꺼짐 문항)가 2칸 이상이면, 필수 응답이 아니어도 켠 항목에 **체크한 칸 / 전체 칸**이 표시됩니다. 아직 제출하지 않았으면 `0/n`입니다.
3. **목표 숫자**: 학점·과목 수 등에 목표값을 넣으면 진행 바로 보입니다.
4. **표시 순서**: 항목 순서를 드래그로 바꿉니다.

> [!NOTE]
> 아카데미 플랜(SHIFT 등)과 학교 기능 토글에 따라 일부 항목(보드 할 일 등)이 숨겨질 수 있습니다.
