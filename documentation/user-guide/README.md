# 사용자 가이드

교사와 학생을 위한 Altsis 기능별 사용 가이드입니다. 이 문서는 Altsis의 주요 기능을 기능별로 나누어 사용법을 상세히 안내합니다.

---

## 대상 독자

이 가이드는 다음 사용자를 대상으로 합니다.

| 역할 | 설명 |
|------|------|
| 교사 (Teacher) | 수업을 개설하고, 학생을 평가하며, 기록을 관리하는 사용자 |
| 학생 (Student) | 수업에 수강 신청하고, 본인의 평가 및 기록을 조회하는 사용자 |

> [!NOTE]
> 학교 및 아카데미 관리 기능은 [관리자 가이드](../admin-guide/README.md)를 참고하세요.

---

## 권한 기호

이 문서에서 사용하는 권한 기호는 다음과 같습니다.

| 기호 | 의미 |
|------|------|
| ⚫ | 시스템 관리자(Owner) 권한 필요 |
| 🔴 | 아카데미 관리자(Admin) 권한 필요 |
| 🔵 | 학교 관리자(Manager) 권한 필요 |
| ⚪ | 일반 사용자(Member) 사용 가능 |

---

## 시작하기 전에

Altsis를 사용하기 위해 다음 사항을 확인하세요.

1. **계정 생성**: 관리자로부터 계정을 발급받았는지 확인합니다.
2. **학교 등록**: 소속 학교에 등록되어 있는지 확인합니다.
3. **학기 등록**: 현재 활성 학기에 등록되어 있는지 확인합니다.

> [!TIP]
> 계정이 없거나 학교/학기에 등록되지 않은 경우, 학교 관리자에게 문의하세요.

---

## 권장 학습 순서

처음 Altsis를 사용하는 경우 아래 순서로 가이드를 읽는 것을 권장합니다.

### 교사

```
수업 관리 → 평가 → 학생 기록 → 캘린더 → 게시판 → 설정
```

### 학생

```
수업 관리(수강신청) → 평가(결과 조회) → 학생 기록(내 기록) → 캘린더 → 게시판 → 설정
```
