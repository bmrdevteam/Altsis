# 사용자 가이드

교사와 학생을 위한 Altsis 기능별 사용 가이드입니다. 메뉴 이름·화면 구성은 앱과 같습니다.

---

## 대상 독자

| 역할 | 설명 |
|------|------|
| 교사 (Teacher) | 수업을 개설하고, 학생을 평가하며, 기록·보드 활동을 관리하는 사용자 |
| 학생 (Student) | 수강 신청하고, 본인 평가·기록·문서를 조회하며 보드에 참여하는 사용자 |

> [!NOTE]
> 학교 및 아카데미 관리 기능은 [관리자 가이드](../admin-guide/README.md)를 참고하세요.

---

## 화면 구성

로그인 후 URL은 `/:아카데미ID/:학교ID/...` 형태입니다. 상단에서 학기(쿼터)를 바꿀 수 있습니다.

### 좌측 사이드바

| 메뉴 | 설명 | 조건 |
|------|------|------|
| 일정 | 홈. 월/주/일 캘린더 | 항상 (학기 등록 없이도) |
| 수업 | 시간표·수강·개설·담당. 하위: 수업 개설, 수강 신청, 전체 목록, 강의실 현황 | 학기 등록 있음 |
| 기록 | 학교 기록 양식별 탭 | 학기 등록 + 해당 양식 권한 |
| 문서 | 출력 양식 미리보기·인쇄 | 학기 등록 있음 |
| 보드 | 활동·게시글·채팅. 학기 없이도 학교 보드 사용 가능 | 아카데미/학교에서 보드 켜짐 |
| 관리 | 학교·학기·양식 등 (관리자). admin 하위: 양식·사용자·플랜·백업 및 복구·(허용 시)공개 웹사이트. manager 하위: 양식 | admin / manager |
| 링크 | 학교가 등록한 외부 URL | 링크가 있을 때 |
| 목표 | 진행 요약 위젯 | 학교 목표 기능 켜짐 |
| 프로필 | **내 정보**(나의 정보) / **설정** / 로그아웃 | 항상 |

학기 등록이 없으면 수업·기록·문서는 숨겨지고 **일정·보드** 중심으로 쓸 수 있습니다.

### 상단 네비게이션

| 항목 | 설명 |
|------|------|
| 검색 | `⌘K` / `Ctrl+K` 명령 팔레트. 메뉴·사용자 검색 |
| 학기 선택 | 같은 학교의 등록된 학기 전환 |
| 알림 | 실시간 알림 |
| 채팅 | DM·그룹 채팅 (채팅 기능이 켜진 경우) |
| Alter | 전역 AI 작성·점검 도우미 (AI가 켜진 경우) |

앱 안 이 문서는 사이드바 **안내**(소유자) 또는 설정 → **Altsis 안내**, 로그인 화면의 안내 링크로 엽니다. 주소는 `/guide` 입니다.

## 권한 기호

| 기호 | 의미 |
|------|------|
| ⚫ | 시스템 관리자(Owner) 권한 필요 |
| 🔴 | 아카데미 관리자(Admin) 권한 필요 |
| 🔵 | 학교 관리자(Manager) 권한 필요 |
| ⚪ | 일반 사용자(교사/학생) 사용 가능 |

---

## 시작하기 전에

1. **계정 생성**: 관리자로부터 계정을 발급받았는지 확인합니다.
2. **학교 등록**: 소속 학교에 등록되어 있는지 확인합니다.
3. **학기 등록**: 수업·기록·문서를 쓰려면 현재 학기에 등록되어 있어야 합니다. 보드만 쓰는 학교는 학기 없이 운영할 수도 있습니다.

> [!TIP]
> 계정이 없거나 학교/학기에 등록되지 않은 경우, 학교 관리자에게 문의하세요.

---

## 권장 학습 순서

### 교사

```
수업 관리 → 평가 → 학생 기록 → 문서 → 일정 → 보드 → 목표 → 설정
```

### 학생

```
수업 관리(수강신청) → 평가(결과 조회) → 기록·문서 → 일정 → 보드 → 목표 → 설정
```
