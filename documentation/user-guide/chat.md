# 채팅 ⚪

## 개요

Altsis의 채팅 기능은 학교 구성원 간의 실시간 소통을 지원하는 메시징 시스템입니다. WebSocket 기반으로 실시간 메시지를 주고받으며, 텍스트·이미지·파일 공유가 가능합니다. Alter는 같은 화면 상단에서 열 수 있는 **작성·점검 도우미**이며, DM/보드 채팅방과는 분리되어 있습니다.

**주요 특징:**
- DM(1:1), 그룹 채팅, 보드 채팅
- 실시간 메시지 전송/수신 (WebSocket 기반)
- 인용 답장, 이모지 리액션
- 이미지, 문서 등 다양한 파일 공유
- 말풍선 읽음 숫자와 목록 미읽음 뱃지
- 채팅방 고정(Pin) 및 아카이브
- 메시지 그룹핑 (같은 시간대 메시지 묶어서 표시)
- Alter: 페이지 문맥에 맞는 Skill·초안 적용 (Navbar)

### 기능 활성화

채팅 기능은 아카데미 단위로 활성화/비활성화할 수 있습니다. 아카데미 관리자가 `chatEnabled` 설정을 켜야 채팅 메뉴가 표시됩니다. Alter는 `aiEnabled` 및 학기 AI 설정이 필요합니다 ([설정 — AI](settings.md#ai-설정)).

## 채팅 유형

| 유형 | 설명 | 접근 경로 |
|------|------|-----------|
| DM (1:1) | 특정 사용자와의 1:1 대화 | 상단바 채팅 아이콘 |
| 그룹 채팅 | 여러 명이 참여하는 대화 | 상단바 채팅 아이콘 |
| 보드 채팅 | 보드 멤버 간 대화 (자동 참여) | 보드 > 채팅 탭 |
| Alter | AI 작성·점검 도우미 (사람 채팅과 별개) | 상단바 Alter(스파클) 아이콘 |

## DM (1:1 채팅)

특정 사용자와 1:1 대화를 시작합니다.

### 생성 절차

1. 상단 네비게이션 바의 **채팅** 아이콘을 클릭합니다.
2. 채팅 사이드바가 열립니다.
3. **새 채팅** 버튼을 클릭합니다.
4. 대화 상대를 검색하여 **1명**을 선택합니다.
5. DM 채팅방이 생성됩니다.

> [!NOTE]
> 동일한 상대와의 DM이 이미 존재하는 경우 기존 채팅방이 열립니다. 중복으로 생성되지 않으며, 본인은 참여자 목록에서 자동 제외됩니다.

---

## 그룹 채팅

여러 명이 함께 참여하는 그룹 대화를 시작합니다.

### 생성 절차

1. **새 채팅** 버튼을 클릭합니다.
2. 참여자를 **2명 이상** 검색하여 선택합니다.
3. 그룹 채팅방 이름을 입력합니다 (선택 사항).
4. **생성** 버튼을 클릭합니다.

> [!TIP]
> 그룹 채팅방의 이름을 지정하지 않으면 참여자 이름의 조합이 채팅방 이름으로 사용됩니다.

---

## 보드 채팅

보드 내에서 멤버 간 실시간 대화를 할 수 있습니다. 보드의 **채팅** 탭에서 접근합니다.

### 하위 탭 구성

| 탭 | 설명 |
|----|------|
| 그룹 | 보드 멤버 전원이 참여하는 메인 채팅 |
| DM | 보드 멤버 간 1:1 대화 |
| AI | AI 교육 보조(Alter)와 대화 |

### 그룹 채팅

보드에 진입하면 자동으로 보드 그룹 채팅에 참여됩니다. 별도의 초대가 필요 없습니다.

### 보드 내 DM

멤버 사이드바에서 대화할 상대를 선택하면 해당 멤버와의 DM이 시작됩니다.

## Alter (전역 AI 어시스턴트)

Alter는 보드 채팅 탭이 아니라 **상단 Navbar의 Alter(스파클) 아이콘**으로 여는 전역 패널입니다. 현재 보고 있는 페이지 문맥(강의계획서, 평가, 캘린더, 기록, 보드 문서 등)에 맞는 Skill로 초안을 만들고, 확인 후 화면에 적용할 수 있습니다.

### 사용 조건

- 아카데미에서 `aiEnabled`가 활성화되어 있어야 합니다.
- AI API 키·제공자·모델이 설정되어 있어야 합니다.
- 현재 학기(및 학교)에서 AI 사용이 허용되어야 합니다.

### 사용 방법

1. 상단바에서 **Alter** 아이콘을 클릭해 패널을 엽니다.
2. 필요하면 Skill(수업·평가·기록·문서·응답 등)과 지침·참고자료를 확인합니다.
3. 요청을 보내 초안·점검 결과·일반 답변을 받습니다.
4. 초안이 나오면 **적용(Apply Draft)** 으로 해당 입력란·문서에 반영합니다 (미리보기 후 적용).
5. 대화는 학교 단위로 저장되며, 패널에서 이전 대화를 이어갈 수 있습니다.

### Skill과 초안

| Skill 예시 | 용도 |
|------------|------|
| 챗봇 | 범용 Q&A |
| 수업 | 강의계획서 항목 초안 |
| 평가 / 채점 | 평가·채점 초안 |
| 기록 | 학생 기록 초안 |
| 문서 / 문서 점검 | 보드 문서 작성·지침 점검 |
| 응답 / 활동 | 양식 응답·활동 구조 초안 |

> [!NOTE]
> 토큰 사용량은 서버 로그에 기록됩니다. 제공자·모델은 아카데미 관리자가 설정합니다. API 상세는 [AI API](../api-reference/ai.md)를 참고하세요.

## 메시지 전송 및 수신

### 메시지 전송

1. 채팅방 하단의 메시지 입력란에 텍스트를 입력합니다.
2. **Enter** 키를 누르거나 전송 버튼을 클릭합니다.
3. 메시지가 즉시 전송됩니다.

### 메시지 수신

- 채팅방에 접속 중이면 새 메시지가 실시간으로 표시됩니다.
- 접속하지 않은 상태에서 메시지를 받으면 채팅 아이콘에 안읽은 메시지 수가 표시됩니다.

### 메시지 유형

| 유형 | 설명 |
|------|------|
| 텍스트 | 일반 텍스트 메시지 |
| 이미지 | 이미지 파일 (미리보기 제공) |
| 파일 | 문서, 압축 파일 등 (다운로드 링크 제공) |
| 시스템 | 참여자 입장/퇴장 등 시스템 메시지 |

### 메시지 그룹핑

같은 발신자가 연속으로 보낸 메시지는 시간대별로 그룹핑되어 표시됩니다. 프로필 사진과 이름이 첫 메시지에만 표시되어 대화 가독성이 높아집니다.

---

## 답장과 리액션

### 인용 답장

메시지에서 **답장**을 누르면 입력창에 `> 보낸사람[시간] : 미리보기` 형식으로 원문이 붙습니다. 그대로 보내거나 인용을 수정·지운 뒤 보낼 수 있습니다. 삭제된 메시지와 시스템 메시지에는 답장할 수 없습니다.

### 이모지 리액션

말풍선에서 리액션을 고르면 메시지 아래에 집계됩니다. 같은 이모지를 다시 누르면 취소됩니다.

- 기본: 확인, 기도, 좋아요, 웃음, 하트, 기쁨, 놀람, 울음, 축하
- **+** 로 다른 유니코드 이모지를 추가할 수 있습니다.

## 파일 공유

### 파일 전송

1. 메시지 입력란 옆의 **파일 첨부** 버튼을 클릭합니다.
2. 공유할 파일을 선택합니다.
3. 파일이 업로드되고 채팅방에 메시지로 전송됩니다.

**지원 파일 유형:**

| 분류 | 파일 유형 |
|------|-----------|
| 이미지 | JPG, PNG, GIF, WebP 등 |
| 문서 | PDF, DOC, DOCX, XLS, XLSX, PPT, PPTX 등 |
| 기타 | ZIP, TXT 등 |

### 이미지 미리보기

이미지 파일을 전송하면 채팅 메시지 내에 미리보기 썸네일이 표시됩니다.

### 파일 다운로드

파일 메시지를 클릭하면 파일을 다운로드할 수 있습니다.

## 채팅방 관리

### 채팅방 고정 (Pin)

자주 사용하는 채팅방을 목록 상단에 고정할 수 있습니다.

1. 채팅방을 길게 누르거나 옵션 메뉴를 엽니다.
2. **고정**을 선택합니다.
3. 고정된 채팅방은 목록 상단에 표시됩니다.

### 채팅방 아카이브

사용하지 않는 채팅방을 아카이브하여 목록에서 숨길 수 있습니다.

1. 채팅방 옵션 메뉴에서 **아카이브**를 선택합니다.
2. 아카이브된 채팅방은 기본 목록에서 숨겨집니다.
3. 아카이브 필터로 숨겨진 채팅방을 확인할 수 있습니다.

### 참여자 초대 (그룹 채팅)

1. 채팅방 상단의 **설정** 아이콘을 클릭합니다.
2. **참여자 초대**를 선택합니다.
3. 초대할 사용자를 검색하여 선택합니다.

### 채팅방 나가기

1. 채팅방 상단의 **설정** 아이콘을 클릭합니다.
2. **채팅방 나가기**를 선택합니다.

> [!WARNING]
> 채팅방을 나가면 이후의 메시지를 받을 수 없습니다.

## 읽음 표시

### 말풍선 숫자

본인이 보낸 메시지 옆에, 아직 읽지 않은 참여자 수가 표시됩니다. DM에서는 `1`이 상대가 읽으면 사라집니다. 그룹·보드 팀방·보드 전체방도 같은 방식입니다. 모두 읽으면 숫자는 숨겨집니다.

한 번도 채팅을 열지 않은 참여자는 미읽음으로 셉니다. 보드 전체방은 멤버가 많으면 숫자가 오래 남을 수 있습니다.

### 읽음 처리 시점

- 채팅방에 접속하면 해당 시점까지의 메시지가 자동으로 읽음 처리됩니다.
- 각 참여자의 마지막 읽음 시간(`lastReadAt`)이 기록되고, 상대 화면의 숫자가 바로 줄어듭니다.

> [!TIP]
> 채팅방 목록에서 안읽은 메시지가 있는 채팅방은 뱃지로 표시되어 쉽게 찾을 수 있습니다.
