## 개요

Altsis의 채팅 기능은 학교 구성원 간의 실시간 소통을 지원하는 메시징 시스템입니다. 1:1 대화와 그룹 대화를 모두 지원하며, 텍스트 메시지뿐 아니라 이미지와 파일도 공유할 수 있습니다.

**주요 특징:**
- 1:1 및 그룹 채팅 지원
- 실시간 메시지 전송/수신 (WebSocket 기반)
- 이미지, 문서 등 다양한 파일 공유
- 읽음 확인 표시
- 채팅방별 파일 저장소
- 참여자 초대 및 관리

## 채팅방 생성

### 1:1 채팅

특정 사용자와 1:1 대화를 시작합니다.

#### 생성 절차

1. 상단 네비게이션 바의 **채팅** 아이콘을 클릭합니다.
2. 채팅 패널이 열립니다.
3. **새 채팅** 버튼을 클릭합니다.
4. 대화 상대를 검색하여 선택합니다.
5. 1:1 채팅방이 생성됩니다.

> [!NOTE]
> 동일한 상대와의 1:1 채팅방이 이미 존재하는 경우, 기존 채팅방이 열립니다. 중복으로 생성되지 않습니다.

### 그룹 채팅

여러 명이 함께 참여하는 그룹 대화를 시작합니다.

#### 생성 절차

1. **새 채팅** 버튼을 클릭합니다.
2. 참여자를 2명 이상 검색하여 선택합니다.
3. 그룹 채팅방 이름을 입력합니다 (선택 사항).
4. **생성** 버튼을 클릭합니다.
5. 그룹 채팅방이 생성되고 참여자들에게 알림이 전송됩니다.

> [!TIP]
> 그룹 채팅방의 이름을 지정하지 않으면 참여자 이름의 조합이 채팅방 이름으로 사용됩니다. 나중에 채팅방 설정에서 이름을 변경할 수 있습니다.

## 메시지 전송 및 수신

### 메시지 전송

1. 채팅방 하단의 메시지 입력란에 텍스트를 입력합니다.
2. **Enter** 키를 누르거나 전송 버튼을 클릭합니다.
3. 메시지가 즉시 전송됩니다.

### 메시지 수신

- 채팅방에 접속 중이면 새 메시지가 실시간으로 표시됩니다.
- 채팅방에 접속하지 않은 상태에서 메시지를 받으면 네비게이션 바의 채팅 아이콘에 안읽은 메시지 수가 표시됩니다.
- WebSocket을 통해 페이지 새로고침 없이 실시간으로 메시지를 수신합니다.

### 메시지 유형

채팅에서 주고받을 수 있는 메시지 유형은 다음과 같습니다.

| 유형 | 설명 |
|------|------|
| 텍스트 | 일반 텍스트 메시지 |
| 이미지 | 이미지 파일 (미리보기 제공) |
| 파일 | 문서, 압축 파일 등 (다운로드 링크 제공) |
| 시스템 | 참여자 입장/퇴장 등 시스템 메시지 |

### 시스템 메시지

채팅방에서 특정 이벤트가 발생하면 시스템 메시지가 자동으로 표시됩니다.

- 새 참여자가 초대되었을 때
- 참여자가 채팅방을 나갔을 때
- 채팅방 이름이 변경되었을 때

## 파일 공유

### 파일 전송

채팅에서 이미지와 문서를 직접 공유할 수 있습니다.

1. 메시지 입력란 옆의 **파일 첨부** 버튼을 클릭합니다.
2. 공유할 파일을 선택합니다.
3. 파일이 업로드되고 채팅방에 메시지로 전송됩니다.

**지원 파일 유형:**

| 분류 | 파일 유형 |
|------|-----------|
| 이미지 | JPG, PNG, GIF, WebP 등 |
| 문서 | PDF, DOC, DOCX, XLS, XLSX, PPT, PPTX 등 |
| 기타 | ZIP, TXT 등 |

### 이미지 미리보기

이미지 파일을 전송하면 채팅 메시지 내에 미리보기 썸네일이 표시됩니다. 썸네일을 클릭하면 원본 크기로 확인할 수 있습니다.

### 파일 다운로드

파일 메시지를 클릭하면 파일을 다운로드할 수 있습니다. 파일명, 파일 크기, 파일 유형 정보가 함께 표시됩니다.

> [!WARNING]
> 업로드 파일의 크기 제한이 있을 수 있습니다. 대용량 파일은 압축하거나 분할하여 전송하세요.

## 채팅방 설정

### 참여자 초대

그룹 채팅방에 새로운 참여자를 추가할 수 있습니다.

1. 채팅방 상단의 **설정** 아이콘을 클릭합니다.
2. **참여자 초대**를 선택합니다.
3. 초대할 사용자를 검색하여 선택합니다.
4. 선택한 사용자가 채팅방에 추가됩니다.

> [!NOTE]
> 채팅방 설정에 따라 참여자 초대 권한이 제한될 수 있습니다. 채팅방 생성자가 초대 권한을 관리합니다.

### 참여자 퇴장

채팅방에서 나가려면 다음 절차를 따릅니다.

1. 채팅방 상단의 **설정** 아이콘을 클릭합니다.
2. **채팅방 나가기**를 선택합니다.
3. 확인 대화상자에서 **확인**을 클릭합니다.

> [!WARNING]
> 채팅방을 나가면 이후의 메시지를 받을 수 없습니다. 1:1 채팅방을 나가면 대화 기록에 접근할 수 없게 됩니다.

### 채팅방 이름 변경

그룹 채팅방의 이름을 변경할 수 있습니다.

1. 채팅방 상단의 **설정** 아이콘을 클릭합니다.
2. 현재 채팅방 이름을 클릭합니다.
3. 새 이름을 입력합니다.
4. **저장**을 클릭합니다.

## 파일 저장소

채팅에서 공유된 파일을 한 곳에서 관리할 수 있는 파일 저장소 기능입니다.

### 파일 저장소 접근

1. 채팅방 상단의 **설정** 아이콘을 클릭합니다.
2. **파일 저장소**를 선택합니다.
3. 해당 채팅방에서 공유된 모든 파일 목록이 표시됩니다.

### 파일 분류

파일 저장소에서는 파일을 유형별로 분류하여 조회할 수 있습니다.

| 분류 | 설명 |
|------|------|
| 이미지 | 채팅방에서 공유된 모든 이미지 파일 |
| 파일 | 채팅방에서 공유된 모든 문서 및 기타 파일 |

각 파일에는 다음 정보가 표시됩니다.

- 파일명
- 파일 크기
- 파일 유형 (MIME type)
- 업로드한 사용자
- 업로드 날짜

## 읽음 표시

메시지의 읽음 상태를 확인할 수 있는 기능입니다.

### 읽음 상태 표시

- 메시지 옆에 읽음 상태가 표시됩니다.
- 그룹 채팅에서는 읽지 않은 참여자 수가 표시됩니다.
- 모든 참여자가 읽으면 읽음 표시가 사라집니다.

### 읽음 처리 시점

- 채팅방에 접속하면 해당 시점까지의 모든 메시지가 자동으로 읽음 처리됩니다.
- 각 참여자의 마지막 읽음 시간이 기록됩니다.

> [!TIP]
> 채팅방 목록에서 안읽은 메시지가 있는 채팅방은 별도로 표시되어 쉽게 찾을 수 있습니다.
