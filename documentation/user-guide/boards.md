## 개요

Altsis의 **Alt Board**는 문서·양식·시트·채팅을 통합 관리하는 멀티 기능 보드 시스템입니다. 수업 보드와 독립 보드 두 가지 모드를 지원합니다.

### 핵심 구조

```
Alt Board
├── [Docs 탭]   — 게시글 목록 (설문 첨부, 머지 문법 사용 가능)
├── [Form 탭]   — 양식 목록 (각 Form에 Sheet가 종속)
├── [Sheet 탭]  — 시트 목록 (Form별 Sheet 바로 접근)
└── [채팅 탭]   — 보드 단위 그룹 대화 + DM + AI(Alter)
```

### 두 가지 모드

| 모드 | 설명 | 멤버 |
|------|------|------|
| 독립 보드 | 자유롭게 생성 (동아리, 부서, 프로젝트 등) | 초대 기반 |
| 수업 보드 | 수업 계획서에 1:1 연결 | 수강생 자동 동기화 |

### 기능 활성화

보드 기능은 아카데미 단위로 활성화/비활성화할 수 있습니다. 아카데미 관리자가 `boardEnabled` 설정을 켜야 보드 메뉴가 표시됩니다.

## 보드 목록 및 즐겨찾기

### 보드 페이지 접근

좌측 네비게이션 바에서 **보드** 메뉴를 클릭하면 보드 목록 페이지로 이동합니다.

### 보드 목록 뷰

보드 목록은 카드 형태로 표시됩니다. 각 카드에는 보드 이름, 설명, 멤버 수가 표시됩니다.

### 즐겨찾기

자주 사용하는 보드를 즐겨찾기에 추가할 수 있습니다.

1. 보드 카드의 **별** 아이콘을 클릭합니다.
2. 즐겨찾기된 보드는 목록 상단에 표시됩니다.
3. 다시 클릭하면 즐겨찾기가 해제됩니다.

## 보드 탭 구성

보드 상세 페이지에 진입하면 상단에 탭 네비게이션이 표시됩니다.

| 탭 | 설명 | 뱃지 |
|----|------|------|
| Docs | 게시글 목록 (일반, 설문 포함) | - |
| Form | 양식 목록 | - |
| Sheet | 시트 목록 (Form별 데이터) | - |
| 채팅 | 보드 채팅 (그룹/DM/AI) | 안읽은 메시지 수 |

## Docs (게시글)

### 게시글 작성

1. **Docs** 탭에서 **글쓰기** 버튼을 클릭합니다.
2. TipTap WYSIWYG 에디터로 제목과 내용을 작성합니다.
3. 필요 시 파일을 첨부합니다.
4. 대상을 지정합니다 (전체, 관리자, 교사, 학생, 지정).
5. **게시** 버튼을 클릭합니다.

### 게시글 뷰 모드

게시글 목록은 여러 뷰 모드로 볼 수 있습니다.

| 뷰 모드 | 설명 |
|---------|------|
| 스트림 (블로그) | 게시글을 타임라인 형태로 표시 (기본값) |
| 테이블 | 번호, 제목, 작성자, 조회수, 날짜 표 형태 |

### 게시글 고정 (Pin)

관리자는 중요한 게시글을 목록 상단에 고정할 수 있습니다.

### 댓글

게시글 하단에서 댓글을 작성할 수 있으며, 대댓글(답글)을 지원합니다.

## 설문

게시글에 설문을 첨부할 수 있습니다.

### 설문 작성 (교사)

1. 게시글 작성 화면에서 **설문 첨부** 버튼을 클릭합니다.
2. 설문 빌더가 열립니다.
3. 질문을 추가하고 타입을 선택합니다.

**지원 질문 타입:**

| 타입 | 설명 |
|------|------|
| 단일 선택 (singleChoice) | 하나만 선택 |
| 복수 선택 (multipleChoice) | 여러 개 선택 |
| 단답형 (shortText) | 짧은 텍스트 입력 |
| 장문형 (longText) | 긴 텍스트 입력 |
| 평점 (rating) | 별점 매기기 |
| 선형 배율 (linearScale) | 숫자 범위 선택 |
| 날짜 (date) | 날짜 선택 |
| 시간 (time) | 시간 선택 |
| 파일 업로드 (fileUpload) | 파일 첨부 |

4. 설문 설정을 구성합니다.

| 설정 | 설명 |
|------|------|
| 익명 응답 | 응답자 정보를 숨김 |
| 응답 수정 허용 | 제출 후 수정 가능 |
| 응답 공유 | 모든 사용자가 결과 열람 가능 |

5. 게시글과 함께 게시합니다.

### 설문 응답 (학생)

1. 설문이 첨부된 게시글을 열면 설문 응답 UI가 표시됩니다.
2. 질문에 답변을 입력합니다.
3. **제출** 버튼을 클릭합니다.

### 설문 결과 확인

- **교사**: 전체 응답 통계(분포, 평균) 및 개별 응답을 확인할 수 있습니다.
- **학생**: 설정에 따라 전체 결과를 볼 수 있습니다.
- 설문 결과를 JSON으로 내보낼 수 있습니다.

## Alt Form (양식)

Alt Form은 데이터 수집을 위한 양식 빌더입니다. Form을 생성하면 연결된 Sheet가 자동 생성됩니다.

### Form 생성 (교사/관리자)

1. **Form** 탭에서 **양식 만들기** 버튼을 클릭합니다.
2. 제목과 설명을 입력합니다.
3. 필드를 추가합니다.

**지원 필드 타입:**

| 타입 | 설명 |
|------|------|
| text | 단답형 |
| textarea | 장문형 |
| number | 숫자 |
| date | 날짜 |
| file | 파일 업로드 |
| select / multiSelect | 단일/복수 선택 |
| checkbox | 체크박스 |
| radio | 라디오 버튼 |
| userSelect | 학교 사용자 선택 |
| approval | 승인 워크플로우 |
| rating | 평점 |
| scale | 척도 |
| counter | 카운터 (응답 수 제한) |
| content | 안내 문서 |
| docResponse | 응답 문서 |
| aiChat | AI 챗봇 (교사 AI 권한이 있을 때 추가). 지침·자료를 넣고 학생이 그 범위에서 대화합니다. 대화는 양식 응답을 볼 수 있는 교사가 확인합니다. 학생 전역 AI 권한은 필요 없습니다. 학생은 필드에서 오늘 Alt 사용량을 볼 수 있으며, 한도는 Alter와 같습니다. 응답을 삭제해도 대화는 남고, 교사는 기록 시트의 **AI 대화 보기**에서 확인한 뒤 삭제할 수 있습니다. |

4. 각 필드의 권한을 설정합니다.

| 권한 | 설명 |
|------|------|
| respondent | 응답자(학생)가 Form에서 입력 |
| owner | 작성자(교사)가 Sheet에서만 입력 |

5. Form 설정을 구성합니다.

| 설정 | 설명 |
|------|------|
| 공개 시작/종료 | Form 응답 가능 기간 |
| 재제출 허용 | 제출 후 취소 → 재제출 가능 여부 |
| 퀴즈 모드 | 자동 채점 + 결과 공개 설정 |
| 응답 공유 | 모든 응답자가 전체 결과 열람 가능 |

6. **저장** 버튼을 클릭하면 Form과 Sheet가 함께 생성됩니다.

### Form 응답 (학생)

1. **Form** 탭에서 응답할 양식을 클릭합니다.
2. `respondent` 권한 필드만 화면에 표시됩니다.
3. 응답을 입력한 후 **제출** 버튼을 클릭합니다.
4. 제출 상태가 표시됩니다.

> [!NOTE]
> 공개 기간 외에는 Form에 접근할 수 없습니다. 재제출이 허용된 경우 기존 응답을 취소한 후 다시 제출할 수 있습니다.

### Form 관리

- **복제**: 기존 Form의 구조를 복제하여 새 Form을 생성합니다 (데이터 제외).
- **내보내기/가져오기**: JSON 형식으로 Form 구조를 내보내거나 가져올 수 있습니다.
- **제출 현황**: 전체 멤버 대비 제출/미제출 현황을 확인합니다.
- **미제출자 알림**: 미제출 멤버에게 알림을 보낼 수 있습니다.

## Alt Sheet (시트)

Alt Sheet는 Form 응답 데이터를 테이블 형태로 관리하는 기능입니다.

### Sheet 조회

- **교사/관리자**: 전체 행을 볼 수 있으며, 모든 필드(시스템 컬럼 포함)가 표시됩니다.
- **학생**: `_respondent`가 본인인 행만 표시되며, `respondent` 필드와 `응답자에게 공개` 설정된 `owner` 필드만 볼 수 있습니다.

### 시스템 컬럼

Form 필드 외에 자동으로 추가되는 시스템 컬럼:

| 컬럼 | 설명 |
|------|------|
| `_respondent` | 응답자 |
| `_submittedAt` | 응답 시간 |
| `_updatedAt` | 수정 시간 |

### Sheet 편집 (교사)

- 셀을 클릭하면 인라인 편집이 가능합니다 (owner 필드).
- 행을 직접 추가하거나 삭제할 수 있습니다.
- 다중 행 일괄 입력(Bulk)이 가능합니다.
- CSV 가져오기/내보내기를 지원합니다.

## 머지 Docs (동적 문서)

게시글에서 Sheet 데이터를 동적으로 바인딩하여 개인별 맞춤 문서를 생성할 수 있습니다.

### 머지 문법

| 문법 | 동작 |
|------|------|
| `{{#sheet 시트명}}` | 데이터 소스 Sheet 선언 (문서 상단, 1개만) |
| `{{변수}}` | Sheet 행의 해당 필드 값 |
| `{{#each}} ... {{/each}}` | 매칭된 모든 행을 반복 |
| `{{#table 컬럼1, 컬럼2, ...}}` | 매칭된 행을 테이블로 렌더링 |
| `{{_count}}` | 매칭된 행 수 |

### 열람 동작

| 열람자 | 동작 |
|--------|------|
| 응답자 (학생) | Sheet에서 `_respondent = 나`인 행 자동 매칭 → 변수 치환 |
| Sheet 열람 권한자 (교사) | 상단에 사용자 검색/선택 UI → 선택한 사용자의 행으로 변수 치환 |

### 예시 — 성적 통지서

```
{{#sheet 과제 제출}}

{{_respondentName}}님의 과제 현황

- 과제 제목: {{과제 제목}}
- 점수: {{점수}}점
- 피드백: {{피드백}}
```

## 보드 채팅

보드 내에서 실시간 채팅 기능을 사용할 수 있습니다. 채팅 탭은 세 가지 하위 탭으로 구성됩니다.

### 그룹 채팅

보드 멤버 전원이 참여하는 메인 대화 공간입니다. 보드 멤버가 자동으로 참여합니다.

### DM (1:1)

보드 멤버 간 1:1 대화를 할 수 있습니다. 멤버 목록에서 대화 상대를 선택합니다.

### AI 채팅 (Alter)

AI 기능이 활성화된 경우, AI 교육 보조(Alter)와 대화할 수 있습니다.

> [!NOTE]
> AI 채팅은 아카데미 및 학기 단위로 AI가 활성화되어 있어야 사용 가능합니다.

## 보드 권한

보드의 권한은 **설정 기반**으로, 학교 역할(교사/학생)과 독립적으로 부여됩니다.

| 역할 | 설명 |
|------|------|
| 관리자 (admin) | 보드 설정, 멤버 관리, 모든 기능 접근 |
| 작성자 (writer) | Docs/Form 생성, Sheet 전체 열람/편집 |
| 응답자 (respondent) | Form 응답, 본인 행만 Sheet에서 열람 |

### 수업 보드 기본값

| 학교 역할 | 보드 역할 |
|-----------|-----------|
| 교사 | 관리자 (admin) |
| 학생 | 응답자 (respondent) |

### 독립 보드

생성자가 관리자가 되며, 초대 시 역할을 자유롭게 지정할 수 있습니다. 학생도 관리자/작성자가 될 수 있습니다.

## 보드 관리

### 보드 생성

1. 보드 목록 페이지에서 **보드 만들기** 버튼을 클릭합니다.
2. 보드 이름, 설명을 입력합니다.
3. 멤버를 초대합니다.
4. **생성** 버튼을 클릭합니다.

### 멤버 관리

- 관리자는 멤버를 초대하거나 제거할 수 있습니다.
- 멤버의 역할(관리자/작성자/응답자)을 변경할 수 있습니다.
- 그룹 단위(관리자/교사/학생) 또는 개별 사용자 단위로 접근을 제어할 수 있습니다.

### 알림 설정

보드 단위 및 학교 단위로 알림 이벤트를 제어할 수 있습니다.

| 알림 이벤트 | 설명 |
|------------|------|
| 새 게시글 | 보드에 새 게시글 등록 시 알림 |
| 보드 초대 | 보드에 초대되었을 때 알림 |
| 승인 요청 | Form 승인 요청 수신 시 알림 |
| 승인 결과 | Form 승인/반려 결과 알림 |
