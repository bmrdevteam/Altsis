# 보드 ⚪

Alt Board는 활동(양식)·문서(게시글)·채팅을 한 보드에서 다루는 기능입니다. 사이드바 이름은 **보드**입니다.

## 개요

```
보드 목록 (/boards)
├── [보드] 탭   — 가입한 보드 (기본 탭)
└── [할 일] 탭  — 모든 보드의 미제출·승인·채점 대기

보드 상세
├── [활동] — 양식(설문·퀴즈·평가·승인 등). 응답 시트도 여기서 염
├── [문서] — 게시글, 머지 문서
└── [채팅] — 전체방·팀방·멤버 DM (채팅이 켜진 경우)
```

예전 「기록」 탭은 **활동**으로 합쳐졌습니다. URL 해시 `#기록`·`#양식`은 `#활동`으로 열립니다.

### 보드 종류

| 종류 | 설명 | 멤버 |
|------|------|------|
| 독립 보드 | 동아리·부서·프로젝트 등 | 초대 또는 그룹(교사/학생) |
| 수업 보드 | 강의계획서에 연결 | 수강생과 동기화. 열면 **수업 상세**의 활동/문서/채팅으로 이동 |

### 기능 켜기

보드는 아카데미에서 허용되고 학교에서 끄지 않아야 사이드바에 보입니다. 학교 기본값은 켜짐(`boardEnabled` 미설정 시 표시)입니다. 아카데미 플랜(SHIFT)에 따라 막힐 수 있습니다.

## 보드 목록과 할 일

좌측 사이드바 **보드**로 들어갑니다. 기본 탭은 **보드**입니다. 할 일은 오른쪽 **할 일** 탭에서 모아서 봅니다. 사이드바·보드 카드에 할 일 수가 뱃지로 표시됩니다.

### 보드 탭

- 표 또는 갤러리로 볼 수 있습니다. 보기 방식은 브라우저에 기억됩니다.
- 이름 검색, 할 일 있음, 범위(학교/시즌), 유형, 수업 연결 여부로 좁힐 수 있습니다.
- 정렬: 기본, 이름, 수정일, 생성일, 게시글 수, 생성자.
- 카드의 **별**로 즐겨찾기하면 목록 위쪽에 둡니다.
- 수업 연결 보드는 「수업」 뱃지, 범위는 「학교」/「시즌」 라벨로 구분합니다.

### 할 일 탭

가입한 모든 보드의 조치할 일을 모읍니다. (필수 미제출, 승인 대기, 채점 대기 등) 카드를 누르면 해당 보드·활동으로 이동합니다. 할 일이 없으면 「할 일이 없습니다」와 **보드 목록 보기**가 나옵니다.

예전 목록 URL 해시 `#활동`은 `#할 일`로 열립니다.

---

## 보드 범위

생성 시 **학교 전체** 또는 **이번 시즌만**을 고릅니다. 생성 후 바꿀 수 없습니다.

| 범위 | 동작 |
|------|------|
| 학교 전체 | 그 학교 소속이면 시즌이 바뀌어도 목록에 보입니다. |
| 이번 시즌만 | **현재 학기**일 때만 목록·할 일에 보입니다. |

**시즌 보드:** 그 학기에 활성화된 등록이 있는 사용자만 초대·접근합니다. 예외: 아카데미 admin, 학교 manager, 보드 생성자.

**학기 없이 보드만 쓰기:** 사용자를 학교에 배정하면 됩니다. 학기 등록이 없으면 사이드바의 수업·기록·문서와 상단 학기 선택은 숨겨지고, **일정·보드**는 그대로입니다.

## 보드 상세 탭

| 탭 | 역할 | 뱃지 |
|----|------|------|
| 활동 | 양식 목록, 응답·시트·승인·채점 | 필수 미제출 + 승인/채점 대기 |
| 문서 | 게시글 (스트림/표) | 안 읽은 공개 글 |
| 채팅 | 전체방, 초대제 팀방, 멤버 DM | 안 읽은 메시지 |

수업 연결 보드는 보드 URL 대신 수업 화면의 같은 탭으로 보냅니다.

## 활동 (양식)

활동 탭에서 양식을 만들고 제출·채점합니다. 양식을 저장하면 연결된 **시트(응답 행)** 가 생깁니다. 시트는 별도 탭이 아니라 활동에서 엽니다.

### 양식 만들기 (작성자/관리자)

1. **활동**에서 새 양식을 누릅니다.
2. 제목·설명, 공개 기간, 퀴즈/평가 등을 정합니다.
3. 필드를 추가하고 저장합니다.
4. **비공개**로 두면 작성자만 보입니다. **공개**해야 활동 목록에 올라갑니다.
5. **삭제는 비공개일 때만** 가능합니다.

**자주 쓰는 필드 유형:** 단답/장문, 숫자, 날짜, 시간(오전·오후), 파일, 객관식/드롭다운/체크박스, 사용자 선택, 승인, 회람, 평점·척도, 안내 문서, 응답 문서, AI 챗봇(교사 AI 권한이 있을 때. 학생 전역 AI 권한은 필요 없음).

필드 권한:

| 권한 | 설명 |
|------|------|
| respondent | 응답자가 양식에서 입력 |
| owner | 작성자가 시트에서만 입력 |

자세한 필드·루브릭·퀴즈 설정은 [Alt Board 양식 매뉴얼](../../docs/alt-board-form-manual.md)을 참고하세요. 승인 필드·결재 보기·인쇄·알림은 [결재](approval.md)입니다.

### 퀴즈와 평가 모드

| 구분 | 동작 |
|------|------|
| 퀴즈 | 정답·배점 기반 **자동 채점** |
| 평가 | 제출 후 교사가 **루브릭으로 채점**하고 **확정 공개**. 공개 형태는 점수+루브릭 |

카드 유형·색으로 구분합니다. 채점 대기는 학교 할 일·활동 뱃지로 열 수 있습니다.

### 응답 (학생)

공개 기간 안에 활동 목록에서 양식을 열어 제출합니다. 작성 중 입력은 브라우저에 남고, **저장**은 미제출 초안입니다. **제출**해야 시트·할 일·결재가 시작됩니다. 응답 수정이 허용되면 본인 제출을 고치거나 지울 수 있습니다. 필수 제출은 `n/N` 진행으로 보입니다. 요일마다를 켠 양식은 선택한 요일·시간대에만 할 일과 제출이 가능합니다.

### 시트·가져오기 (교사)

- 셀 인라인 편집, 행 추가/삭제, CSV 가져오기/내보내기
- 승인 칸이 있으면 보기 메뉴에서 **결재 보기**. 일괄 인쇄는 [결재](approval.md#일괄-인쇄와-활동-제목)
- 수업 **평가** 탭에서 활동 응답·CSV를 **빈 칸만** 일괄 가져올 수 있습니다
- 상단 **Alter**로 활동 초안·응답 초안·채점 초안을 받은 뒤 미리보기 확인 후 반영합니다. 채점 초안은 시트에서 미채점 응답을 여러 건 골라 한 번에 받을 수 있습니다. 반영해도 초안이며 **평가 확정**해야 학생에게 보입니다.

## 문서 (게시글)

1. **문서** 탭에서 글쓰기를 누릅니다.
2. TipTap 에디터로 제목·본문·파일을 넣습니다.
3. 공개 대상을 정한 뒤 게시합니다.

| 보기 | 설명 |
|------|------|
| 스트림 | 타임라인 (기본) |
| 테이블 | 제목, 작성자, 조회수, 날짜 |

관리자는 글을 상단에 고정할 수 있습니다. 댓글·대댓글을 지원합니다.

게시글에 설문을 붙일 수 있습니다. (단일/복수 선택, 단답·장문, 평점, 선형 배율, 날짜·시간, 파일 등) 익명·수정 허용·결과 공유를 설정합니다.

### 머지 문서

시트 값을 본문에 넣어 학생별 문서를 만듭니다.

| 문법 | 동작 |
|------|------|
| `{{#sheet 시트명}}` | 데이터 소스 (문서 상단, 1개) |
| `{{변수}}` | 해당 필드 값 |
| `{{#each}} ... {{/each}}` | 매칭 행 반복 |
| `{{#table 컬럼1, 컬럼2}}` | 표로 렌더링 |
| `{{_count}}` | 매칭 행 수 |

학생은 `_respondent = 나`인 행이 자동 적용됩니다. 교사는 상단에서 학생을 고릅니다.

사이드바 **문서**(출력 양식)와는 다릅니다. → [문서](docs.md)

## 보드 채팅

채팅이 켜져 있으면 **채팅** 탭을 씁니다.

| 공간 | 설명 |
|------|------|
| 전체방 | 보드 멤버 전원 |
| 팀방 | 초대된 멤버만 보는 비공개 방 |
| DM | 멤버 목록에서 상대를 고르면 1:1 |

**Alter는 보드 채팅 안에 없습니다.** 상단 네비의 Alter 아이콘을 사용합니다. → [채팅 — Alter](chat.md#alter-전역-ai-어시스턴트)

## 보드 권한

학교 역할과 별도로 보드 역할을 둡니다.

| 역할 | 설명 |
|------|------|
| 관리자 (admin) | 설정, 멤버, 모든 기능 |
| 작성자 (writer) | 문서·양식 생성, 시트 전체 |
| 응답자 (respondent) | 양식 응답, 본인 행만 |

수업 보드 기본값: 교사 → 관리자, 학생 → 응답자. 독립 보드는 생성자가 관리자이며, 학생도 관리자/작성자가 될 수 있습니다.

---

## 보드 관리

권한이 있으면 보드 만들기, 복제(양식·문서 구조), 멤버 초대/역할 변경, 나가기를 쓸 수 있습니다. 누가 만들 수 있는지는 학교 **보드** 탭의 생성 권한(교사/학생)과 관리자 여부에 따릅니다.

알림: 새 게시글, 보드 초대, 승인 요청/결과는 [설정 → 알림](settings.md)과 [알림](notifications.md)에서 유형별로 끕니다. 결재선·결재 보기·인쇄는 [결재](approval.md)를 보세요.
