## 개요

Altsis의 게시판은 학교 구성원 간의 정보 공유를 위한 기능입니다. 공지사항, 자유게시판 등 다양한 용도의 게시판을 만들고 운영할 수 있습니다.

| 기능 | 관리자 | 교사 | 학생 |
|------|:------:|:----:|:----:|
| 게시판 생성/관리 | O | - | - |
| 게시글 작성 | O | O (권한에 따라) | O (권한에 따라) |
| 게시글 수정/삭제 | O (모든 글) | O (본인 글) | O (본인 글) |
| 게시글 고정(Pin) | O | - | - |
| 댓글 작성 | O | O | O |

## 게시판 목록 조회

### 게시판 페이지 접근

좌측 네비게이션 바에서 **게시판** 메뉴를 클릭하면 게시판 페이지로 이동합니다.

### 게시판 탭 구성

게시판 페이지 상단에 사용 가능한 게시판 목록이 탭 형태로 표시됩니다.

- 기본 게시판(공지사항)이 자동으로 선택됩니다.
- 탭을 클릭하면 해당 게시판의 게시글 목록이 표시됩니다.
- 각 게시판에는 설명이 포함될 수 있으며, 게시판 선택 시 설명이 표시됩니다.

> [!NOTE]
> 게시판이 하나도 없는 경우 "게시판이 없습니다." 메시지가 표시됩니다. 학교 관리자에게 게시판 생성을 요청하세요.

### 게시글 목록

선택한 게시판의 게시글이 표 형태로 표시됩니다.

| 열 | 설명 |
|----|------|
| No | 게시글 번호 (최신순) |
| 제목 | 게시글 제목 (고정글은 `[공지]` 접두사 표시) |
| 대상 | 게시글 대상 (전체, 관리자, 교사, 학생, 지정) |
| 작성자 | 작성자 프로필 사진과 이름 |
| 조회 | 조회수 |
| 작성일 | 게시글 작성 날짜 |

## 게시글 작성

### 작성 절차

#### 1단계: 게시판 선택

게시글을 작성할 게시판 탭을 선택합니다.

#### 2단계: 글쓰기 시작

**글쓰기** 버튼을 클릭합니다.

> [!NOTE]
> 글쓰기 버튼은 해당 게시판에 쓰기 권한이 있는 사용자에게만 표시됩니다.

#### 3단계: 게시글 내용 입력

게시글 작성 화면에서 다음 정보를 입력합니다.

| 항목 | 설명 | 필수 |
|------|------|:----:|
| 제목 | 게시글 제목 | O |
| 본문 | 게시글 내용 (서식 있는 텍스트 에디터) | O |
| 첨부파일 | 문서, 이미지 등 파일 첨부 | - |
| 대상 선택 | 게시글을 공개할 대상 그룹 | - |

### 대상 선택

게시글의 공개 대상을 지정할 수 있습니다.

| 대상 | 설명 |
|------|------|
| 전체 | 모든 학교 구성원에게 공개 |
| 관리자 | 관리자에게만 공개 |
| 교사 | 교사에게만 공개 |
| 학생 | 학생에게만 공개 |
| 지정 | 특정 사용자를 직접 지정하여 공개 |

> [!TIP]
> 대상을 지정하지 않으면 기본적으로 "전체"로 설정됩니다. 특정 그룹에게만 공개하고 싶은 경우 적절한 대상을 선택하세요.

#### 4단계: 게시

내용 입력을 완료한 후 **게시** 버튼을 클릭하면 게시글이 등록됩니다.

## 게시글 조회 및 관리

### 게시글 조회

게시글 목록에서 제목을 클릭하면 게시글 상세 페이지로 이동합니다. 상세 페이지에서는 게시글의 전체 내용, 첨부파일, 댓글을 확인할 수 있습니다.

### 게시글 수정

1. 게시글 목록에서 수정할 게시글의 체크박스를 선택합니다.
2. **수정** 버튼이 표시됩니다 (한 건만 선택한 경우).
3. **수정** 버튼을 클릭하면 게시글 편집 페이지로 이동합니다.
4. 내용을 수정한 후 저장합니다.

> [!NOTE]
> 본인이 작성한 게시글만 수정할 수 있습니다. 관리자는 모든 게시글을 수정할 수 있습니다.

### 게시글 삭제

1. 게시글 목록에서 삭제할 게시글의 체크박스를 선택합니다 (여러 건 선택 가능).
2. **삭제** 버튼을 클릭합니다.
3. 확인 대화상자에서 **확인**을 클릭합니다.

> [!WARNING]
> 삭제된 게시글은 복구할 수 없습니다. 여러 건을 한 번에 삭제할 수 있으므로 선택 항목을 신중하게 확인하세요.

## 게시글 고정

중요한 게시글을 목록 상단에 고정하는 기능입니다. 고정된 게시글은 제목 앞에 `[공지]` 표시가 추가됩니다.

### 고정 방법

1. 게시글 목록에서 고정할 게시글의 체크박스를 선택합니다.
2. **고정** 버튼을 클릭합니다.
3. 선택한 게시글이 목록 상단에 고정됩니다.

### 고정 해제

1. 고정된 게시글의 체크박스를 선택합니다.
2. **고정해제** 버튼을 클릭합니다.
3. 고정이 해제되어 일반 게시글과 동일하게 표시됩니다.

> [!NOTE]
> 게시글 고정/해제는 관리자만 가능합니다. 일반 교사나 학생은 이 기능을 사용할 수 없습니다.

## 댓글

게시글에 댓글을 작성하여 의견을 나눌 수 있습니다.

### 댓글 작성

1. 게시글 상세 페이지 하단의 댓글 입력란에 내용을 작성합니다.
2. **등록** 버튼을 클릭합니다.
3. 댓글이 게시글 하단에 추가됩니다.

### 댓글 수정

1. 본인이 작성한 댓글의 **수정** 버튼을 클릭합니다.
2. 댓글 내용을 수정합니다.
3. **저장** 버튼을 클릭합니다.

### 댓글 삭제

1. 본인이 작성한 댓글의 **삭제** 버튼을 클릭합니다.
2. 확인 대화상자에서 **확인**을 클릭합니다.

## 게시판 권한

게시판별로 읽기 및 쓰기 권한을 설정할 수 있습니다.

### 권한 구분

| 권한 유형 | 설명 |
|-----------|------|
| 읽기 권한 | 게시판의 게시글을 조회할 수 있는 권한 |
| 쓰기 권한 | 게시판에 게시글을 작성할 수 있는 권한 |

### 역할별 권한

| 역할 | 기본 권한 |
|------|-----------|
| 관리자 | 모든 게시판 읽기/쓰기, 게시글 고정, 게시판 관리 |
| 교사 | 게시판 설정에 따라 읽기/쓰기 권한 부여 |
| 학생 | 게시판 설정에 따라 읽기/쓰기 권한 부여 |

> [!TIP]
> 게시판의 권한 설정은 관리자가 게시판 관리 화면에서 변경할 수 있습니다. 특정 게시판에 접근이 필요한 경우 관리자에게 요청하세요.

### 게시판 관리 (관리자)

관리자는 다음 게시판 관리 기능을 사용할 수 있습니다.

- **게시판 생성**: 새 게시판을 만들고 이름, 설명, 권한을 설정합니다.
- **게시판 수정**: 기존 게시판의 이름, 설명, 권한을 변경합니다.
- **기본 게시판 설정**: 기본 공지 게시판을 지정합니다.
