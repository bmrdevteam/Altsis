## 개요

Altsis의 학생 기록 기능은 학교에서 정의한 양식에 따라 학생 개인의 다양한 정보를 체계적으로 관리하는 시스템입니다. 출결, 활동 내역, 인적사항 등 학교 운영에 필요한 모든 기록을 디지털화하여 관리할 수 있습니다.

| 기능 | 관리자 | 교사 | 학생 |
|------|:------:|:----:|:----:|
| 기록 입력/수정 | O | O (담당 학생) | - |
| 기록 조회 (다른 학생) | O | O (담당 학생) | - |
| 본인 기록 조회 | - | - | O |
| 문서 출력 | O | O | O (본인) |

> [!NOTE]
> 기록 양식의 종류와 접근 권한은 학교 관리자가 설정합니다. 양식에 따라 교사와 관리자의 접근 범위가 다를 수 있습니다.

## 기록 유형

Altsis는 두 가지 유형의 기록을 지원합니다.

### 누적 기록 (Array)

시간이 지남에 따라 지속적으로 추가되는 기록입니다. 하나의 양식에 여러 건의 데이터를 계속 누적할 수 있습니다.

**예시:**
- 출결 기록 (매일 추가)
- 상담 기록 (상담할 때마다 추가)
- 활동 기록 (활동 참여 시마다 추가)
- 봉사활동 기록
- 독서 기록

**특징:**
- 기록이 목록(리스트) 형태로 표시됩니다.
- 새 기록을 추가하면 기존 기록은 그대로 유지되고 새 항목이 목록에 추가됩니다.
- 개별 기록을 선택하여 수정하거나 삭제할 수 있습니다.

### 단일 기록 (Object)

한 번 입력하거나, 하나의 값만 유지하는 기록입니다. 새로 입력하면 이전 값이 대체됩니다.

**예시:**
- 인적사항 (이름, 생년월일, 연락처 등)
- 건강검진 결과
- 학기별 종합 소견
- 자기소개서

**특징:**
- 기록이 단일 양식 형태로 표시됩니다.
- 값을 수정하면 기존 값이 새 값으로 대체됩니다.
- 항상 하나의 데이터만 유지됩니다.

## 기록 입력

### 기록 입력 절차

#### 1단계: 기록 페이지 접근

좌측 사이드바에서 **기록**을 클릭합니다. 교사와 관리자는 학생 기록 페이지가, 학생은 본인 기록 페이지가 표시됩니다. (학생 메뉴 이름도 **기록**이며 경로는 `/myArchive`입니다.)

> [!NOTE]
> 접근 가능한 기록 양식이 없는 경우 해당 메뉴 자체가 없거나, "조회 가능한 기록이 없습니다. 학교 관리자에게 문의해주세요." 메시지가 표시됩니다.

유형별 **컬럼 필터·검색**으로 필드를 좁혀 볼 수 있습니다. 교사 화면에서 고른 학생 목록은 학기 단위로 기억되어, 양식을 바꿔도 학생이 유지됩니다. 보기 유형은 양식별로 마지막 선택이 저장됩니다. **인쇄**는 현재 보기만 출력합니다. 상단 **Alter**로 학생별·동일 문구 기록 초안을 받은 뒤 확인하여 반영할 수 있습니다.

#### 2단계: 양식 선택

기록 페이지 상단에 사용 가능한 기록 양식 목록이 탭 형태로 표시됩니다. 입력하려는 기록에 해당하는 양식 탭을 선택합니다.

#### 3단계: 학생 선택 (교사/관리자)

교사 또는 관리자인 경우, 기록을 입력할 학생을 선택합니다. 담당 학생 목록에서 해당 학생을 클릭합니다.

#### 4단계: 필드별 데이터 입력

양식에 정의된 필드에 따라 데이터를 입력합니다.

**입력 가능한 필드 유형:**

| 유형 | 설명 | 입력 방법 |
|------|------|-----------|
| 텍스트 | 자유 형식의 텍스트 | 직접 타이핑 |
| 숫자 | 숫자 값 | 숫자 입력 |
| 선택형 | 미리 정의된 옵션 | 드롭다운에서 선택 |
| 파일 첨부 | 문서, 이미지 등 파일 | 파일 업로드 버튼 클릭 |

#### 5단계: 저장

모든 필드 입력을 완료한 후 **저장** 버튼을 클릭합니다.

- **누적 기록**: 새 기록이 목록에 추가됩니다.
- **단일 기록**: 기존 데이터가 입력한 데이터로 대체됩니다.

> [!TIP]
> 누적 기록의 경우, 기존 기록을 수정하려면 목록에서 해당 기록을 선택한 후 수정합니다. 새 기록을 추가하려면 추가 버튼을 사용합니다.

### 엑셀 내보내기

기록 데이터를 엑셀 파일로 내보낼 수 있습니다.

1. 기록 양식을 선택한 상태에서 **엑셀 내보내기** 버튼을 클릭합니다.
2. 내보낼 데이터 범위를 설정합니다.
3. 엑셀 파일이 다운로드됩니다.

## 기록 조회

### 교사의 기록 조회

교사는 담당 학생의 기록을 조회할 수 있습니다.

1. **기록** 페이지에서 조회할 기록 양식을 선택합니다.
2. 학생 목록에서 조회할 학생을 선택합니다.
3. 해당 학생의 기록이 표시됩니다.

**양식별 접근 권한:**

교사의 기록 접근 권한은 양식별로 설정됩니다.

| 권한 | 설명 |
|------|------|
| 조회만 가능 | 기록을 확인만 할 수 있고 수정할 수 없음 |
| 조회 및 수정 | 기록을 확인하고 수정할 수 있음 |
| 접근 불가 | 해당 양식에 접근할 수 없음 |

### 학생의 기록 조회 (myArchive)

학생은 본인의 기록만 조회할 수 있습니다.

1. 사이드바 **기록**을 클릭합니다. (`/myArchive`)
2. 조회 가능한 기록 양식 목록이 표시됩니다.
3. 양식을 선택하면 본인의 기록을 확인할 수 있습니다.

> [!NOTE]
> 학생에게 공개되는 기록 양식은 관리자가 설정합니다. 일부 기록은 교사와 관리자에게만 공개되고 학생에게는 비공개일 수 있습니다.

### 학생 검색을 통한 조회

특정 학생의 기록을 빠르게 찾으려면 학생 검색 기능을 활용합니다.

1. 상단 검색 바에서 학생 이름 또는 학번으로 검색합니다.
2. 검색 결과에서 학생을 선택합니다.
3. 학생 정보 페이지에서 **기록** 탭을 클릭합니다.
4. 해당 학생의 모든 접근 가능한 기록이 표시됩니다.
