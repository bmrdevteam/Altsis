# 결재 한 장 안내

보드 활동 양식의 승인·회람입니다. (수업 개설 승인과 다름)  
자세한 설명: [결재](approval.md)

| 제출 | → | 1차 승인 | → | 2차 … | → | 최종 승인 |
|------|---|----------|---|--------|---|-----------|
| 저장만 하면 시작 안 됨 | | 자기 차례만 처리 | | 승인해야 다음 | | 반려 시 즉시 종료 |

**지정** 단계는 비우면 건너뜀 · **고정**은 양식에서 정해짐 · **회람**은 보기만 · 설정에 **그룹**이 있으면 제출자가 불러와 결재선을 바꿀 수 있음

---

## 결재 보기

활동 → 양식 **기록** → 보기 메뉴 → **결재 보기**

| 칩 | 용도 |
|----|------|
| 내 결재 대기 | 지금 내가 할 일 (기본) |
| 진행 중 / 최종 승인 / 반려 | 상태별 |
| 내가 올린 건 | 내 기안 |
| 전체 | 권한 있는 모든 문서 |

정렬: 최근 제출순 · **오래 대기순**(밀린 건) · 단계순. **3일 이상** 대기는 강조.

행 클릭 → 내용 확인 → **승인 / 반려**. 이전·다음으로 연속 처리.  
체크 후 **일괄 승인 / 일괄 반려**(최대 50건, 반려 시 의견 필수).

---

## 인쇄 (활동 제목)

표시 항목 칩 **활동 제목**을 켜 두면 각 장 맨 위에 양식 이름이 붙습니다.  
여러 장이면 `결석계 (1/5)`. 브라우저 인쇄에서 **머리글/바닥글 없음**.

| 어디서 | 어떻게 | 무엇이 찍히나 |
|--------|--------|---------------|
| **결재 보기** | 문서 **체크** → 일괄 인쇄 아이콘 | 고른 문서만, 건당 1장 + 결재 진행 |
| **문서 보기** | ⋯ → 일괄 인쇄 | 검색·필터된 **전체** |
| 프린터 아이콘 | 지금 화면 | 보고 있는 한 건(또는 표) |

필요 없는 칸은 칩을 꺼서 숨깁니다. **응답자·제출일**도 머리글에서 뺄 수 있습니다.

## 알림 (앱 · 푸시 · 메일)

**학교(보드 탭) → 그 보드 관리 → 내 설정** 이 모두 켜져야 갑니다. 학교·보드는 기본 꺼짐.

| 유형 | 받는 사람 |
|------|-----------|
| 승인·회람 알림 | 지금 승인자, 회람자 |
| 승인 결과 | 제출자, (최종 때) 회람자 |

**푸시:** 설정 → 알림 → 유형 켜기 → **잠금화면 알림** 켜기 → 브라우저 허용 → 테스트 보내기.  
iPhone은 **홈 화면에 추가**한 뒤 그 아이콘으로 엽니다.

**메일:** 아카데미가 이메일 허용·SMTP·유형(승인·회람 / 결과)을 켠 뒤, 사용자는 설정에서 **이메일 알림**과 같은 유형을 켭니다. 프로필 또는 Google 메일로 갑니다. 테스트 보내기로 확인.

알림을 탭하면 그 문서가 열립니다.

---

## 한 줄 팁

- 할 일 카드 = 승인해야 함 / 내가 올린 건 = 승인 진행(읽기). 제목은 양식 이름 · 문서 제목(결재 보기와 같음).
- 한 번 승인·반려되면 기안자는 수정·삭제 잠김.  
- 알림 제목은 첫 단답(또는 양식 이름) + `· 승인 요청`.
