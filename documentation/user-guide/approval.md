# 결재 ⚪

보드 **활동** 양식에서 제출한 내용을 정해진 순서대로 검토하고, 승인하거나 반려하는 기능입니다. 결석계·예산 신청처럼 “누가 보고, 누가 허락했는지”가 필요할 때 씁니다.

수업 개설의 **강의계획서 승인**과는 다른 기능입니다.

한 장으로 빠르게 보려면 [결재 한 장 안내](approval-one-pager.md)를 인쇄하세요.

## 한눈에 보는 흐름

```
제출자가 양식 작성 → 제출
        ↓
1차 승인자가 검토 (승인 또는 반려)
        ↓ 승인하면
2차 승인자가 검토 …
        ↓ 마지막까지 승인하면
최종 승인 (회람자에게도 결과 알림)
```

한 단계에서 **반려**하면 다음 단계는 진행되지 않고 결재가 끝납니다. 동시에 여러 명이 승인하는 병렬 결재는 없습니다.

---

## 역할과 용어

| 역할 | 하는 일 | 할 수 없는 일 |
|------|---------|---------------|
| **기안자(제출자)** | 양식을 채우고 제출합니다. 「지정」 단계의 승인자를 고르거나 비울 수 있습니다. | 양식에서 「고정」으로 정해 둔 승인자는 바꾸지 못합니다. |
| **승인자** | 자기 차례일 때 내용을 보고 **승인** 또는 **반려**합니다. | 자기 차례가 아니면 승인·반려할 수 없습니다. |
| **회람자** | 제출된 문서를 **보기만** 합니다. 최종 결과 알림도 받습니다. | 승인·반려 권한이 없습니다. |
| **양식 작성자 / 보드 관리자** | 결재선·회람을 만들고, 기록(시트)에서 전체를 관리합니다. | — |

보드 멤버가 아니어도 **승인자나 회람자로 지정되면** 그 제출 건을 볼 수 있습니다.

| 화면 용어 | 의미 |
|-----------|------|
| **승인** (필드 유형) | 양식에 넣는 결재 칸 |
| **결재선** | 1차 → 2차 → … 검토 순서. 양식에 저장되며 복제·JSON 가져오기 때도 함께 갑니다 |
| **지정(제출 시)** | 제출자가 승인자를 고릅니다. 기본 승인자를 둘 수 있고, 비우면 **그 단계는 건너뜁니다** |
| **고정** | 양식에서 미리 정한 사람. 제출자가 바꾸지 못합니다 |
| **회람** | 결재 없이 문서를 볼 사람 |
| **결재 생략** | 남는 승인자가 없을 때 결재 없이 바로 최종 승인된 상태 (선택 항목이고 지정 단계를 모두 비운 경우) |
| **승인해야 함** | 지금 내가 처리할 차례 |
| **승인 진행** | 내가 제출해 두고 아직 결과가 나지 않은 건 |
| **의견** | 승인·반려 메모. 단건은 선택, **일괄 반려는 필수** |

단계 상태:

| 상태 | 뜻 |
|------|----|
| 대기 전 | 아직 자기 차례가 아님 |
| 진행 중 / 대기 | 지금 이 사람이 처리해야 함 |
| 승인 | 이 단계를 통과함 |
| 반려 | 이 단계에서 거절. 결재 전체 종료 |
| 최종 승인 | 모든 단계를 통과함 |

## 어디서 처리하나요

| 하고 싶은 일 | 가는 곳 |
|--------------|---------|
| 오늘 처리할 건 | 보드 → **활동** → 할 일, 또는 보드 목록 → **할 일** |
| 문서함처럼 모아 보기 | 활동 → 해당 양식 **기록** → 보기 메뉴 → **결재 보기** |
| 표에서 바로 처리 | 기록 시트의 승인 칸 |
| 알림으로 바로 열기 | 상단 알림 아이콘 또는 잠금화면 알림을 탭 |

활동 **할 일**의 노란 느낌 카드가 **승인해야 함**입니다. 내가 올린 건은 **승인 진행** 카드(예: `승인 진행 1/2`)로 보이며 읽기 전용입니다. 카드 제목은 양식 이름 뒤에 결재 보기와 같은 기준(「제목」칸, 없으면 첫 단답·장문·선택)으로 뽑은 문서 제목이 붙습니다.

## 결재 보기

승인 칸이 있는 양식의 기록에서만 메뉴에 **결재 보기**가 나타납니다.

### 열기

1. 보드 → **활동**에서 양식의 **기록(시트)** 을 엽니다.
2. 오른쪽 위 **보기** 아이콘을 누릅니다.
3. **결재 보기**를 선택합니다.

문서 보기·테이블 보기와 같이 양식마다 마지막 보기가 기억됩니다.

### 목록 읽기

표 열은 **상태 · 문서 제목 · 기안자 · 현재 단계 · 대기 · 제출일시**입니다.

- **문서 제목**은 양식에 이름이 `제목`인 칸이 있으면 그 값, 없으면 첫 단답/장문/선택 칸입니다. 둘 다 없으면 기안자 이름이 나옵니다.
- **대기**는 지금 단계가 시작된 뒤 며칠인지입니다. **3일 이상**이면 칸이 강조됩니다. 당일은 `오늘`입니다.
- 내 차례인 행은 배경이 조금 다릅니다. 행을 누르면 문서가 열립니다.

### 필터와 정렬

| 칩 | 보이는 내용 |
|----|-------------|
| **전체** | 볼 권한이 있는 모든 문서 |
| **내 결재 대기** | 지금 내가 처리할 건 |
| **진행 중** | 아직 끝나지 않은 결재 |
| **최종 승인** / **반려** | 끝난 문서 |
| **내가 올린 건** | 내가 기안한 문서 |

처음 열면 **내 결재 대기**입니다. 내 대기 건이 없고 다른 문서가 있으면 **전체**부터 엽니다.

정렬:

| 정렬 | 쓰임 |
|------|------|
| **최근 제출순** | 새로 올라온 건부터 (기본) |
| **오래 대기순** | 밀린 건부터 처리할 때 |
| **단계순** | 1차·2차처럼 단계가 빠른 것부터 |

검색·항목 필터는 기록 위쪽과 같습니다. 기안자·내용·제출일로 좁힌 뒤 결재 칩을 쓰면 됩니다.

### 한 건 처리

1. 행을 클릭합니다.
2. 제출 내용과 **결재 진행 상황**을 확인합니다.
3. 자기 차례이면 **의견**(선택)을 적고 **승인** 또는 **반려**합니다.
4. 푸터의 **이전 / 다음**으로 목록의 다른 문서로 넘깁니다.
5. 보드 관리자이거나 현재 승인자이면 **수정**으로 기록 화면을 열 수 있습니다.

자기 차례가 아니면 팝업 제목이 **승인 진행**이고 버튼은 없습니다.

### 일괄 승인·반려

1. 왼쪽 체크박스로 문서를 고릅니다. 맨 위 체크로 현재 목록을 모두 고를 수 있습니다.
2. 아래 막대에 `N건 선택`이 보입니다. 고른 것 중 내 차례가 아니면 `· 승인 가능 M건`이 붙습니다.
3. 의견을 적습니다. **일괄 반려는 의견이 필수**입니다.
4. **일괄 승인** 또는 **일괄 반려**를 누릅니다.

한 번에 **50건**까지입니다. 자기 차례가 아닌 건은 처리되지 않습니다.

## 일괄 인쇄와 활동 제목

인쇄는 **지금 화면에 보이는 영역만** 나갑니다. 필터 칩·체크박스·승인 버튼은 인쇄되지 않습니다.

### 활동 제목으로 머리글 맞추기

기록 위 **표시 항목** 칩의 첫 칸이 **활동 제목**입니다. 켜져 있으면(기본) 인쇄물 맨 위에 **양식 이름**이 굵게 붙습니다.

| 칩 | 인쇄에 들어가는 것 |
|----|-------------------|
| **활동 제목** (켜짐) | 양식 이름. 예: `결석계` |
| **활동 제목** (꺼짐) | 머리글 없음 |
| **응답자** | 기안자 이름(아이디) |
| **제출일** | 제출 일시 |
| 그 외 항목 칩 | 해당 칸을 본문에서 숨기거나 보이게 함 |

여러 건을 한 번에 찍으면 제목 옆에 쪽 번호가 붙습니다. 예: `결석계 (1/5)`.

깔끔하게 찍는 순서:

1. 양식 제목을 짧게 둡니다. (`2026학년도 1학기 생활 결석계`보다 `결석계`)
2. **활동 제목** 칩을 켜 둡니다.
3. 인쇄에 필요 없는 칸은 칩을 꺼서 숨깁니다.
4. 기안자·날짜가 본문에 이미 있으면 **응답자**·**제출일** 칩을 꺼 머리글을 단순하게 만듭니다.
5. 결재 보기에서는 문서를 **체크한 뒤** 일괄 인쇄합니다.

칩 상태는 양식마다 브라우저에 기억됩니다.

### 결재 보기에서 일괄 인쇄

1. **결재 보기**를 엽니다.
2. 찍을 문서만 체크합니다. (체크하지 않으면 「인쇄할 문서를 선택하세요.」)
3. 오른쪽 위 **일괄 인쇄** 아이콘을 누릅니다.
4. 30건을 넘으면 확인 창이 납니다.
5. 브라우저 인쇄에서 **여백 기본**, **머리글/바닥글 없음**(날짜·URL 숨김)을 고르면 양식 제목만 남습니다.

건마다 **한 장**으로 나뉩니다. 각 장에는 기안 내용과 **결재 진행 상황**이 들어갑니다.

### 문서 보기에서 한 장·여러 장

| 동작 | 위치 | 찍히는 것 |
|------|------|-----------|
| **인쇄** | 기록 오른쪽 위 프린터 아이콘 | 지금 보고 있는 한 건(또는 현재 표·요약) |
| **일괄 인쇄** | 문서 보기 → **더보기(⋯)** → 일괄 인쇄 | 검색·필터에 걸린 **모든** 응답. 체크 불필요 |

결재 보기의 일괄 인쇄는 **체크한 문서만**, 문서 보기의 일괄 인쇄는 **필터된 전체**입니다.

## 양식에 결재선 만들기

1. 보드 **활동**에서 양식을 만들거나 수정합니다.
2. 필드 유형을 **승인**으로 추가합니다.
3. **결재선**에서 단계를 만듭니다.

| 설정 | 설명 |
|------|------|
| **단계 이름** | 예: `담임 확인`, `교감 결재` |
| **지정 / 고정** | 제출자가 고를지, 양식에서 고정할지 |
| **사람** | 지정: 기본 승인자(없어도 됨). 고정: 반드시 한 명 |

**+ 결재 단계 추가**로 단계를 늘립니다. 승인 후보는 **보드 작성자 + 보드 관리자**입니다.

지정 단계를 비우면 그 단계만 건너뜁니다. 고정 단계는 건너뛸 수 없습니다. 고정 승인자를 비운 채 두면 제출 시 「고정 승인자가 설정되지 않았습니다.」가 납니다.

| 승인 칸 | 지정 단계를 모두 비우면 |
|---------|------------------------|
| **필수**이고 남는 승인자가 없음 | 「승인자를 한 명 이상 선택해주세요.」 |
| **필수**이지만 **고정 승인자**가 있음 | 제출 가능. 고정된 사람부터 시작 |
| **선택**이고 남는 승인자가 없음 | **결재 생략**(최종 승인) |

회람은 필드 유형 **회람**으로 따로 둡니다. 후보는 보드 멤버·작성자·관리자입니다. 지정은 제출자가 바꾸거나 비울 수 있고, 고정은 양식에서 정해집니다.

### 결재·회람 그룹

양식 **설정**에서 그룹을 만들 수 있습니다. 그룹마다 이름과 종류(결재자 / 회람 / 둘 다)를 둡니다. 결재자·둘 다는 단계 이름과 사람, 회람은 사람만 둡니다.

제출 화면의 **그룹 불러오기**로 고르면:

- **승인 칸:** 양식에 있던 고정·지정 단계가 모두 사라지고, 그룹의 단계 이름·사람으로 지정 단계가 다시 만들어집니다.
- **회람 칸:** 사람이 그룹 인원으로 바뀝니다.

그룹을 만들지 않으면 양식 결재선이 그대로입니다. 불러온 뒤에도 지정 단계의 사람은 바꾸거나 비울 수 있습니다.

---

## 제출하기

1. 활동에서 양식을 엽니다.
2. 내용을 채우고, 지정 단계의 승인자를 고르거나 **그룹 불러오기**로 결재선을 바꿉니다.
3. **제출**을 누릅니다.

**저장**(초안)만 하면 결재와 알림은 시작되지 않습니다.

| 상황 | 수정·삭제 |
|------|-----------|
| 초안 | 가능 |
| 제출했고 아직 아무도 승인·반려하지 않음 | 양식의 **응답 수정**이 켜져 있으면 가능 |
| 한 번이라도 승인·반려되었거나 결재 생략 | 잠김 |
| 복수 응답에서 **재사용** | 내용은 복사되고 결재는 처음부터 |

---

## 승인·반려하기

자기 차례일 때만 버튼이 열립니다.

| 내가 한 일 | 다음에 일어나는 일 |
|------------|-------------------|
| **승인**이고 다음 단계가 있음 | 다음 승인자에게 요청. 제출자에게 「○○ 승인됨, 다음 대기」 |
| **승인**이고 마지막 단계 | **최종 승인.** 제출자·회람자에게 결과 |
| **반려** | 결재 종료. 제출자·회람자에게 「반려됨」 |

알림 제목은 양식의 **첫 단답**을 앞에 붙입니다. 없으면 양식 제목입니다. 예: `감기로 하루 쉽니다 · 승인 요청`

## 알림 (앱 · 푸시 · 이메일)

결재 알림이 가려면 **학교 → 보드 → 개인**이 모두 켜져 있어야 합니다. 기본값은 학교·보드가 꺼져 있으므로, 처음 쓰는 학교는 관리자가 먼저 켭니다.

### 1단계. 학교에서 허용 (관리자)

**관리 → 학교 관리 → 보드**에서 다음을 켭니다. (기본 꺼짐)

| 항목 | 의미 |
|------|------|
| **승인·회람 알림** | 제출·다음 단계·회람 |
| **승인 결과 알림** | 중간 단계 승인, 최종 승인·반려 |

### 2단계. 그 보드에서 허용 (보드 관리자)

보드 **관리 → 알림 설정**에서 같은 두 항목을 켭니다. (기본 꺼짐)

| 항목 | 언제 가는지 |
|------|-------------|
| **승인·회람 알림** | 제출 직후 1차 승인자, 다음 단계 승인자, 회람자(1차 승인자와 겹치면 회람 알림은 생략) |
| **승인 결과 알림** | 중간 승인 시 제출자, 최종 승인·반려 시 제출자 + 회람자 |

### 3단계. 내가 받기 (모든 사용자)

**설정 → 알림**의 **Alt 폼**에서 켭니다. (기본 켜짐)

| 항목 | 설명 |
|------|------|
| **승인·회람 알림** | 요청·회람을 받음 |
| **승인 결과** | 승인·반려 결과를 받음 |

여기서 끈 유형은 **앱 안 · 잠금화면 푸시 · 이메일**이 모두 멈춥니다.

알림을 누르면 해당 제출 건이 열립니다.

### 잠금화면 푸시 (Web Push)

앱을 닫아 두어도 휴대폰·컴퓨터 알림창으로 받습니다.

1. **설정 → 알림**에서 받을 유형(승인·회람, 승인 결과)을 켭니다.
2. 아래 **잠금화면 알림**을 켭니다.
3. 브라우저가 권한을 물으면 **허용**합니다.
4. **테스트 보내기**로 이 기기에 오는지 확인합니다. 앱을 백그라운드로 두면 보기 쉽습니다.

| 상황 | 대처 |
|------|------|
| 「브라우저 알림 권한이 거부되었습니다」 | 주소창 자물쇠 → 알림을 허용한 뒤, 잠금화면 알림을 껐다 켭니다 |
| iPhone / iPad | Safari에서 사이트를 **홈 화면에 추가**한 뒤, 그 아이콘으로 열고 다시 켭니다 |
| 테스트가 「이 기기의 푸시 구독이 없습니다」 | 잠금화면 알림을 껐다 다시 켭니다 |
| 지원하지 않는 브라우저 | Chrome, Edge, Safari(홈 화면 추가)를 씁니다 |

같은 문서의 알림은 목록에서 하나로 갱신됩니다. 아이콘 뱃지는 미확인 알림과 안 읽은 채팅을 합칩니다.

### 이메일 알림

메일은 **아카데미가 허용하고 SMTP를 넣은 뒤**, 사용자가 수신을 켜야 갑니다. 새 게시글·채팅·일정 시작은 메일로 가지 않습니다. 결재의 **승인·회람 요청**과 **승인 결과**는 아카데미가 해당 유형을 켜 두면 메일로 갈 수 있습니다.

**관리자**

1. 소유자가 아카데미에서 **이메일 알림 허용**을 켭니다.
2. **관리 → 이메일 알림**에서 SMTP를 저장하고 테스트합니다.
3. 같은 화면에서 메일로 보낼 유형에 **승인·회람 요청**, **승인 결과**를 켭니다.

**사용자**

1. 프로필에 이메일을 넣거나 Google로 로그인합니다.
2. **설정 → 알림**에서 **이메일 알림**을 켭니다. (아카데미가 허용한 학교에만 이 칸이 보입니다.)
3. 위에서 **승인·회람 알림** / **승인 결과**도 켜 둡니다.
4. **테스트 보내기**로 메일함을 확인합니다.

받을 주소가 없으면 「프로필 이메일을 넣거나 Google로 로그인해 주세요.」가 납니다.

### 알림이 안 올 때

위에서부터 확인합니다.

1. 학교 보드 탭의 승인 알림이 켜져 있는가  
2. 그 보드 관리의 승인 알림이 켜져 있는가  
3. 내 설정의 Alt 폼 유형이 켜져 있는가  
4. 푸시: 잠금화면 알림 + 브라우저 허용  
5. 메일: 아카데미 허용 · SMTP · 유형 · 내 이메일 알림 · 프로필 주소  

앱이 열려 있을 때는 상단 **알림 종**과 알림음으로도 옵니다. 알림음은 **설정 → 알림 → 알림음**입니다.

## 예시

### 예시 1. 결석계 (지정 + 고정)

| 칸 | 유형 | 설정 |
|----|------|------|
| 제목 | 단답 | 알림·목록 제목. 예: `3/12 결석계` |
| 결석일 | 날짜 | 필수 |
| 사유 | 장문 | 필수 |
| 결재 | 승인 | 1차 `담임 확인` **지정**, 2차 `교감 결재` **고정** |
| 회람 | 회람 | 지정, 기본 없음 |

민수가 담임 이선생을 고르고 제출 → 이선생 할 일에 카드 → 승인하면 교감에게 요청 → 교감 승인 시 최종 승인.

담임 칸을 비우면 1차를 건너뛰고 바로 교감부터 시작합니다.

### 예시 2. 결재 보기에서 밀린 건 처리 후 인쇄

아침에 교감이 기록 → **결재 보기** → **내 결재 대기**를 엽니다. 정렬을 **오래 대기순**으로 바꿉니다. 3일 이상인 행이 강조됩니다.

5건을 체크하고 **일괄 승인**합니다. 보관용으로 같은 5건을 체크한 채 **일괄 인쇄**합니다. **활동 제목**이 켜져 있으면 각 장 맨 위가 `결석계 (1/5)`처럼 붙습니다. 브라우저 인쇄에서 머리글/바닥글을 끄면 주소가 나오지 않습니다.

### 예시 3. 푸시와 메일로 받기

이선생은 수업 중에도 결석계를 놓치지 않으려 합니다.

1. 학교·보드에서 승인·회람 알림이 켜져 있는지 관리자에게 확인합니다.
2. **설정 → 알림**에서 승인·회람 알림을 켭니다.
3. **잠금화면 알림**을 켜고 테스트 알림을 받습니다.
4. 아카데미가 메일을 쓰면 **이메일 알림**도 켜고 테스트 메일을 확인합니다.

민수가 제출하면 잠금화면에 `감기로 하루 쉽니다 · 승인 요청`이 뜨고, 탭하면 그 건이 열립니다.

## 자주 묻는 질문

**저장과 제출이 뭐가 다른가요?**  
저장은 초안입니다. 결재·알림·할 일에 넣지 않습니다.

**지정 단계를 비워도 되나요?**  
됩니다. 그 단계만 건너뜁니다. 남는 사람이 없고 칸이 필수이면 제출할 수 없습니다.

**반려된 건을 고쳐서 다시 올릴 수 있나요?**  
같은 건은 잠깁니다. **재사용**(복수 응답)하거나 새로 작성하세요.

**누가 내 결석계를 보나요?**  
본인, 결재선의 승인자, 회람자, 보드 작성자·관리자입니다.

**결재 보기 일괄 인쇄가 「문서를 선택하세요」라고 합니다.**  
체크박스로 찍을 건을 고른 뒤 아이콘을 누르세요. 문서 보기의 일괄 인쇄는 필터된 전체를 찍습니다.

**인쇄에 양식 이름이 안 나옵니다.**  
표시 항목의 **활동 제목** 칩을 켜세요.
