# 평가 ⚪

학생에 대한 평가를 입력하고 조회하는 기능을 안내합니다. 같은 교과목 수업 간의 평가 동기화 메커니즘도 설명합니다.

## 개요

Altsis의 평가 기능은 학교 관리자가 정의한 평가 양식에 따라 학생별로 평가 데이터를 입력하고 관리하는 시스템입니다. 평가는 수업 단위로 이루어지며, 같은 교과목의 수업들 사이에서 평가 정보가 자동으로 동기화됩니다.

| 기능 | 교사 | 학생 |
|------|:----:|:----:|
| 평가 입력 | O | - |
| 평가 수정 | O | - |
| 평가 조회 (전체 학생) | O | - |
| 본인 평가 결과 조회 | - | O |

> [!NOTE]
> 평가 입력 권한은 학기별 권한 설정에 의해 관리됩니다. 멘토(담당 교사) 또는 수업 개설자에게 평가 권한이 부여됩니다.

---

## 평가 구조

### 평가 양식

평가 양식은 학교 관리자가 학기별로 정의합니다. 양식에는 평가할 항목(필드)이 정의되어 있으며, 각 필드는 다양한 입력 유형을 가질 수 있습니다.

**평가 필드 유형:**

| 유형 | 설명 | 예시 |
|------|------|------|
| 텍스트 | 자유 서술 형식의 텍스트 입력 | 종합 평가 의견, 특기 사항 |
| 숫자 | 숫자 값 입력 | 점수, 출석 횟수 |
| 선택형 | 미리 정의된 옵션 중 선택 | 등급(A/B/C/D/F), 이수/미이수 |

### 평가 범위

평가 항목은 다음 두 가지 범위로 구분됩니다.

| 범위 | 설명 | 동기화 단위 |
|------|------|-------------|
| 학기 단위 | 해당 학기 내에서만 유효한 평가 | 같은 학기, 같은 교과목 수업 간 동기화 |
| 학년도 단위 | 학년도 전체에 걸친 평가 | 같은 학년도, 같은 교과목 수업 간 동기화 |

> [!IMPORTANT]
> 학년도 단위 평가 항목은 1학기와 2학기에 걸쳐 동기화됩니다. 한쪽에서 입력한 평가가 다른 학기의 같은 교과목 수업에도 반영됩니다.

## 평가 입력

### 평가 입력 절차

#### 1단계: 수업 선택

1. **수업** 페이지에서 평가를 입력할 수업을 선택합니다.
2. **담당 수업** 탭 또는 **개설 수업** 탭에서 해당 수업을 클릭합니다.

#### 2단계: 수강생 목록 확인

수업 상세 화면에서 수강생 목록이 표시됩니다. 각 학생 이름 옆에 평가 입력 상태가 함께 표시됩니다.

#### 3단계: 평가 항목 입력

1. 수강생 목록에서 평가할 학생을 선택합니다.
2. 평가 양식에 정의된 필드가 표시됩니다.
3. 각 필드에 평가 데이터를 입력합니다.

**입력 유형별 안내:**

- **텍스트 필드**: 평가 내용을 직접 입력합니다. 여러 줄 입력이 가능한 필드도 있습니다.
- **숫자 필드**: 숫자 값을 입력합니다. 최솟값/최댓값 제한이 있을 수 있습니다.
- **선택형 필드**: 드롭다운 메뉴에서 해당하는 옵션을 선택합니다.

#### 4단계: 저장

입력을 완료한 후 **저장** 버튼을 클릭하여 평가를 저장합니다.

> [!TIP]
> 평가 데이터는 저장 버튼을 클릭해야 반영됩니다. 페이지를 이동하기 전에 반드시 저장하세요.

### 평가 수정

이미 입력된 평가를 수정하려면 동일한 절차로 수업 상세 화면에 진입한 뒤, 해당 학생의 평가 필드 값을 수정하고 저장합니다.

> [!WARNING]
> 평가를 수정하면 동기화된 다른 수업의 평가 데이터도 함께 변경됩니다. 수정 전에 다른 수업 담당 교사와 확인하는 것을 권장합니다.

## 평가 동기화

### 동기화 메커니즘

Altsis는 같은 교과목으로 개설된 수업들 사이에서 평가 데이터를 자동으로 동기화합니다. 이를 통해 하나의 교과목에 여러 수업(분반)이 있더라도 일관된 평가가 가능합니다.

### 동기화 규칙

```
수업 A (국어, 1학기) ←→ 수업 B (국어, 1학기)    : 학기 단위 항목 동기화
수업 A (국어, 1학기) ←→ 수업 C (국어, 2학기)    : 학년도 단위 항목 동기화
수업 A (국어, 1학기) ←→ 수업 D (수학, 1학기)    : 동기화 없음 (교과목이 다름)
```

### 동기화 동작 방식

1. **교사 A**가 수업 A에서 학생 X의 평가를 입력합니다.
2. 학생 X가 같은 교과목의 수업 B에도 수강 중인 경우, 수업 B의 해당 평가 항목에도 동일한 값이 자동 반영됩니다.
3. **교사 B**가 수업 B에서 해당 값을 확인하면 이미 입력된 상태입니다.

> [!NOTE]
> 동기화는 같은 교과목 수업 간에만 이루어집니다. 서로 다른 교과목의 수업 간에는 동기화되지 않습니다.

### 동기화 충돌

두 명의 교사가 동시에 같은 학생의 같은 평가 항목을 수정하는 경우, 마지막으로 저장된 값이 적용됩니다.

> [!WARNING]
> 동일한 평가 항목을 여러 교사가 동시에 수정하지 않도록 주의하세요. 필요한 경우 교사 간 역할 분담을 명확히 하는 것이 좋습니다.

## 평가 조회

### 교사의 평가 조회

교사는 다음 방법으로 평가 데이터를 조회할 수 있습니다.

1. **수업별 조회**: 수업 상세 화면에서 수강생 전체의 평가 현황을 확인합니다.
2. **학생별 조회**: 학생 검색 기능을 통해 특정 학생의 전체 평가 내역을 확인합니다.

### 학생의 평가 결과 확인

학생은 본인의 평가 결과를 다음과 같이 확인할 수 있습니다.

1. **내 계정** 페이지로 이동합니다.
2. **수업** 탭에서 수강 중인 수업 목록을 확인합니다.
3. 각 수업을 클릭하면 본인에 대한 평가 결과가 표시됩니다.

> [!NOTE]
> 학생에게 공개되는 평가 항목은 관리자가 설정한 평가 양식의 공개 설정에 따릅니다. 일부 항목은 교사에게만 표시되고 학생에게는 공개되지 않을 수 있습니다.
