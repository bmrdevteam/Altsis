## 개요

Altsis의 수업 관리 기능은 교사와 학생 모두가 사용하는 핵심 기능입니다. 교사는 강의계획서를 작성하여 수업을 개설하고, 학생은 개설된 수업에 수강신청을 합니다.

| 기능 | 교사 | 학생 |
|------|:----:|:----:|
| 강의계획서 생성 | O | O (권한에 따라) |
| 수강신청 | O | O |
| 수업 초대 | O (멘토) | - |
| 수업 조회 | O | O |
| 시간표 보기 | O | O |

> [!NOTE]
> 강의계획서 생성 및 수강신청 권한은 학기별로 관리자가 설정합니다. 권한이 없는 경우 해당 하위 메뉴가 숨겨지거나 안내 메시지가 나타납니다. 수업·기록·문서는 **학기 등록**이 있을 때만 사이드바에 보입니다.

## 사이드바 메뉴

**수업**을 열면 시간표·수강 현황·개설·담당 탭이 있는 홈이 나옵니다. 권한이 있으면 하위에 바로가기가 붙습니다.

| 메뉴 | 경로 | 설명 |
|------|------|------|
| 수업 (홈) | `/courses` | 시간표, 수강 현황, 개설 수업, 담당 수업 |
| 수업 개설 | `/courses/design` | 강의계획서 작성 (개설 권한) |
| 수강 신청 | `/courses/enroll` | 개설된 수업 신청 (수강 권한) |
| 전체 목록 | `/courses/list` | 학기 수업 전체. 검색·필터는 수강신청과 같음 |
| 강의실 현황 | `/courses/classrooms` | 강의실·시간대 사용 현황 |

목록·탭에는 **조치 가능한 할 일**(승인 대기, 개설 미승인, 평가 등)만 뱃지로 셉니다. 사이드바 숫자와 맞춥니다.

## 강의계획서 생성

강의계획서는 수업의 기본 정보를 정의하는 문서입니다. 강의계획서를 작성하면 수업이 개설됩니다.

### 강의계획서 작성 단계

#### 1단계: 기본 정보 입력

좌측 **수업 개설**로 들어가거나, 수업 홈의 **개설 수업**에서 새 수업을 만듭니다.

다음 기본 정보를 입력합니다.

| 항목 | 설명 | 필수 |
|------|------|:----:|
| 학기 | 수업이 개설될 학기 (현재 활성 학기 기준) | O |
| 교과목 | 학기에 등록된 교과목 목록에서 선택 | O |
| 수업명 | 수업의 이름 (미입력 시 교과목명 사용) | - |
| 정원 | 수강 가능 최대 인원 (0이면 제한 없음) | - |

오른쪽 위 **불러오기**(붙여넣기 아이콘)로 기존 강의계획서를 복사할 수 있습니다.

- **내 강의계획서**: 내가 개설한 문서를 전 학년도에서 고릅니다.
- **학교 전체**: 현재 학교의 다른 사용자 문서도 볼 수 있습니다. 처음에는 **현재 학년도**만 보이고, 학년도·학기 필터로 범위를 바꿀 수 있습니다.
- 검색은 수업명, 개설자, 교과목을 대상으로 합니다.
- 복사되는 항목은 **교과목, 수업명, 강의 설명(상세)** 입니다. 멘토, 시간, 강의실은 복사되지 않습니다. 현재 학기 교과목 목록에 없는 교과목은 비워 둡니다.

#### 2단계: 수업 시간표 설정

수업이 진행되는 요일과 시간을 설정합니다.

1. **강의실 선택**: 학기에 등록된 강의실 목록에서 선택합니다.
2. **시간대 선택**: 시간표 양식에 정의된 시간대 중에서 수업 시간을 선택합니다.
3. **중복 확인**: 이미 다른 수업이 배정된 시간대는 자동으로 표시됩니다.

> [!WARNING]
> 같은 강의실, 같은 시간대에 다른 수업이 이미 배정되어 있으면 시간표 충돌이 발생합니다. 충돌이 표시되는 경우 다른 시간대를 선택하세요.

#### 3단계: 강의 설명 작성

강의계획서 양식에 따라 수업의 상세 설명을 작성합니다. 양식은 학교 관리자가 정의한 필드 구성을 따릅니다.

**입력 가능한 필드 유형:**
- 텍스트 입력 (한 줄 또는 여러 줄)
- 숫자 입력
- 선택형 (드롭다운)
- 서식 있는 텍스트 (리치 에디터)

#### 4단계: Alter로 초안·점검 (선택 사항)

상단 네비게이션 오른쪽 **Alter** 아이콘을 열면, 수업 개설/수정 화면에서는 강의계획서 초안·점검 Skill이 추천됩니다. 학교 지침을 반영한 초안은 **미리보기 후 확인**해야 반영됩니다. 자동으로 덮어쓰지 않습니다.

#### 5단계: 강의계획서 승인

강의계획서 작성이 완료되면 승인 절차를 거칩니다.

- **자동 승인**: 권한 설정에 따라 강의계획서가 즉시 승인될 수 있습니다.
- **관리자 승인**: 관리자가 강의계획서를 검토한 후 승인합니다.

승인된 강의계획서만 수강신청 목록에 노출됩니다.

## 수강신청

학생(또는 교사)이 개설된 수업에 등록하는 기능입니다.

### 수강신청 절차

#### 1단계: 수강신청 페이지 접근

좌측 사이드바 **수업** 아래 **수강 신청**을 클릭합니다.

> [!NOTE]
> 수강 신청 메뉴는 수강신청 권한이 부여된 사용자에게만 표시됩니다. 권한이 없으면 메뉴가 없거나 "수강신청 권한이 없습니다." 안내가 나타납니다.

#### 2단계: 개설 수업 목록 조회

수강 가능한 수업 목록이 표 형태로 표시됩니다. 각 수업의 다음 정보를 확인할 수 있습니다.

| 열 | 설명 |
|----|------|
| 교과목 | 수업의 교과목 분류 |
| 수업명 | 수업 이름 |
| 담당 교사 | 수업을 개설한 교사 |
| 시간 | 수업 시간표 |
| 수강/정원 | 현재 수강 인원 / 최대 정원 |
| 신청 | 수강신청 상태 버튼 |

#### 3단계: 수강신청 실행

수업 목록에서 원하는 수업의 **신청** 버튼을 클릭합니다.

**신청 버튼 상태:**

| 상태 | 색상 | 설명 |
|------|------|------|
| 신청 | 초록 | 수강신청 가능 -- 클릭하여 신청 |
| 취소 | 빨강 | 이미 수강 중 -- 클릭하여 취소 |
| 중복 | 보라 | 시간표 중복 -- 기존 수업과 시간이 겹침 |
| 마감 | 파랑 | 정원 초과 -- 수강신청 불가 |

#### 4단계: 수강신청 완료

신청 버튼을 클릭하면 요청이 서버로 전송되고, 처리 완료 시 알림이 표시됩니다. 수강신청이 완료되면 **수업** 페이지의 **수강 현황** 탭에서 수강 중인 수업을 확인할 수 있습니다.

### 대기번호 시스템

수강신청이 동시에 많이 몰리는 경우, 서버 안정성을 위해 실시간 대기열이 자동으로 활성화됩니다.

**대기열 동작 방식:**

1. 수강신청 요청을 보내면 Socket.io 기반의 실시간 대기열에 진입합니다.
2. 화면에 대기 팝업이 나타나며, 다음 정보가 실시간으로 표시됩니다.
   - **앞에 대기 중인 인원**: 본인보다 먼저 대기 중인 사용자 수
   - **뒤에 대기 중인 인원**: 본인보다 나중에 대기열에 진입한 사용자 수
   - **진행률 바**: 전체 대기열에서의 본인 위치를 시각적으로 표시
3. 차례가 되면 자동으로 수강신청이 처리됩니다.

> [!WARNING]
> 대기 중에 페이지를 새로고침하거나 재접속하면 대기 순번이 초기화되어 대기 시간이 더 길어질 수 있습니다. 대기 팝업이 표시되면 그대로 기다려 주세요.

## 수업 초대

멘토(교사)가 학생을 직접 수업에 초대하는 기능입니다. 수강신청을 거치지 않고 학생을 수업에 등록할 수 있습니다.

### 수업 초대 절차

1. **수업** 페이지에서 **담당 수업** 탭으로 이동합니다.
2. 학생을 초대할 수업을 선택합니다.
3. 수강생 관리 영역에서 **학생 초대** 기능을 사용합니다.
4. 초대할 학생을 검색하여 선택합니다.
5. 초대된 학생에게 알림이 발송되며, 수업에 자동 등록됩니다.

> [!NOTE]
> 수업 초대는 멘토(담당 교사) 권한이 있는 교사만 사용할 수 있습니다. 일반 교사는 본인이 개설한 수업에 대해서만 초대가 가능합니다.

### 일괄 초대

여러 학생을 한 번에 초대할 수 있는 일괄 초대 기능도 제공됩니다.

1. **담당 수업** 탭에서 해당 수업을 선택합니다.
2. **일괄 등록** 버튼을 클릭합니다.
3. 등록할 학생 목록을 선택합니다.
4. 확인을 클릭하면 선택된 학생이 모두 수업에 등록됩니다.

## 수업 조회

수업 관련 정보를 다양한 관점에서 조회할 수 있습니다.

### 수업 페이지 탭 구성

수업 페이지는 사용자 역할에 따라 다음과 같은 탭으로 구성됩니다.

#### 공통 탭 (교사, 학생)

| 탭 | 설명 |
|----|------|
| 시간표 | 현재 수강 중인 수업의 시간표를 표 형태로 표시 |
| 수강 현황 | 수강 중인 수업 목록과 상세 정보 조회 |
| 개설 수업 | 본인이 개설(작성)한 수업 목록 |

#### 교사 전용 탭

| 탭 | 설명 |
|----|------|
| 담당 수업 | 멘토로 배정된 수업 목록 및 수강생 관리 |

### 시간표 보기

**시간표** 탭에서는 현재 학기에 수강 중인 모든 수업의 시간표를 한눈에 확인할 수 있습니다.

- 학기에 설정된 시간표 양식에 따라 시간대가 표시됩니다.
- 각 셀을 클릭하면 해당 수업의 상세 정보를 확인할 수 있습니다.

### 수업 상세 정보

수업 목록에서 수업을 클릭하면 다음 상세 정보를 확인할 수 있습니다.

- **기본 정보**: 교과목, 수업명, 담당 교사, 강의실, 시간
- **강의계획서**: 수업 설명, 목표, 진행 방법 등
- **수강생 목록**: 수강 중인 학생 명단
- **평가 정보**: 수업에 연결된 평가 항목

> [!TIP]
> 수업 상세 정보 화면에서 인쇄 버튼을 클릭하면 강의계획서를 깔끔하게 출력할 수 있습니다. 인쇄 시 버튼 등 불필요한 UI 요소는 자동으로 숨겨집니다. 목록에서는 수강신청과 같은 방식으로 검색·컬럼 필터를 쓸 수 있습니다.

## 수업과 보드

담당 수업에 보드를 연결할 수 있습니다. 연결된 보드는 수업 상세의 **활동 / 문서 / 채팅**으로 열리며, 보드 목록에서 수업 보드를 눌러도 같은 화면으로 갑니다. 보드 복제로 양식·문서를 다음 학기에 재사용하기 쉽습니다. 자세한 내용은 [보드](boards.md)를 참고하세요.
