## 개요

Altsis의 알림 시스템은 학교 활동과 관련된 다양한 이벤트를 실시간으로 사용자에게 전달하는 기능입니다. 수업 초대, 일정 시작, 새 게시글 등의 이벤트가 발생하면 즉시 알림을 받을 수 있습니다.

**주요 특징:**
- 실시간 WebSocket 기반 알림 전달
- 다양한 알림 유형 지원
- 유형별 알림 ON/OFF 설정
- 개별 및 일괄 확인 기능
- 알림 발송(쪽지) 기능
- 알림음 설정

## 알림 유형

Altsis에서 지원하는 알림 유형은 다음과 같습니다.

### 수업 초대 (classInvitation)

멘토(교사)가 학생을 수업에 초대했을 때 발송되는 알림입니다.

| 항목 | 내용 |
|------|------|
| 발생 시점 | 교사가 수업에 학생을 초대할 때 |
| 수신 대상 | 초대받은 학생 |
| 관련 기능 | [수업 관리 - 수업 초대](courses.md#수업-초대) |

### 수업 취소 / 수업 초대 취소 (classCancellation)

수업 초대가 취소되었거나 수강이 해제되었을 때 발송됩니다. 설정 화면 라벨은 **수업 초대 취소**입니다.

| 항목 | 내용 |
|------|------|
| 발생 시점 | 수업 초대 취소 또는 수강 해제 |
| 수신 대상 | 해당 학생 |
| 관련 기능 | [수업 관리](courses.md) |

### 수업 승인 (classApproval)

강의계획서가 승인되었을 때 발송되는 알림입니다.

| 항목 | 내용 |
|------|------|
| 발생 시점 | 관리자가 강의계획서를 승인할 때 |
| 수신 대상 | 강의계획서 작성자 (수업 개설자) |
| 관련 기능 | [수업 관리 - 강의계획서 생성](courses.md#강의계획서-생성) |

### 수업 승인 취소 (classApprovalCancel)

승인된 강의계획서의 승인이 취소되었을 때 발송되는 알림입니다.

| 항목 | 내용 |
|------|------|
| 발생 시점 | 관리자가 강의계획서 승인을 철회할 때 |
| 수신 대상 | 강의계획서 작성자 (수업 개설자) |
| 관련 기능 | [수업 관리 - 강의계획서 생성](courses.md#강의계획서-생성) |

### 일정 시작 (scheduleStart)

캘린더에 등록된 일정의 시작 시간이 되면 발송되는 알림입니다. 일정에서 **일정 시작 알림**을 켠 경우에만 예약됩니다(기본 OFF).

| 항목 | 내용 |
|------|------|
| 발생 시점 | 이벤트 시작 시각 (일정에서 일정 시작 알림 ON) |
| 수신 대상 | 일정 등록자. 학교 일정에서 **학교 전체 알림**을 켠 경우 해당 학교 구성원도 후보에 포함. 각자 [알림 설정](#알림-설정)의 「일정 시작」이 OFF면 받지 않음 |
| 관련 기능 | [캘린더 - 이벤트 알림 설정](calendar.md#이벤트-알림-설정) |

### 새 게시글 (newPost)

구독·접근 가능한 **보드**에 새 게시글이 등록되었을 때 발송됩니다.

| 항목 | 내용 |
|------|------|
| 발생 시점 | 보드에 새 게시글이 등록될 때 |
| 수신 대상 | 해당 보드에 접근 권한이 있는 사용자 |
| 관련 기능 | [보드](boards.md) |

### 보드 초대 (boardInvitation)

보드에 초대되었을 때 발송됩니다.

### 승인 요청 / 승인 결과 (altFormApprovalRequest, altFormApprovalResult)

활동(양식) 결재에서 요청·회람이 오거나 승인·반려 결과가 났을 때 발송됩니다. 학교·보드에서 해당 알림을 켜 두어야 하며, 잠금화면 푸시와 이메일은 [설정 → 알림](settings.md)에서 받습니다.

| 항목 | 내용 |
|------|------|
| 발생 시점 | 제출·다음 단계(요청), 회람, 단계·최종 승인/반려(결과) |
| 수신 대상 | 현재 승인자·회람자(요청), 제출자·회람자(결과) |
| 관련 기능 | [결재](approval.md#알림-앱--푸시--이메일) |

### 채팅 메시지 (chatMessage)

새 채팅 메시지입니다. **잠금화면 알림**이 켜져 있을 때 잠금화면에 표시됩니다. (설정 설명: 「새 채팅 메시지가 오면 잠금화면 알림을 받습니다」)

### 직접 메시지 (쪽지)

알림 페이지에서 보내는 쪽지(알림 발송)를 받았을 때입니다.

### 리마인더 (reminder)

사용자가 설정한 리마인더 시간에 발송되는 알림입니다. 일정·독립 리마인더에서 켠 경우에만 발송됩니다.

| 항목 | 내용 |
|------|------|
| 발생 시점 | 사용자가 설정한 리마인더 시간 |
| 수신 대상 | 리마인더를 설정한 사용자(일정 등록자). 학교 일정에서 **학교 전체 알림**을 켠 경우 해당 학교 구성원도 후보에 포함. 각자 「리마인더」 설정이 OFF면 받지 않음 |
| 관련 기능 | [캘린더](calendar.md) |

## 알림 수신

### 실시간 알림

Altsis는 WebSocket 기반의 실시간 알림 시스템을 사용합니다. 브라우저가 열려 있는 동안 새 알림이 발생하면 즉시 수신됩니다.

**알림 수신 표시:**

1. **네비게이션 바 아이콘**: 상단 네비게이션 바의 알림 아이콘에 읽지 않은 알림 수가 배지로 표시됩니다.
2. **알림음**: 앱이 열려 있을 때 설정에 따라 알림음이 재생됩니다.
3. **유형별 수신 설정**: [설정 > 알림]에서 수업·일정·보드·Alt 폼 등 유형별로 받을지 끌 수 있습니다. 끄면 앱 안 알림과 잠금화면 알림이 함께 꺼집니다.
4. **잠금화면 알림 (Web Push, 옵트인)**: [설정 > 알림]에서 「잠금화면 알림」을 켠 경우, 위에서 허용한 유형(채팅 메시지 포함)이 앱 안과 동일하게 잠금화면에도 표시됩니다. 같은 대상(같은 채팅방·같은 게시글 등)의 알림은 목록에서 하나로 갱신되며, 홈 화면 앱 아이콘 뱃지에는 미확인 알림·미읽음 채팅 합계가 표시됩니다. 알림을 탭하면 관련 페이지(게시글, 수업, 채팅방 등)로 이동합니다. iOS는 홈 화면에 추가한 뒤 사용할 수 있습니다.

### 알림 패널

네비게이션 바의 알림 아이콘을 클릭하면 알림 패널이 열리며, 최근 알림 목록을 빠르게 확인할 수 있습니다.

## 알림 확인 및 관리

### 알림 페이지

알림 페이지에서 모든 알림을 체계적으로 관리할 수 있습니다. 알림 페이지는 다음 두 가지 탭으로 구성됩니다.

| 탭 | 설명 |
|----|------|
| 받은 알림 (Inbox) | 다른 사용자 또는 시스템으로부터 받은 알림 목록 |
| 보낸 알림 (Sent) | 내가 발송한 알림(쪽지) 목록 |

### 알림 확인 (개별)

1. 알림 목록에서 확인할 알림을 클릭합니다.
2. 알림 상세 팝업이 열리며 내용을 확인할 수 있습니다.
3. 알림을 열면 자동으로 읽음 처리됩니다.

### 알림 확인 (일괄)

여러 알림을 한 번에 읽음 처리할 수 있습니다.

1. 알림 목록에서 확인할 알림의 체크박스를 선택합니다.
2. **일괄 확인** 버튼을 클릭합니다.
3. 선택한 모든 알림이 읽음 처리됩니다.

### 알림 상세 정보

알림을 클릭하면 다음 정보를 확인할 수 있습니다.

| 항목 | 설명 |
|------|------|
| 발신자 | 알림을 보낸 사용자 또는 시스템 |
| 제목 | 알림 제목 |
| 내용 | 알림 상세 내용 |
| 날짜 | 알림 발송 시간 |
| 유형 | 알림 분류 (수업 초대, 게시글 등) |
| 관련 항목 | 알림과 연결된 수업, 게시글 등으로 이동하는 링크 |

### 자동 삭제

일부 알림은 확인 시 자동으로 삭제되도록 설정될 수 있습니다. 이 기능은 알림 종류에 따라 시스템에서 자동으로 관리됩니다.

## 알림 발송

다른 사용자에게 직접 알림(쪽지)을 보낼 수 있습니다.

### 알림 발송 절차

1. 알림 페이지에서 **새 알림** 또는 **쪽지 보내기** 버튼을 클릭합니다.
2. 수신자를 검색하여 선택합니다 (여러 명 선택 가능).
3. 알림 제목과 내용을 입력합니다.
4. **발송** 버튼을 클릭합니다.

### 수신자 선택

| 방법 | 설명 |
|------|------|
| 개별 선택 | 사용자 이름 또는 아이디로 검색하여 개별 선택 |
| 다중 선택 | 여러 사용자를 한 번에 선택하여 동일한 알림 발송 |

### 알림 답장

받은 알림에 대해 답장을 보낼 수 있습니다.

1. 알림 상세 팝업에서 **답장** 버튼을 클릭합니다.
2. 답장 내용을 입력합니다.
3. **발송** 버튼을 클릭합니다.

> [!TIP]
> 보낸 알림은 **보낸 알림** 탭에서 확인할 수 있습니다. 수신자 목록과 발송 시간이 함께 표시됩니다.

## 알림 설정

알림 유형별로 수신 여부와 알림음을 설정할 수 있습니다.

### 알림 설정 접근

1. [설정](settings.md) 페이지로 이동합니다.
2. 좌측 메뉴에서 **알림** 섹션을 선택합니다.

### 유형별 알림 ON/OFF

각 알림 유형의 수신 여부를 개별적으로 설정할 수 있습니다.

| 설정 항목 | 설명 | 기본값 |
|-----------|------|:------:|
| 수업 초대 | 수업 초대 시 알림 수신 | ON |
| 수업 취소 | 수업 취소 시 알림 수신 | ON |
| 수업 승인 | 강의계획서 승인 시 알림 수신 | ON |
| 수업 승인 취소 | 강의계획서 승인 취소 시 알림 수신 | ON |
| 일정 시작 | 캘린더 일정 시작 전 알림 수신 | ON |
| 새 게시글 | 보드 새 게시글 알림 수신 | ON |
| 직접 메시지 | 쪽지 수신 시 알림 수신 | ON |
| 리마인더 | 리마인더 알림 수신 | ON |

### 알림음 설정

알림 수신 시 재생되는 알림음을 설정할 수 있습니다.

| 설정 항목 | 설명 |
|-----------|------|
| 알림음 ON/OFF | 알림 수신 시 소리 재생 여부 |

> [!TIP]
> 수업 중이거나 집중이 필요한 시간에는 알림음을 OFF로 설정하면 방해받지 않고 학습할 수 있습니다. 알림은 읽지 않은 상태로 유지되므로 나중에 확인할 수 있습니다.

### 이벤트 기본 알림 시간

캘린더 이벤트의 기본 알림 시간을 설정할 수 있습니다. 새 이벤트를 생성할 때 이 기본값이 자동으로 적용됩니다.
