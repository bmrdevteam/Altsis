## 개요

Altsis의 **일정**은 개인 일정과 학교 일정을 한 화면에서 봅니다. 직접 입력한 일정뿐 아니라, 수강 중인 수업과 강의계획서 일정이 자동으로 동기화됩니다. 학기 등록이 없어도 일정 메뉴는 보입니다.

**주요 특징:**
- 월별, 주별, 일별 세 가지 보기 모드 지원
- 수업 및 강의계획서 일정 자동 동기화
- 종일 이벤트, 시간 지정 이벤트, 다일(multi-day) 이벤트 지원
- 캘린더별 표시/숨김 설정
- 개인 캘린더 추가

## 캘린더 보기

### 월별 보기

가장 기본적인 보기 모드입니다. 한 달 전체의 일정을 한눈에 파악할 수 있습니다.

**특징:**
- 달력 형태로 한 달의 일정 표시
- 각 날짜 셀에 해당 날짜의 이벤트 목록 표시
- 다일 이벤트는 여러 날에 걸쳐 연속 바(bar) 형태로 표시
- 날짜 클릭 시 해당 날짜의 일별 보기로 전환 가능

**다일 이벤트 표시:**

다일 이벤트는 시작일부터 종료일까지 연속된 바로 표시됩니다. 주(week) 경계를 넘는 이벤트는 각 주에 걸쳐 분리되어 표시되며, 레인(lane) 기반 레이아웃으로 이벤트가 겹치지 않도록 배치됩니다.

### 주별 보기

한 주 단위로 일정을 상세하게 확인할 수 있는 보기 모드입니다.

**특징:**
- 7일간의 일정을 시간축과 함께 표시
- 시간 지정 이벤트가 해당 시간대에 정확히 배치
- 종일 이벤트는 상단 영역에 표시
- 현재 시간이 실시간 표시선으로 표시

### 일별 보기

특정 하루의 일정을 가장 상세하게 확인할 수 있는 보기 모드입니다.

**특징:**
- 하루 24시간의 시간축에 이벤트 배치
- 시간 지정 이벤트의 상세 정보 확인 가능
- 종일 이벤트는 상단에 표시
- 현재 시간 표시선 제공

### 보기 모드 전환

캘린더 상단의 보기 전환 버튼을 클릭하여 월별/주별/일별 보기를 자유롭게 전환할 수 있습니다. 또한 좌우 화살표 버튼으로 이전/다음 기간으로 이동하고, **오늘** 버튼으로 현재 날짜로 즉시 이동할 수 있습니다.

## 이벤트 소스

캘린더에 표시되는 이벤트는 다양한 소스에서 가져옵니다. 각 소스별로 고유한 색상이 부여되어 시각적으로 구분됩니다.

### 직접 입력 이벤트 (manual)

사용자가 직접 생성한 개인 일정입니다.

- 자유롭게 추가, 수정, 삭제 가능
- 종일 이벤트, 시간 지정 이벤트, 다일 이벤트 모두 지원
- 개인 캘린더에 속함

### 수강 중인 수업 일정 (enrollment)

수강 신청한 수업의 일정이 자동으로 캘린더에 동기화됩니다.

- 수강신청 시 자동으로 캘린더에 추가
- 수강 취소 시 자동으로 캘린더에서 제거
- 수업 시간표에 따라 반복 일정으로 표시
- 읽기 전용 -- 캘린더에서 직접 수정 불가

### 강의계획서 일정 (syllabus)

강의계획서에 정의된 수업 일정이 동기화됩니다.

- 수업 개설자가 강의계획서에 입력한 일정이 반영
- 강의계획서 수정 시 자동으로 업데이트
- 읽기 전용

### 메모 일정 (memo)

메모에서 생성된 일정이 캘린더에 동기화됩니다.

- 메모에서 일정을 생성하면 캘린더에 자동 추가
- 메모와 캘린더 이벤트가 양방향으로 연결

> [!TIP]
> 이벤트를 클릭하면 이벤트 팝업이 열리며, 소스 유형을 확인할 수 있습니다. 자동 동기화된 이벤트는 원본 소스(수업, 강의계획서 등)로 이동하는 링크가 제공됩니다.

## 이벤트 관리

### 이벤트 추가

#### 방법 1: 빈 영역 클릭

1. 캘린더에서 빈 날짜 또는 시간대를 클릭합니다.
2. 이벤트 생성 팝업이 열립니다.
3. 이벤트 정보를 입력하고 저장합니다.

#### 방법 2: 이벤트 생성 버튼

1. 캘린더 상단의 이벤트 추가 버튼을 클릭합니다.
2. 이벤트 생성 팝업이 열립니다.
3. 이벤트 정보를 입력하고 저장합니다.

### 이벤트 생성 팝업

이벤트 생성 팝업에서 다음 정보를 입력합니다.

| 항목 | 설명 | 필수 |
|------|------|:----:|
| 제목 | 이벤트 이름 | O |
| 캘린더 | 이벤트가 속할 캘린더 선택 | O |
| 날짜 | 시작일 및 종료일 | O |
| 시간 | 시작 시간 및 종료 시간 (종일 이벤트가 아닌 경우) | - |
| 종일 이벤트 | 하루 종일 진행되는 이벤트 여부 | - |
| 설명 | 이벤트에 대한 상세 설명 | - |
| 알림 | 이벤트 시작 전 알림 설정 | - |

### 종일 이벤트

하루 종일 진행되는 이벤트입니다.

- 이벤트 생성 시 **종일** 옵션을 활성화합니다.
- 종일 이벤트는 캘린더 상단 영역에 표시됩니다.
- 시간 지정 이벤트와 시각적으로 구분됩니다.

### 다일(multi-day) 이벤트

여러 날에 걸쳐 진행되는 이벤트입니다.

- 시작일과 종료일을 다른 날짜로 설정합니다.
- 캘린더에서 시작일부터 종료일까지 연속 바로 표시됩니다.
- 각 날짜에서의 순서(sequence)와 전체 일수(duration)가 자동으로 계산됩니다.

### 이벤트 수정

1. 캘린더에서 수정할 이벤트를 클릭합니다.
2. 이벤트 상세 팝업이 열립니다.
3. **수정** 버튼을 클릭합니다.
4. 이벤트 정보를 수정하고 저장합니다.

> [!NOTE]
> 자동 동기화된 이벤트(수업, 강의계획서, 메모)는 캘린더에서 직접 수정할 수 없습니다. 원본 소스에서 수정해야 합니다.
>
> 학교 캘린더(기본 학교 캘린더 및 관리자가 만든 학교 캘린더)의 일정은 `owner`/`admin`/`manager`만 추가·수정·삭제할 수 있습니다. 일반 사용자는 조회만 가능합니다.

### 이벤트 삭제

1. 캘린더에서 삭제할 이벤트를 클릭합니다.
2. 이벤트 상세 팝업에서 **삭제** 버튼을 클릭합니다.
3. 삭제 확인 대화상자에서 **확인**을 클릭합니다.

> [!WARNING]
> 삭제된 이벤트는 복구할 수 없습니다. 신중하게 삭제하세요.

## 캘린더 설정

### 캘린더별 표시/숨김

여러 캘린더 소스를 선택적으로 표시하거나 숨길 수 있습니다.

1. 캘린더 설정 버튼을 클릭합니다.
2. 캘린더 목록이 표시됩니다.
3. 각 캘린더 옆의 토글을 클릭하여 표시/숨김을 전환합니다.

**설정 저장:**

캘린더 표시/숨김 설정은 브라우저의 localStorage에 저장되어, 같은 브라우저에서 다시 접속하면 이전 설정이 유지됩니다.

> [!NOTE]
> 캘린더 표시/숨김 설정은 기기 및 브라우저별로 저장됩니다. 다른 기기나 브라우저에서 접속하면 기본 설정이 적용됩니다.

### 개인 캘린더 추가

기본 캘린더 외에 개인 캘린더를 추가하여 일정을 분류할 수 있습니다.

1. 캘린더 설정에서 **캘린더 추가** 버튼을 클릭합니다.
2. 캘린더 이름과 색상을 설정합니다.
3. 새 캘린더가 목록에 추가됩니다.

추가한 개인 캘린더는 이벤트 생성 시 소속 캘린더로 선택할 수 있습니다.

### 본인만 보기

사용자 캘린더를 추가하거나 수정할 때 **본인만 보기**를 켜면, 다른 사람이 해당 사용자를 조회할 때 그 캘린더와 일정이 보이지 않습니다. 본인 화면에서는 그대로 표시됩니다.

학교 캘린더에는 이 옵션을 쓸 수 없습니다. 기본 「개인 캘린더」(직접 만든 사용자 캘린더가 아닌 시스템 카테고리)는 타인 조회 시에도 보입니다.

### 이벤트 알림 설정

시간 지정 일정에서 알림을 **옵트인**으로 켤 수 있습니다(기본 OFF).

- **일정 시작 알림**: 일정 시작 시각에 알림을 받습니다.
- **리마인더**: 시작 N분 전에 알림을 받습니다. 기본 분 값은 [설정](settings.md)에서 변경할 수 있습니다.
- **학교 전체 알림** (학교 캘린더만): 켜면 학교 구성원도 일정 시작·리마인더 수신 후보에 포함됩니다. 각자 [알림](notifications.md) 설정의 「일정 시작」「리마인더」가 OFF면 받지 않습니다.
- 종일 일정에는 일정 시작·리마인더를 예약하지 않습니다.
