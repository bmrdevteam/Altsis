# 문서 ⚪

사이드바 **문서** 메뉴는 학교 관리자가 만든 **출력 양식**으로 학생 기록·평가를 모아 미리보고 인쇄하는 화면입니다. 보드 안의 「문서」 탭(게시글)과는 다릅니다.

## 개요

| 항목 | 내용 |
|------|------|
| 메뉴 | 좌측 사이드바 **문서** (`/docs`) |
| 언제 보이나 | 현재 학기에 등록되어 있을 때 |
| 양식 | 관리자가 [양식](../admin-guide/form-management.md)에서 만든 **출력(print)** 유형 |
| 교사 | 학생을 골라 해당 학생의 기록·평가가 채워진 문서를 봄 |
| 학생 | 본인 문서만 조회 |

보드에서 글을 쓰거나 `{{#sheet}}` 머지 문서를 보는 방법은 [보드](boards.md)를 참고하세요.

---

## 문서 페이지 열기

1. 좌측 사이드바에서 **문서**를 클릭합니다.
2. 사용 가능한 출력 양식이 있으면 목록이 나타납니다.
3. 양식이 없으면 학교 관리자에게 출력 양식 생성을 요청하세요.

---

## 양식 선택

여러 출력 양식이 있으면 화면에서 양식을 고릅니다. 선택한 양식은 학교별로 브라우저에 기억되어, 다음에 같은 학교에서 열면 이전 선택이 유지됩니다.

---

## 학생 선택

교사·관리자는 이름·학년·담임 등으로 학생을 검색해 고릅니다. 최근 검색한 학생을 다시 고를 수 있습니다.

학생이 바뀌면 같은 양식에 그 학생의 기록·평가가 채워집니다.

> [!NOTE]
> 학생 역할로 로그인한 경우 다른 학생을 고를 수 없고, 본인 문서만 보입니다.

---

## 미리보기와 인쇄

1. 양식과 학생을 고르면 미리보기가 표시됩니다.
2. **인쇄**로 브라우저 인쇄 대화상자를 엽니다.
3. PDF로 저장하려면 프린터에서 「PDF로 저장」을 선택하세요.

> [!TIP]
> 여백을 「없음」 또는 「최소」로 두면 양식이 잘리지 않고 나옵니다.

---

## Alter 문서 점검

상단 네비게이션의 **Alter**에서 문서 점검 Skill을 쓰면, 현재 미리보기에 올라온 양식·학생 데이터를 기준으로 지침 대비 점검을 받을 수 있습니다. 결과는 미리보기 후 확인해야 반영됩니다. 자세한 내용은 [채팅 — Alter](chat.md#alter-전역-ai-어시스턴트)를 참고하세요.
