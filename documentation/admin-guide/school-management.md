# 학교 관리 🔴

학교는 아카데미 내에서 운영되는 독립적인 교육 기관 단위입니다. 하나의 아카데미에 여러 학교를 생성할 수 있으며, 각 학교는 독립된 학기, 사용자 등록, 기록 양식을 갖습니다. 이 문서에서는 학교의 생성, 기본 설정, 사용자 등록, 기록 양식 설정 방법을 설명합니다.

## 학교 생성

> **필요 권한**: 🔴 Admin

아카데미 내에 새로운 학교를 추가합니다.

### 학교 데이터 구조

| 필드 | 설명 | 필수 | 비고 |
|------|------|:----:|------|
| `schoolId` | 학교 고유 ID | O | 영문, 숫자로 구성. 아카데미 내에서 유일 |
| `schoolName` | 학교 이름 | O | 한글, 영문, 숫자 사용 가능 |
| `formArchive` | 기록 양식 | - | 생성 후 설정 |
| `links` | 외부 링크 목록 | - | 학교 관련 외부 URL |

### 생성 절차

1. Admin 계정으로 로그인합니다.
2. **관리자** > **학교 관리** 페이지로 이동합니다.
3. **학교 생성** 버튼을 클릭합니다.
4. 필수 정보를 입력합니다.
   - `schoolId`: 학교 고유 식별자 (예: `bmr-middle`)
   - `schoolName`: 학교 표시 이름 (예: `별무리중학교`)
5. **생성** 버튼을 클릭합니다.

> [!WARNING]
> `schoolId`는 아카데미 내에서 유일해야 하며, 생성 후 변경할 수 없습니다. 동일한 ID로 학교를 다시 생성할 수 없으므로 신중하게 설정하세요.

## 학교 상세 탭

**관리** → 학교 목록에서 학교를 열면 역할에 따라 다음 탭이 있습니다.

| 탭 | 설명 |
|----|------|
| 학기 | 학기 생성·복사·활성화 ([학기 관리](season-management.md)) |
| 기록 | 기록 양식 (`formArchive`) |
| 사용자 | 이 학교 소속 사용자 |
| 알림 | 학교 알림 |
| 채팅 | 이 학교 채팅 on/off (아카데미에서 채팅이 허용된 경우) |
| 보드 | 보드 on/off, 생성 권한(교사/학생), 보드 관리 |
| AI | 학교 AI 켜기, 역할 권한, 공식 라이브러리 스킬 연결. 일일 Alt 한도 |
| 링크 | 사이드바에 보일 외부 링크 |
| 목표 | 목표 위젯 항목·숫자 ([목표](../user-guide/goals.md)) |
| 대시보드 | 기간·범위 필터로 트래픽·AI·학기 지표 비교 |
| 삭제 | admin만. 학교 삭제 |

기능 ON/OFF(채팅·보드·AI)는 **관리자 → 학교 관리**의 해당 탭입니다. 아카데미 플랜(SHIFT/CTRL)이 꺼져 있으면 탭 자체가 숨겨질 수 있습니다.

## 학교 AI

> **필요 권한**: 🔵 Manager (학기 on/off는 학기 **AI 설정** 탭)

학교 **AI** 탭에서 Alter를 켭니다. 역할 권한·스킬 연결은 여기이고, 학기 탭은 해당 학기 켜기/끄기만 합니다. 지침·학습정보 본문은 **Alter 라이브러리**(`/:academyId/:schoolId/library`, Alter 패널 헤더)에서 만듭니다.

### 라이브러리

항목 종류는 두 가지입니다.

| 종류 | 설명 |
|------|------|
| 지침 (`instruction`) | 작성·점검 기준. 관리자만 학교 공식으로 작성합니다 |
| 학습정보 (`learning`) | 참고 자료. 관리자(학교 공식) 또는 교사(내 자료·공유)가 에디터·파일로 올립니다 |

학교 공식 항목에 **스킬 태그**를 달거나 AI 탭에서 체크하면 해당 Skill 준비 칸에 붙습니다. 교사 공유·내 자료는 스킬 체크 대상이 아니며, 교사 Alter 챗 검색에만 합쳐집니다.

### 역할 권한 · 한도

교사·학생 토글로 Alter 사용 여부를 정합니다. 1인당 일일 Alt 한도와 미성년 보호 이행사항은 같은 탭과 [아카데미 관리 — AI](academy-management.md#ai-설정)를 따릅니다.

## 학교 기본 정보 설정

> **필요 권한**: 🔴 Admin

학교 생성 후 기본 정보를 변경하거나 외부 링크를 관리할 수 있습니다.

### 기본 정보 탭

학교 목록에서 학교를 선택하면 상세 설정 페이지가 표시됩니다.

| 설정 항목 | 설명 | 변경 가능 여부 |
|-----------|------|:--------------:|
| 학교 이름 (`schoolName`) | 학교 표시 이름 | O |
| 학교 ID (`schoolId`) | 학교 고유 식별자 | X (변경 불가) |

### 외부 링크 관리

학교에 관련된 외부 웹사이트 링크를 등록할 수 있습니다.

| 필드 | 설명 | 예시 |
|------|------|------|
| `url` | 링크 URL | `https://www.bmrschool.net` |
| `title` | 링크 제목 | `별무리학교 홈페이지` |

#### 링크 추가 절차

1. 학교 상세 페이지에서 **링크** 탭으로 이동합니다.
2. URL과 제목을 입력합니다.
3. **추가** 버튼을 클릭합니다.

## 학교에 사용자 등록

> **필요 권한**: 🔴 Admin

사용자를 특정 학교에 등록하면 해당 학교의 학기에 배정할 수 있게 됩니다. 사용자는 여러 학교에 동시에 등록될 수 있습니다.

### 개별 등록

1. 학교 상세 페이지에서 **사용자** 탭으로 이동합니다.
2. 등록된 사용자 목록이 표시됩니다.
3. **사용자 추가** 버튼을 클릭합니다.
4. 검색 또는 목록에서 등록할 사용자를 선택합니다.
5. 선택한 사용자를 학교에 등록합니다.

### 일괄 등록

사용자 관리 페이지에서 여러 사용자를 한 번에 학교에 등록할 수 있습니다.

1. **관리자** > **사용자 관리** 페이지로 이동합니다.
2. 등록할 사용자들을 선택합니다.
3. **학교 일괄 등록** 기능을 사용하여 대상 학교를 지정합니다.

> [!TIP]
> 사용자가 학교에 등록되어 있어야 해당 학교의 학기에 배정(Registration)할 수 있습니다. 학기 등록은 [학기 관리](season-management.md)를 참고하세요.

### 사용자 등록 정보 구조

사용자의 `schools` 필드에 학교 정보가 배열로 저장됩니다.

```json
{
  "schools": [
    {
      "school": "65a1b2c3d4e5f6a7b8c9d0e1",
      "schoolId": "bmr-middle",
      "schoolName": "별무리중학교"
    },
    {
      "school": "65a1b2c3d4e5f6a7b8c9d0e2",
      "schoolId": "bmr-high",
      "schoolName": "별무리고등학교"
    }
  ]
}
```

## 기록 양식 설정

> **필요 권한**: 🔴 Admin

학교별로 학생 기록에 사용할 양식(필드)을 정의합니다. 기록 양식은 학교 단위로 설정되며, 해당 학교의 모든 학기에서 공통으로 사용됩니다.

### 기록 양식 데이터 유형

기록 양식은 두 가지 데이터 유형을 지원합니다.

| 데이터 유형 | 설명 | 용도 |
|-------------|------|------|
| `array` (누적 기록) | 여러 행의 데이터를 누적하여 기록 | 상담 기록, 활동 기록, 독서 기록 등 |
| `object` (단일 기록) | 단일 행의 데이터를 기록 | 프로필 정보, 인적사항 등 |

### 양식 항목 구조

각 양식 항목(`formArchiveItem`)은 다음과 같은 구조를 갖습니다.

| 필드 | 설명 | 값 |
|------|------|-----|
| `label` | 양식 항목 이름 | 예: `상담 기록`, `독서 기록` |
| `dataType` | 데이터 유형 | `array` (누적) 또는 `object` (단일) |
| `fields` | 필드 목록 | 아래 표 참고 |
| `authTeacher` | 교사 접근 권한 | `undefined`, `viewAndEditStudents`, `viewAndEditMyStudents` |
| `authStudent` | 학생 접근 권한 | `undefined`, `view`, `viewAndEdit` |
| `authManager` | 관리자 접근 권한 | `undefined`, `viewAndEdit` |

### 필드 유형

#### 누적 기록 (`dataType: "array"`) 필드 유형

| 유형 | 표시 | 설명 |
|------|------|------|
| `input` | 텍스트 | 자유 텍스트 입력 |
| `input-number` | 숫자 | 숫자 입력 (합산/누계합산 가능) |
| `select` | 선택 | 드롭다운 선택 (옵션 정의 필요) |

#### 단일 기록 (`dataType: "object"`) 필드 유형

| 유형 | 표시 | 설명 |
|------|------|------|
| `input` | 텍스트 | 자유 텍스트 입력 |
| `file` | 파일 | 파일 첨부 |
| `file-image` | 사진 | 이미지 파일 첨부 |

### 숫자 필드 옵션 (누적 기록 전용)

숫자 필드(`input-number`)는 추가 집계 옵션을 제공합니다.

| 옵션 | 설명 |
|------|------|
| `total` (합산) | 해당 필드의 전체 합계를 계산하여 표시 |
| `runningTotal` (누계합산) | 행이 추가될 때마다 누적 합계를 계산하여 표시 |

### 양식 항목 생성 절차

1. 학교 상세 페이지에서 **기록 양식** 탭으로 이동합니다.
2. **항목 추가** 버튼을 클릭합니다.
3. 항목 이름(`label`)과 데이터 유형(`dataType`)을 설정합니다.
4. 항목을 선택하여 상세 설정 팝업을 엽니다.
5. 필드를 추가합니다.
   - **필드명**: 필드의 표시 이름
   - **유형**: 텍스트, 숫자, 선택 등
   - **합산/누계합산**: 숫자 필드인 경우 집계 옵션
6. 필드 순서를 드래그하여 조정합니다.
7. 저장합니다.

### 접근 권한 설정

각 기록 양식 항목별로 교사, 학생, 관리자의 접근 권한을 개별 설정할 수 있습니다.

| 역할 | 권한 옵션 | 설명 |
|------|-----------|------|
| 교사 (`authTeacher`) | `undefined` | 접근 불가 |
| | `viewAndEditStudents` | 모든 학생의 기록 열람 및 편집 |
| | `viewAndEditMyStudents` | 담당 학생의 기록만 열람 및 편집 |
| 학생 (`authStudent`) | `undefined` | 접근 불가 |
| | `view` | 본인 기록 열람만 가능 |
| | `viewAndEdit` | 본인 기록 열람 및 편집 |
| 관리자 (`authManager`) | `undefined` | 접근 불가 |
| | `viewAndEdit` | 모든 학생의 기록 열람 및 편집 |

> [!TIP]
> `viewAndEditMyStudents` 옵션은 Registration에서 담당 교사(`teacher`, `subTeacher`)로 지정된 학생에 대해서만 접근을 허용합니다. 담임 교사 체계를 활용하는 학교에 적합합니다.

### 삭제된 양식 복구

기록 양식 항목을 삭제하면 즉시 영구 삭제되지 않고 `deletedFormArchive` 목록으로 이동합니다. 삭제된 항목은 삭제 시점(`deletedAt`)과 함께 보관되며, 필요 시 복구할 수 있습니다.

> [!IMPORTANT]
> 기록 양식의 필드를 변경하면 기존에 입력된 데이터의 구조와 불일치가 발생할 수 있습니다. 이미 데이터가 입력된 양식의 필드 변경은 신중하게 진행하세요.
