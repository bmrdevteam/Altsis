# 양식 관리 🔵

Altsis의 양식 시스템은 학교 운영에 필요한 다양한 문서와 데이터 구조를 커스터마이즈할 수 있도록 설계되었습니다. 평가 양식, 기록 양식, 시간표 양식, 강의계획서 양식, 출력 양식 등 다양한 유형의 양식을 정의하고 관리할 수 있습니다.

## 양식 개요

Altsis의 양식은 크게 두 가지 방식으로 관리됩니다.

| 관리 방식 | 저장 위치 | 양식 유형 |
|-----------|-----------|-----------|
| 학기(Season) 내장 | `Season` 모델 | 평가 양식, 시간표 양식, 강의계획서 양식 |
| 독립 양식(Form) | `Form` 모델 | 시간표 양식, 강의계획서 양식, 출력 양식 |
| 학교(School) 내장 | `School` 모델 | 기록 양식 |

### 독립 양식(Form) 데이터 구조

| 필드 | 설명 | 필수 |
|------|------|:----:|
| `type` | 양식 유형 (`timetable`, `syllabus`, `print`) | O |
| `title` | 양식 제목 | O |
| `data` | 에디터에서 정의한 양식 데이터 | O |
| `userId` | 생성자 ID | O |
| `userName` | 생성자 이름 | O |
| `archived` | 보관 처리 여부 | - |
| `permissionView` | 열람 권한 설정 | - |

> [!TIP]
> 독립 양식은 **관리자** > **양식 관리** 페이지에서 관리하며, 학기별 양식은 **학교 관리** > **학기** > **양식** 탭에서 관리합니다. 독립 양식을 만들어둔 후 학기 양식으로 연결하는 방식으로 사용합니다. 시간표·강의계획서·출력 양식 에디터에서는 상단 **Alter**의 **양식** Skill로 초안을 받은 뒤 미리보기 확인 후 반영할 수 있습니다.

## 양식 유형

### 평가 양식

> **저장 위치**: `Season.formEvaluation`
>
> **필요 권한**: 🔵 Manager

평가 양식은 수업별 평가 항목을 정의합니다. 교사가 학생을 평가하거나, 학생이 자기 평가를 할 때 사용하는 항목의 구조를 결정합니다.

#### 평가 항목 데이터 구조

| 필드 | 설명 | 기본값 |
|------|------|--------|
| `label` | 평가 항목 이름 | - |
| `type` | 입력 유형 | `input` |
| `options` | 선택 옵션 (type이 `select`인 경우) | `[]` |
| `combineBy` | 평가 동기화 단위 | `term` |
| `authOption` | 권한 옵션 | `editByTeacher` |

#### 평가 항목 입력 유형

| 유형 | 설명 | 사용 예시 |
|------|------|-----------|
| `input` | 자유 텍스트 입력 | 서술형 평가, 코멘트 |
| `input-number` | 숫자 입력 | 점수, 등급 |
| `select` | 드롭다운 선택 | 등급 선택 (A/B/C/D) |

#### 평가 동기화 단위 (`combineBy`)

| 값 | 설명 |
|-----|------|
| `term` | 학기 단위로 평가 데이터를 동기화 |
| `year` | 학년도 단위로 평가 데이터를 동기화 |

> [!IMPORTANT]
> `combineBy`가 `year`로 설정된 평가 항목은 같은 학년도의 모든 학기에서 데이터가 공유됩니다. 예를 들어, 1학기에 입력한 평가가 2학기에서도 보이게 됩니다.

#### 권한 옵션 (`authOption`)

| 옵션 | 교사 | 학생 | 설명 |
|------|:----:|:----:|------|
| `editByTeacher` | 편집 | X | 교사만 입력/수정 가능 |
| `editByStudent` | X | 편집 | 학생 자기 평가용 |
| `editByTeacherAndStudentCanView` | 편집 | 열람 | 교사가 입력, 학생은 결과만 조회 |

#### 평가 양식 설정 절차

1. 학기 상세 페이지에서 **양식** 탭으로 이동합니다.
2. **평가 양식** 섹션에서 항목을 관리합니다.
3. **항목 추가** 버튼을 클릭합니다.
4. 각 항목의 속성을 설정합니다.
   - **항목 이름**: 예) `멘토평가`, `자기평가`, `출석점수`
   - **유형**: 텍스트, 숫자, 선택 중 택일
   - **선택 옵션**: 유형이 `select`인 경우 옵션 목록 등록
   - **동기화 단위**: `학기` 또는 `학년도`
   - **권한**: 교사 입력 / 학생 입력 / 교사 입력+학생 열람
5. 항목 순서를 조정합니다.
6. **저장** 버튼을 클릭합니다.

> [!WARNING]
> 학기가 최초 활성화(`isActivatedFirst: true`)된 이후에는 평가 양식의 수정이 제한됩니다. 수업이 진행되고 평가 데이터가 입력된 상태에서 양식을 변경하면 데이터 정합성 문제가 발생할 수 있으므로, 학기 활성화 전에 양식을 확정하세요.

### 기록 양식

> **저장 위치**: `School.formArchive`
>
> **필요 권한**: 🔴 Admin

기록 양식은 학교 단위로 관리되며, 학생 기록에 사용할 필드를 정의합니다. 상세 내용은 [학교 관리 > 기록 양식 설정](school-management.md#기록-양식-설정)을 참고하세요.

| 데이터 유형 | 용도 | 필드 유형 |
|-------------|------|-----------|
| 누적 기록 (`array`) | 상담, 활동, 독서 기록 등 | `input`, `input-number`, `select` |
| 단일 기록 (`object`) | 프로필, 인적사항 등 | `input`, `file`, `file-image` |

### 시간표 양식

> **저장 위치**: `Season.formTimetable` (학기 연결) / `Form` 모델 (독립 양식)
>
> **필요 권한**: 🔵 Manager

시간표 양식은 에디터를 사용하여 시간표의 레이아웃을 정의합니다. 요일, 교시, 시간대 등의 구조를 자유롭게 설계할 수 있습니다.

#### 시간표 양식 데이터 구조

```json
{
  "formTimetable": {
    "title": "2026학년도 1학기 시간표",
    "data": [
      { /* 에디터에 의해 정의된 행/열 구조 */ }
    ]
  }
}
```

#### 시간표 양식 설정 절차

1. **관리자** > **양식 관리** 페이지에서 시간표 양식을 생성합니다.
   - **양식 유형**: `timetable`
   - **제목**: 양식 이름
   - 에디터에서 시간표 레이아웃을 설계합니다.
2. 학기 상세 페이지의 **양식** 탭으로 이동합니다.
3. **시간표 양식** 항목에서 **선택** 버튼을 클릭합니다.
4. 목록에서 사용할 시간표 양식을 선택합니다.

> [!IMPORTANT]
> 시간표 양식은 학기 최초 활성화 전에만 변경할 수 있습니다. 활성화 후에는 "없음"으로 표시되며 변경이 불가합니다.

### 강의계획서 양식

> **저장 위치**: `Season.formSyllabus` (학기 연결) / `Form` 모델 (독립 양식)
>
> **필요 권한**: 🔵 Manager

강의계획서 양식은 에디터를 사용하여 수업 계획서의 템플릿을 정의합니다. 교사가 강의계획서를 작성할 때 이 양식에 따라 내용을 입력합니다.

#### 강의계획서 양식 데이터 구조

```json
{
  "formSyllabus": {
    "title": "2026학년도 강의계획서 양식",
    "data": [
      { /* 에디터에 의해 정의된 필드 구조 */ }
    ]
  }
}
```

#### 강의계획서 양식 설정 절차

1. **관리자** > **양식 관리** 페이지에서 강의계획서 양식을 생성합니다.
   - **양식 유형**: `syllabus`
   - **제목**: 양식 이름
   - 에디터에서 강의계획서 레이아웃을 설계합니다.
2. 학기 상세 페이지의 **양식** 탭으로 이동합니다.
3. **강의계획서 양식** 항목에서 **선택** 버튼을 클릭합니다.
4. 목록에서 사용할 강의계획서 양식을 선택합니다.

> [!IMPORTANT]
> 강의계획서 양식 역시 학기 최초 활성화 전에만 변경할 수 있습니다. 활성화 후 수업(Syllabus)이 이 양식 구조에 따라 생성되므로, 변경 시 기존 수업 데이터와 구조가 불일치할 수 있습니다.

### 출력 양식

> **저장 위치**: `Form` 모델
>
> **필요 권한**: 🔵 Manager

출력 양식은 문서 출력(인쇄)에 사용되는 템플릿을 정의합니다. 에디터를 사용하여 출력 레이아웃을 설계하며, 데이터 연결 기능을 통해 동적 데이터를 삽입할 수 있습니다.

#### 출력 양식 유형

| 유형 | 설명 | 사용 예시 |
|------|------|-----------|
| `print` | 일반 출력 양식 | 성적표, 생활기록부, 수료증 등 |

#### 출력 양식 생성 절차

1. **관리자** > **양식 관리** 페이지로 이동합니다.
2. **양식 추가** 버튼을 클릭합니다.
3. 양식 유형으로 `print`(출력)를 선택합니다.
4. 양식 제목을 입력합니다.
5. 에디터에서 출력 레이아웃을 설계합니다.
   - 텍스트, 표, 이미지 등을 배치합니다.
   - 데이터 연결 필드를 삽입합니다 (아래 [데이터 연결](#데이터-연결) 참고).
6. **저장** 버튼을 클릭합니다.

## 데이터 연결

양식 에디터에서는 정적 텍스트 외에 시스템 데이터를 동적으로 바인딩할 수 있습니다. 데이터 연결 기능을 사용하면 양식이 출력되거나 표시될 때 실제 데이터가 자동으로 채워집니다.

### 데이터 연결 개념

```
양식 템플릿 (정적 레이아웃)
    ├── 텍스트: "성명:"
    ├── 데이터 필드: {userName}     → 실제 값: "홍길동"
    ├── 텍스트: "학년도:"
    └── 데이터 필드: {year}         → 실제 값: "2026학년도"
```

### 연결 가능한 데이터 소스

| 소스 | 설명 | 사용 가능한 필드 예시 |
|------|------|----------------------|
| Registration | 학기 등록 정보 | `userName`, `userId`, `role`, `grade`, `group` |
| Season | 학기 정보 | `year`, `term`, `schoolName` |
| Enrollment | 수강 정보 | 수업명, 수강 데이터 |
| Evaluation | 평가 데이터 | 평가 항목별 값 |
| Archive | 학생 기록 | 기록 양식 필드별 값 |

### 데이터 연결 설정 절차

1. 양식 에디터에서 데이터를 삽입할 위치를 선택합니다.
2. **데이터 연결** 도구를 클릭합니다.
3. 연결할 데이터 소스를 선택합니다.
4. 바인딩할 필드를 지정합니다.
5. 필요한 경우 필터 조건을 추가합니다.

> [!TIP]
> 출력 양식에서 데이터 연결을 사용하면 학생별 성적표, 기록부 등을 자동으로 생성할 수 있습니다. 양식을 한 번 설계해두면 학생 수만큼의 문서가 자동으로 채워집니다.

## 양식 권한 설정

독립 양식(Form 모델)에는 열람 권한을 개별 설정할 수 있습니다.

### 권한 구조

```json
{
  "permissionView": {
    "teacher": true,
    "student": false,
    "exceptions": [
      {
        "user": "65a1b2c3d4e5f6a7b8c9d0e1",
        "userId": "student01",
        "userName": "홍길동",
        "isAllowed": true
      }
    ]
  }
}
```

### 권한 옵션

| 항목 | 설명 | 기본값 |
|------|------|--------|
| `teacher` | 교사 전체 열람 허용 | `true` |
| `student` | 학생 전체 열람 허용 | `false` |
| `exceptions` | 개별 사용자 예외 설정 | `[]` |

### 권한 설정 절차

1. **양식 관리** 페이지에서 양식을 선택합니다.
2. **권한 설정** 버튼을 클릭합니다.
3. 기본 권한을 설정합니다.
   - **교사 열람**: Y(허용) / N(거부)
   - **학생 열람**: Y(허용) / N(거부)
4. 필요한 경우 예외 사용자를 추가합니다.
   - 특정 사용자에게 기본 권한과 다른 접근 권한을 부여
   - 예: 학생 전체는 열람 거부이지만, 특정 학생만 열람 허용
5. **저장** 버튼을 클릭합니다.

### 예외 사용자 설정 예시

| 시나리오 | `teacher` | `student` | 예외 설정 |
|----------|:---------:|:---------:|-----------|
| 교사만 열람 가능 | `true` | `false` | 없음 |
| 모두 열람 가능 | `true` | `true` | 없음 |
| 교사 중 특정 인원만 거부 | `true` | `false` | 해당 교사 `isAllowed: false` |
| 학생 중 특정 인원만 허용 | `true` | `false` | 해당 학생 `isAllowed: true` |

> [!TIP]
> 예외 설정은 기본 권한을 덮어씁니다. 예를 들어, `student: false`(학생 전체 거부)인 상태에서 특정 학생의 `isAllowed: true`로 설정하면 해당 학생만 열람할 수 있습니다.

### 보관 처리

더 이상 사용하지 않는 양식은 삭제 대신 **보관 처리**할 수 있습니다.

1. 양식 목록에서 대상 양식을 선택합니다.
2. **보관** 버튼을 클릭합니다.
3. 보관된 양식은 목록에서 숨겨지며, 필터를 통해 확인할 수 있습니다.

> [!IMPORTANT]
> 양식이 학기에 연결(`Season.formTimetable`, `Season.formSyllabus`)되어 있는 경우, 해당 양식을 삭제하거나 보관 처리하면 학기에서 양식 연결이 유지되더라도 내용을 확인할 수 없게 될 수 있습니다. 학기에서 양식 연결을 먼저 해제한 후 보관 처리하세요.

| 출력 양식 | Form | O | X | O |
