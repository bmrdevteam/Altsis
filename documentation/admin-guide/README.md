# 관리자 가이드

Altsis 시스템을 운영하는 관리자를 위한 종합 가이드입니다. 아카데미 생성부터 학기 운영, 양식 관리, 권한 설정까지 시스템 관리에 필요한 모든 내용을 다룹니다.

---

## 관리자 유형

Altsis는 역할 기반 권한 체계를 사용합니다. 관리자는 세 가지 유형으로 구분되며, 각 유형에 따라 접근할 수 있는 기능이 다릅니다.

| 기호 | 역할 | 영문 | 설명 |
|:----:|------|------|------|
| ⚫ | 시스템 관리자 | Owner | 아카데미 전체를 총괄하는 최상위 관리자. 아카데미 생성 및 삭제, 시스템 전반의 설정을 담당합니다. |
| 🔴 | 아카데미 관리자 | Admin | 아카데미 내의 학교, 사용자, 데이터를 관리하는 관리자. 학교 생성, 사용자 계정 관리, 아카데미 설정을 담당합니다. |
| 🔵 | 학교 관리자 | Manager | 특정 학교에 배정되어 해당 학교의 학기, 양식, 권한을 관리하는 관리자. 학기 생성 및 운영, 양식 정의, 권한 설정을 담당합니다. |

### 역할 계층 구조

```
⚫ Owner (시스템 관리자)
 └── 🔴 Admin (아카데미 관리자)
      └── 🔵 Manager (학교 관리자)
           └── ⚪ Member (일반 사용자: 교사/학생)
```

> [!IMPORTANT]
> Owner는 시스템 최초 설정 시 생성되는 특수 계정입니다. 일반적인 운영 환경에서는 Admin과 Manager가 대부분의 관리 업무를 수행합니다.

---

## 각 관리자 역할 요약

### ⚫ Owner (시스템 관리자)

| 기능 | 설명 |
|------|------|
| 아카데미 생성 | 새로운 아카데미를 생성하고 고유 ID를 부여 |
| 아카데미 설정 | 아카데미 기본 정보, AI 설정, 채팅 활성화 관리 |
| 데이터 백업/복원 | 아카데미 전체 데이터의 백업 및 복원 수행 |

### 🔴 Admin (아카데미 관리자)

| 기능 | 설명 |
|------|------|
| 학교 관리 | 아카데미 내 학교 생성, 설정, 삭제 |
| 사용자 관리 | 사용자 계정 생성, 역할 할당, 학교 등록 |
| 기록 양식 관리 | 학교별 기록 양식(필드) 정의 |
| 아카데미 설정 | 기본 정보 변경, AI/채팅 설정 |

### 🔵 Manager (학교 관리자)

| 기능 | 설명 |
|------|------|
| 학기 관리 | 학기 생성, 복사, 활성화/비활성화 |
| 양식 관리 | 평가, 시간표, 강의계획서, 출력 양식 정의 |
| 권한 설정 | 수업 개설, 수강신청, 평가 권한 설정 |
| 등록 관리 | 학기에 학생/교사 등록, 교과목/강의실 설정 |
| AI 설정 | 학기별 AI 기능 활성화 및 권한 관리 |

## 권장 학습 순서

시스템을 처음 운영하는 관리자라면 다음 순서로 문서를 학습하는 것을 권장합니다.

```
아카데미 관리 → 학교 관리 → 사용자 관리 → 학기 관리 → 양식 관리 → 권한 설정
```

> [!TIP]
> 이미 아카데미와 학교가 생성되어 있다면, 학기 관리부터 시작해도 됩니다. 학교 관리자(Manager)는 학기 관리 문서부터 참고하세요.
