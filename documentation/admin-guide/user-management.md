# 사용자 관리 🔴

## 사용자 계정 생성

> **필요 권한**: 🔴 Admin

### 사용자 데이터 구조

| 필드 | 설명 | 필수 | 유효성 검사 |
|------|------|:----:|-------------|
| `userId` | 사용자 고유 ID | O | 알파벳, 숫자로 이루어진 길이 4~20의 문자열 |
| `userName` | 사용자 이름 | O | 알파벳, 숫자, 한글로 이루어진 길이 2~20의 문자열 |
| `password` | 비밀번호 | O | 특수문자(`!@#$%^&*()`)가 하나 이상 포함된 길이 8~26의 문자열 |
| `auth` | 계정 역할 | O | `admin`, `manager`, `member` 중 선택 (기본값: `member`) |
| `email` | 이메일 | - | 이메일 형식 (예: `user@example.com`) |
| `tel` | 전화번호 | - | 전화번호 형식 (예: `010-0000-0000`) |
| `snsId.google` | 구글 로그인 이메일 | - | 이메일 형식. 소셜 로그인에 사용 |
| `schools` | 소속 학교 목록 | - | 생성 시 또는 이후 등록 |

> [!IMPORTANT]
> `userId`와 `userName`은 생성 후 변경할 수 없습니다. `userId`는 아카데미 내에서 고유해야 하며, `snsId.google` (구글 로그인 이메일) 역시 고유한 값으로 중복이 허용되지 않습니다.

### 단일 생성 절차

1. Admin 계정으로 로그인합니다.
2. **관리자** > **사용자 관리** 페이지로 이동합니다.
3. **사용자 단일 생성** 버튼을 클릭합니다.
4. 팝업에서 사용자 정보를 입력합니다.
   - **소속 학교**: 드롭다운에서 학교를 선택하고 **등록** 버튼으로 추가 (복수 선택 가능)
   - **등급**: `멤버`, `매니저`, `관리자` 중 선택
   - **ID**: 사용자 고유 식별자
   - **이름**: 사용자 표시 이름
   - **비밀번호**: 초기 비밀번호
   - **이메일**: (선택) 연락용 이메일
   - **구글 로그인 이메일**: (선택) 소셜 로그인용 이메일
   - **전화번호**: (선택) 연락처
5. **생성** 버튼을 클릭합니다.

> [!TIP]
> 사용자 생성 시 학교를 함께 등록할 수 있습니다. 학교 등록을 건너뛰고 나중에 추가할 수도 있습니다.

## 계정 역할

Altsis는 4단계의 계정 역할(`auth`)을 제공합니다.

| 역할 | 영문 | 설명 | UI 표시 |
|------|------|------|---------|
| 시스템 관리자 | `owner` | 최상위 관리자. 아카데미 생성/관리 | - |
| 아카데미 관리자 | `admin` | 아카데미 내 모든 관리 기능 접근 가능 | 관리자 |
| 학교 관리자 | `manager` | 소속 학교의 학기/양식/권한 관리 가능 | 매니저 |
| 일반 사용자 | `member` | 교사 또는 학생으로 수업 참여 | 멤버 |

### 역할별 접근 가능 메뉴

| 메뉴 | `owner` | `admin` | `manager` | `member` |
|------|:-------:|:-------:|:---------:|:--------:|
| 아카데미 설정 | O | O | X | X |
| 학교 관리 | O | O | X | X |
| 사용자 관리 | O | O | X | X |
| 학기 관리 | O | O | O | X |
| 양식 관리 | O | O | O | X |
| 권한 설정 | O | O | O | X |
| 수업/수강신청 | O | O | O | O |
| 일정/보드/채팅 | O | O | O | O |

### 역할 변경

1. **관리자** > **사용자 관리** 페이지에서 대상 사용자를 선택합니다.
2. 사용자 편집 팝업에서 **등급** 탭으로 이동합니다.
3. 새로운 역할을 선택합니다.
4. **저장** 버튼을 클릭합니다.

> [!WARNING]
> 역할 변경은 즉시 적용됩니다. Admin 역할을 부여하면 해당 사용자가 아카데미의 모든 관리 기능에 접근할 수 있게 되므로 신중하게 결정하세요.

## 사용자 학교 등록

> **필요 권한**: 🔴 Admin

사용자를 특정 학교에 등록하면 해당 학교의 학기에 배정할 수 있게 됩니다.

### 개별 등록

사용자 편집 팝업에서 학교를 등록합니다.

1. **사용자 관리** 페이지에서 사용자를 선택합니다.
2. 편집 팝업의 **학교** 탭으로 이동합니다.
3. 드롭다운에서 학교를 선택합니다.
4. **등록** 버튼을 클릭합니다.

### 일괄 등록

여러 사용자를 한 번에 같은 학교에 등록합니다.

1. **사용자 관리** 페이지에서 체크박스로 대상 사용자들을 선택합니다.
2. **학교 일괄 등록** 버튼을 클릭합니다.
3. 대상 학교를 선택합니다.
4. **등록** 버튼을 클릭합니다.

### 학교 등록 해제

사용자 편집 팝업의 학교 탭에서 등록된 학교의 **삭제** 버튼을 클릭하면 해당 학교 등록이 해제됩니다.

> [!IMPORTANT]
> 학교 등록을 해제해도 해당 사용자의 학기 등록(Registration) 데이터는 자동으로 삭제되지 않습니다. 학기 등록 해제가 필요한 경우 [학기 관리](season-management.md)에서 별도로 처리해야 합니다.

## CSV 일괄 등록

> **필요 권한**: 🔴 Admin

대량의 사용자를 Excel(CSV) 파일을 이용하여 한 번에 등록할 수 있습니다.

### 파일 양식

| 열 순서 | 필드명 | 필수 | 설명 |
|:-------:|--------|:----:|------|
| A | ID | O | 알파벳, 숫자 (4~20자) |
| B | 이름 | O | 알파벳, 숫자, 한글 (2~20자) |
| C | 비밀번호 | O | 특수문자 포함 (8~26자) |
| D | 이메일 | - | 이메일 형식 |
| E | 구글 로그인 이메일 | - | 이메일 형식 (소셜 로그인용) |
| F | 전화번호 | - | 전화번호 형식 |

### Excel 파일 예시

| ID | 이름 | 비밀번호 | 이메일 | 구글 로그인 이메일 | 전화번호 |
|----|------|----------|--------|-------------------|----------|
| user01 | 홍길동 | asdfqwer!@#$ | google@email.com | google@gmail.com | 010-0000-1111 |
| user02 | 김철수 | password!123 | | | 010-2222-3333 |

### 일괄 등록 절차

1. **관리자** > **사용자 관리** 페이지에서 **일괄 생성** 버튼을 클릭합니다.
2. **도움말** 탭에서 파일 양식과 규칙을 확인합니다.
3. **양식 다운로드** 버튼을 클릭하여 Excel 템플릿(`example.xlsx`)을 다운로드합니다.
4. 템플릿에 사용자 정보를 B1 셀부터 입력합니다.
5. **학교 선택** 탭에서 사용자들을 등록할 학교를 선택합니다 (선택 사항).
6. **업로드** 탭에서 작성한 Excel 파일을 업로드합니다.
7. 업로드된 데이터를 확인하고 **추가** 탭에서 등록을 실행합니다.

> [!WARNING]
> - ID가 이미 존재하는 사용자는 등록이 거부됩니다.
> - 구글 로그인 이메일이 이미 다른 사용자에게 등록된 경우 해당 행의 등록이 실패합니다.
> - 필수 필드의 유효성 검사에 실패하면 해당 행이 등록되지 않습니다.

### 일괄 등록 시 유의사항

```
양식 다운로드 → Excel 편집 → 학교 선택(선택) → 파일 업로드 → 데이터 확인 → 등록 실행
```

- B1 셀부터 데이터를 입력해야 합니다 (A행은 헤더).
- 빈 행이 있으면 해당 행 이후의 데이터가 무시될 수 있습니다.
- ID와 이름은 등록 후 수정할 수 없으므로 오타에 주의하세요.

## 사용자 검색 및 조회

> **필요 권한**: 🔴 Admin

### 사용자 목록 조회

**관리자** > **사용자 관리** 페이지에서 아카데미에 등록된 모든 사용자를 조회할 수 있습니다.

| 표시 항목 | 설명 |
|-----------|------|
| ID | 사용자 고유 식별자 |
| 이름 | 사용자 이름 |
| 등급 | 역할 (admin/manager/member) |
| 소속 학교 | 등록된 학교 목록 |

### 검색 및 필터

사용자 목록에서 다음 방법으로 검색할 수 있습니다.

- **텍스트 검색**: ID 또는 이름으로 검색
- **테이블 정렬**: 각 열의 헤더를 클릭하여 정렬
- **페이지 네비게이션**: 페이지당 표시 수를 조절하여 탐색

### 사용자 상세 조회

사용자를 클릭하면 편집 팝업이 표시되며, 다음 탭에서 상세 정보를 확인할 수 있습니다.

| 탭 | 내용 |
|-----|------|
| 기본 정보 | ID, 이름, 이메일, 전화번호, 구글 로그인 이메일 |
| 등급 | 계정 역할 변경 |
| 학교 | 소속 학교 목록 관리 |
| 등록 정보 | 학기별 Registration 목록 |

## 계정 비활성화/삭제

> **필요 권한**: 🔴 Admin

### 사용자 삭제

1. **사용자 관리** 페이지에서 삭제할 사용자를 선택합니다.
2. 사용자 편집 팝업에서 **삭제** 기능을 사용합니다.
3. 확인 대화상자에서 삭제를 승인합니다.

### 일괄 삭제

여러 사용자를 한 번에 삭제할 수 있습니다.

1. **사용자 관리** 페이지에서 삭제할 사용자들을 체크박스로 선택합니다.
2. **일괄 삭제** 버튼을 클릭합니다.
3. 확인 대화상자에서 삭제를 승인합니다.

> [!WARNING]
> 사용자를 삭제하면 해당 사용자의 계정 정보가 영구 삭제됩니다. 다만, 해당 사용자와 연관된 학기 등록(Registration), 수강 정보(Enrollment) 등의 데이터는 자동으로 삭제되지 않을 수 있습니다. 삭제 전에 관련 데이터를 먼저 정리하는 것을 권장합니다.

### 아카데미 비활성화를 통한 접근 차단

개별 사용자의 접근을 차단하는 별도의 비활성화 기능 대신, 아카데미 전체의 `isActivated` 설정을 통해 모든 사용자의 로그인을 일괄 차단할 수 있습니다. 아카데미가 비활성화(`isActivated: false`)되면 해당 아카데미에 속한 모든 사용자의 로그인이 거부됩니다.
