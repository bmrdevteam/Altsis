# 아카데미 관리 ⚫🔴

아카데미는 Altsis 시스템의 최상위 조직 단위입니다. 하나의 아카데미 안에 여러 학교를 포함할 수 있으며, 모든 사용자와 데이터는 아카데미 단위로 격리됩니다. 이 문서에서는 아카데미의 생성, 설정, AI 구성, 백업/복원 방법을 설명합니다.

## 아카데미 생성

> **필요 권한**: ⚫ Owner

아카데미를 생성하면 독립된 데이터베이스가 자동으로 생성되며, 해당 아카데미의 모든 데이터는 이 데이터베이스에 저장됩니다.

### 아카데미 데이터 구조

| 필드 | 설명 | 필수 | 비고 |
|------|------|:----:|------|
| `academyId` | 아카데미 고유 ID | O | 영문, 숫자로 구성. 생성 후 변경 불가 |
| `academyName` | 아카데미 이름 | O | 한글, 영문, 숫자 사용 가능 |
| `email` | 대표 이메일 | - | 이메일 형식 |
| `tel` | 대표 전화번호 | - | 전화번호 형식 |
| `adminId` | 관리자 ID | O | 최초 Admin 계정의 userId |
| `adminName` | 관리자 이름 | O | 최초 Admin 계정의 userName |

### 생성 절차

1. Owner 계정으로 로그인합니다.
2. **관리자 메뉴**에서 아카데미 관리 페이지로 이동합니다.
3. **아카데미 생성** 버튼을 클릭합니다.
4. 필수 정보를 입력합니다.
   - `academyId`: 아카데미의 고유 식별자 (예: `bmr-academy`)
   - `academyName`: 아카데미 표시 이름 (예: `별무리 아카데미`)
5. 관리자 계정 정보를 입력합니다.
6. **생성** 버튼을 클릭하여 아카데미를 생성합니다.

> [!WARNING]
> `academyId`는 생성 후 변경할 수 없습니다. 또한 내부적으로 `academyId + "-db"` 형태로 데이터베이스명이 자동 생성되므로, 신중하게 설정하세요.

### 생성 후 자동 처리

아카데미가 생성되면 다음 작업이 자동으로 수행됩니다.

```
아카데미 생성
 ├── 아카데미 전용 데이터베이스 생성 ({academyId}-db)
 ├── 아카데미 레코드 루트 DB에 저장
 └── 기본 관리자(Admin) 계정 생성
```

## 아카데미 설정

> **필요 권한**: 🔴 Admin

아카데미 생성 후 기본 정보를 변경할 수 있습니다.

### 변경 가능한 설정 항목

| 항목 | 설명 | 변경 가능 여부 |
|------|------|:--------------:|
| 아카데미 이름 (`academyName`) | 아카데미 표시 이름 | O |
| 이메일 (`email`) | 대표 연락 이메일 | O |
| 전화번호 (`tel`) | 대표 연락 전화번호 | O |
| 관리자 ID (`adminId`) | 아카데미 관리자 ID | O |
| 관리자 이름 (`adminName`) | 아카데미 관리자 이름 | O |
| 아카데미 ID (`academyId`) | 아카데미 고유 식별자 | X (변경 불가) |

### 설정 변경 절차

1. Admin 계정으로 로그인합니다.
2. 좌측 사이드바에서 **관리자** 메뉴를 클릭합니다.
3. 아카데미 설정 페이지에서 수정할 항목의 값을 변경합니다.
4. **저장** 버튼을 클릭합니다.

## AI 설정

> **필요 권한**: 🔴 Admin (아카데미 수준), 🔵 Manager (학기 수준)

Altsis는 Google Generative AI를 활용한 AI 기능을 지원합니다. AI 기능은 아카데미 수준과 학기 수준 두 단계로 설정합니다.

### 아카데미 수준 AI 설정 (Admin)

아카데미 수준에서는 AI 기능의 전체 활성화 및 API 키를 관리합니다.

| 항목 | 설명 | 기본값 |
|------|------|--------|
| `aiEnabled` | AI 기능 전체 활성화 | `false` |
| `aiApiKey` | Google Generative AI API 키 | 없음 |
| `aiModel` | 사용할 AI 모델 | `gemini-2.5-flash` |

#### API 키 설정 절차

1. [Google AI Studio](https://aistudio.google.com/)에서 API 키를 발급합니다.
2. Admin 계정으로 로그인한 후, 아카데미 설정 페이지로 이동합니다.
3. **AI 설정** 섹션에서 API 키를 입력합니다.
4. 사용할 모델을 선택합니다.
5. AI 기능을 **활성화**합니다.

> [!IMPORTANT]
> API 키는 보안을 위해 조회 API를 통해 반환되지 않습니다 (`select: false`). 키를 분실한 경우 Google AI Studio에서 새 키를 발급받아야 합니다.

#### 사용 가능한 AI 모델

| 모델명 | 설명 |
|--------|------|
| `gemini-2.5-flash` | 빠르고 효율적인 기본 모델 (기본값) |
| 기타 Gemini 모델 | Google AI에서 지원하는 다른 모델 선택 가능 |

### 학기 수준 AI 설정 (Manager)

학기 수준의 AI 설정은 [학기 관리](season-management.md) 문서와 [권한 설정](permission-settings.md) 문서를 참고하세요. 학기별로 다음 항목을 추가 설정할 수 있습니다.

- AI 기능 활성화/비활성화
- 교사/학생별 AI 사용 권한
- AI 생성 시 기본 지침 (가이드라인)
- AI 참고 자료 등록 (직접 입력 또는 파일 업로드)

## 채팅 활성화/비활성화

> **필요 권한**: 🔴 Admin

아카데미 내 실시간 채팅 기능의 사용 여부를 설정합니다.

| 항목 | 설명 | 기본값 |
|------|------|--------|
| `chatEnabled` | 채팅 기능 활성화 상태 | `false` |

### 설정 절차

1. Admin 계정으로 로그인합니다.
2. 아카데미 설정 페이지로 이동합니다.
3. **채팅 설정** 항목에서 활성화 또는 비활성화를 선택합니다.
4. **저장** 버튼을 클릭합니다.

> [!TIP]
> 채팅 기능을 비활성화하면 아카데미 내 모든 사용자의 채팅 메뉴가 숨겨집니다. 기존 채팅 내역은 삭제되지 않으며, 다시 활성화하면 이전 내역을 확인할 수 있습니다.

## 백업 및 복원

> **필요 권한**: 🔴 Admin

아카데미 전체 데이터를 백업하거나, 백업된 데이터를 복원할 수 있습니다. 백업 데이터는 AWS S3에 JSON 형식으로 저장됩니다.

### 백업 가능한 데이터 모델

| 모델명 | 설명 |
|--------|------|
| `schools` | 학교 정보 |
| `users` | 사용자 계정 정보 |
| `archives` | 학생 기록 데이터 |
| `seasons` | 학기 정보 |
| `registrations` | 학기 등록 정보 |
| `syllabuses` | 강의계획서 |
| `enrollments` | 수강 정보 |
| `forms` | 양식 정보 |
| `notifications` | 알림 데이터 |

### 백업 생성 절차

1. Admin 계정으로 로그인합니다.
2. **관리자 메뉴** > **백업 및 복구** 페이지로 이동합니다.
3. **+ 백업** 버튼을 클릭합니다.
4. 백업 팝업에서 백업할 데이터 모델을 선택합니다.
   - 체크박스를 사용하여 원하는 모델을 선택합니다.
   - 모든 모델을 선택하면 전체 백업이 수행됩니다.
5. **+ 백업** 버튼을 클릭하여 백업을 시작합니다.
6. 백업 완료 후 목록에 새 백업 항목이 표시됩니다.

> [!WARNING]
> 데이터 크기에 따라 백업 시간이 오래 소요될 수 있습니다. 백업 진행 중에는 페이지를 닫지 마세요.

### 백업 데이터 조회 및 다운로드

1. 백업 목록에서 원하는 백업의 **자세히** 버튼을 클릭합니다.
2. 상세 팝업에서 각 모델별 백업 파일을 확인합니다.
3. **다운로드** 버튼을 클릭하여 JSON 파일을 로컬에 저장합니다.

### 백업 삭제

1. 백업 목록에서 삭제할 항목의 **삭제** 버튼을 클릭합니다.
2. 확인 대화상자에서 **확인**을 클릭합니다.

### 데이터 복원 절차

1. **+ 복구** 버튼을 클릭합니다.
2. 복원할 데이터 모델을 드롭다운에서 선택합니다.
   - 예: `schools(학교)`, `users(사용자)` 등
3. **파일 선택** 버튼을 클릭하여 JSON 백업 파일을 업로드합니다.
4. 업로드된 데이터의 미리보기를 확인합니다.
5. **+ 복구** 버튼을 클릭하여 복원을 실행합니다.

> [!WARNING]
> 복원 작업은 기존 데이터를 덮어씁니다. 복원 전에 현재 데이터의 백업을 먼저 수행하는 것을 강력히 권장합니다.

### 복원 파일 형식

복원에 사용하는 JSON 파일은 **배열 형식**이어야 합니다.

```json
[
  {
    "_id": "65a1b2c3d4e5f6a7b8c9d0e1",
    "userId": "user01",
    "userName": "홍길동"
  },
  {
    "_id": "65a1b2c3d4e5f6a7b8c9d0e2",
    "userId": "user02",
    "userName": "김철수"
  }
]
```

> [!IMPORTANT]
> JSON 배열이 아닌 형식(단일 객체 등)의 파일은 업로드가 거부됩니다. 반드시 배열(`[]`) 형식으로 저장된 파일을 사용하세요.
