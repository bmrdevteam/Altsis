# 아카데미 관리 ⚫🔴

아카데미는 Altsis 시스템의 최상위 조직 단위입니다. 하나의 아카데미 안에 여러 학교를 포함할 수 있으며, 모든 사용자와 데이터는 아카데미 단위로 격리됩니다. 이 문서에서는 아카데미의 생성, 설정, AI 구성, 백업/복원 방법을 설명합니다.

## 아카데미 생성

> **필요 권한**: ⚫ Owner

아카데미를 생성하면 독립된 데이터베이스가 자동으로 생성되며, 해당 아카데미의 모든 데이터는 이 데이터베이스에 저장됩니다.

### 아카데미 데이터 구조

| 필드 | 설명 | 필수 | 비고 |
|------|------|:----:|------|
| `academyId` | 아카데미 고유 ID | O | 영문, 숫자로 구성. 생성 후 변경 불가 |
| `academyName` | 아카데미 이름 | O | 한글, 영문, 숫자 사용 가능 |
| `email` | 대표 이메일 | - | 이메일 형식 |
| `tel` | 대표 전화번호 | - | 전화번호 형식 |
| `adminId` | 관리자 ID | O | 최초 Admin 계정의 userId |
| `adminName` | 관리자 이름 | O | 최초 Admin 계정의 userName |

### 생성 절차

1. Owner 계정으로 로그인합니다.
2. **관리자 메뉴**에서 아카데미 관리 페이지로 이동합니다.
3. **아카데미 생성** 버튼을 클릭합니다.
4. 필수 정보를 입력합니다.
   - `academyId`: 아카데미의 고유 식별자 (예: `bmr-academy`)
   - `academyName`: 아카데미 표시 이름 (예: `별무리 아카데미`)
5. 관리자 계정 정보를 입력합니다.
6. **생성** 버튼을 클릭하여 아카데미를 생성합니다.

> [!WARNING]
> `academyId`는 생성 후 변경할 수 없습니다. 또한 내부적으로 `academyId + "-db"` 형태로 데이터베이스명이 자동 생성되므로, 신중하게 설정하세요.

### 생성 후 자동 처리

아카데미가 생성되면 다음 작업이 자동으로 수행됩니다.

```
아카데미 생성
 ├── 아카데미 전용 데이터베이스 생성 ({academyId}-db)
 ├── 아카데미 레코드 루트 DB에 저장
 └── 기본 관리자(Admin) 계정 생성
```

## 아카데미 설정

> **필요 권한**: 🔴 Admin

아카데미 생성 후 기본 정보를 변경할 수 있습니다.

### 변경 가능한 설정 항목

| 항목 | 설명 | 변경 가능 여부 |
|------|------|:--------------:|
| 아카데미 이름 (`academyName`) | 아카데미 표시 이름 | O |
| 이메일 (`email`) | 대표 연락 이메일 | O |
| 전화번호 (`tel`) | 대표 연락 전화번호 | O |
| 관리자 ID (`adminId`) | 아카데미 관리자 ID | O |
| 관리자 이름 (`adminName`) | 아카데미 관리자 이름 | O |
| 아카데미 ID (`academyId`) | 아카데미 고유 식별자 | X (변경 불가) |

### 설정 변경 절차

1. Admin 계정으로 로그인합니다.
2. 좌측 사이드바에서 **관리자** 메뉴를 클릭합니다.
3. 아카데미 설정 페이지에서 수정할 항목의 값을 변경합니다.
4. **저장** 버튼을 클릭합니다.

## AI 설정

> **필요 권한**: 🔴 Admin (아카데미 수준), 🔵 Manager (학기 수준)

Altsis는 OpenAI, Anthropic, Google Gemini(테스트용) API를 활용한 AI 기능을 지원합니다. AI 기능은 아카데미 수준과 학기 수준 두 단계로 설정합니다.

### AI 제공자 선택

| 제공자 | 용도 | 비고 |
|--------|------|------|
| OpenAI | 운영 | 미성년자 대상 사용 허용 (아래 이행사항 준수 필요) |
| Anthropic | 운영 | 미성년자 대상 사용 허용 (아래 이행사항 준수 필요) |
| Google Gemini | 테스트 전용 | Google 약관상 18세 미만이 접근하는 서비스에 사용 금지 |

> [!WARNING]
> Google Gemini API는 [약관](https://ai.google.dev/gemini-api/terms)상 "18세 미만이 접근할 가능성이 높은 서비스"의 일부로 사용할 수 없습니다. 학생이 사용하는 운영 환경에서는 반드시 OpenAI 또는 Anthropic을 사용하고, Gemini는 개발·테스트 용도로만 사용하세요.

### 아카데미 수준 AI 설정 (Admin)

아카데미 수준에서는 AI 제공자, API 키, 모델을 관리합니다.

| 항목 | 설명 | 기본값 |
|------|------|--------|
| `aiEnabled` | AI 기능 전체 활성화 | `false` |
| `aiProvider` | AI 제공자 (`openai` / `anthropic` / `gemini`) | `gemini` |
| `aiApiKey` | 선택한 제공자의 API 키 | 없음 |
| `aiModel` | 사용할 AI 모델 | 제공자별 기본 모델 |

#### API 키 설정 절차

1. 사용할 제공자의 콘솔에서 API 키를 발급합니다.
   - OpenAI: [platform.openai.com/api-keys](https://platform.openai.com/api-keys)
   - Anthropic: [console.anthropic.com/settings/keys](https://console.anthropic.com/settings/keys)
   - Google AI Studio (테스트용): [aistudio.google.com/app/apikey](https://aistudio.google.com/app/apikey)
2. Admin 계정으로 로그인한 후, 아카데미 설정 페이지로 이동합니다.
3. **AI 설정** 섹션에서 제공자를 선택하고 API 키를 입력합니다.
4. **테스트** 버튼으로 키 유효성을 확인하고, **모델 탐색**으로 사용 가능한 모델을 조회해 선택합니다.
5. API 키를 저장한 뒤 AI 기능을 **활성화**합니다.

> [!IMPORTANT]
> API 키는 보안을 위해 조회 API를 통해 반환되지 않습니다 (`select: false`). 키를 분실한 경우 해당 제공자 콘솔에서 새 키를 발급받아야 합니다.

### 아카데미 이행사항 (컴플라이언스)

BYOK(Bring Your Own Key) 구조상 AI 제공자와의 계약 당사자는 API 키를 발급받은 아카데미입니다. 미성년 학생이 AI 기능을 사용하는 경우, 제공자 약관과 개인정보보호법에 따라 아래 사항을 아카데미가 직접 이행해야 합니다.

| 항목 | 대상 | 설명 |
|------|------|------|
| 법정대리인 동의 수집 | 만 14세 미만 학생 | 개인정보보호법에 따라 AI 기능 사용 전 법정대리인 동의가 필요합니다 |
| OpenAI Zero Data Retention 신청 | OpenAI 사용 + 만 14세 미만 학생 | OpenAI 정책상 만 14세 미만(디지털 동의 연령 미만)의 개인정보 처리 전 ZDR 적용이 필요하며, OpenAI 계정에서 직접 신청합니다 |
| 개인정보 처리방침 갱신 | 전체 | 사용하는 AI 제공자를 개인정보 처리 위탁·국외 이전 항목에 기재합니다 |
| 제공자 가이드라인 숙지 | 전체 | OpenAI [Under 18 API Guidance](https://developers.openai.com/api/docs/guides/safety-checks/under-18-api-guidance), Anthropic [미성년자 대상 조직 가이드라인](https://support.claude.com/en/articles/9307344-responsible-use-of-anthropic-s-models-guidelines-for-organizations-serving-minors)을 확인하세요 |

Altsis는 제공자 가이드라인이 요구하는 안전조치 중 다음을 기본 제공하여 아카데미의 이행을 지원합니다.

- AI 챗봇(Alter) 사용 시 AI임을 알리는 상시 고지
- 연령 적합 콘텐츠·위기 대응·개인정보 보호를 포함한 안전 시스템 프롬프트
- 교사의 학생 AI 대화 전체 열람(모니터링) 기능
- AI 생성물에 대한 검토 필요 고지

### 학기 수준 AI 설정 (Manager)

학기 수준의 AI 설정은 [학기 관리](season-management.md) 문서와 [권한 설정](permission-settings.md) 문서를 참고하세요. 학기별로 다음 항목을 추가 설정할 수 있습니다.

- AI 기능 활성화/비활성화
- 교사/학생별 AI 사용 권한
- AI 생성 시 기본 지침 (가이드라인)
- AI 참고 자료 등록 (직접 입력 또는 파일 업로드)

## 채팅 활성화/비활성화

> **필요 권한**: 🔴 Admin

아카데미 내 실시간 채팅 기능의 사용 여부를 설정합니다.

| 항목 | 설명 | 기본값 |
|------|------|--------|
| `chatEnabled` | 채팅 기능 활성화 상태 | `false` |

### 설정 절차

1. Admin 계정으로 로그인합니다.
2. 아카데미 설정 페이지로 이동합니다.
3. **채팅 설정** 항목에서 활성화 또는 비활성화를 선택합니다.
4. **저장** 버튼을 클릭합니다.

> [!TIP]
> 채팅 기능을 비활성화하면 아카데미 내 모든 사용자의 채팅 메뉴가 숨겨집니다. 기존 채팅 내역은 삭제되지 않으며, 다시 활성화하면 이전 내역을 확인할 수 있습니다.

## 백업 및 복원

> **필요 권한**: 🔴 Admin

아카데미 전체 데이터를 백업하거나, 백업된 데이터를 복원할 수 있습니다. 백업 데이터는 AWS S3에 JSON 형식으로 저장됩니다.

### 백업 가능한 데이터 모델

| 모델명 | 설명 |
|--------|------|
| `schools` | 학교 정보 |
| `users` | 사용자 계정 정보 |
| `archives` | 학생 기록 데이터 |
| `seasons` | 학기 정보 |
| `registrations` | 학기 등록 정보 |
| `syllabuses` | 강의계획서 |
| `enrollments` | 수강 정보 |
| `forms` | 양식 정보 |
| `notifications` | 알림 데이터 |

### 백업 생성 절차

1. Admin 계정으로 로그인합니다.
2. **관리자 메뉴** > **백업 및 복구** 페이지로 이동합니다.
3. **+ 백업** 버튼을 클릭합니다.
4. 백업 팝업에서 백업할 데이터 모델을 선택합니다.
   - 체크박스를 사용하여 원하는 모델을 선택합니다.
   - 모든 모델을 선택하면 전체 백업이 수행됩니다.
5. **+ 백업** 버튼을 클릭하여 백업을 시작합니다.
6. 백업 완료 후 목록에 새 백업 항목이 표시됩니다.

> [!WARNING]
> 데이터 크기에 따라 백업 시간이 오래 소요될 수 있습니다. 백업 진행 중에는 페이지를 닫지 마세요.

### 백업 데이터 조회 및 다운로드

1. 백업 목록에서 원하는 백업의 **자세히** 버튼을 클릭합니다.
2. 상세 팝업에서 각 모델별 백업 파일을 확인합니다.
3. **다운로드** 버튼을 클릭하여 JSON 파일을 로컬에 저장합니다.

### 백업 삭제

1. 백업 목록에서 삭제할 항목의 **삭제** 버튼을 클릭합니다.
2. 확인 대화상자에서 **확인**을 클릭합니다.

### 데이터 복원 절차

1. **+ 복구** 버튼을 클릭합니다.
2. 복원할 데이터 모델을 드롭다운에서 선택합니다.
   - 예: `schools(학교)`, `users(사용자)` 등
3. **파일 선택** 버튼을 클릭하여 JSON 백업 파일을 업로드합니다.
4. 업로드된 데이터의 미리보기를 확인합니다.
5. **+ 복구** 버튼을 클릭하여 복원을 실행합니다.

> [!WARNING]
> 복원 작업은 기존 데이터를 덮어씁니다. 복원 전에 현재 데이터의 백업을 먼저 수행하는 것을 강력히 권장합니다.

### 복원 파일 형식

복원에 사용하는 JSON 파일은 **배열 형식**이어야 합니다.

```json
[
  {
    "_id": "65a1b2c3d4e5f6a7b8c9d0e1",
    "userId": "user01",
    "userName": "홍길동"
  },
  {
    "_id": "65a1b2c3d4e5f6a7b8c9d0e2",
    "userId": "user02",
    "userName": "김철수"
  }
]
```

> [!IMPORTANT]
> JSON 배열이 아닌 형식(단일 객체 등)의 파일은 업로드가 거부됩니다. 반드시 배열(`[]`) 형식으로 저장된 파일을 사용하세요.
