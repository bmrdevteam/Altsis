# 학기 관리 🔵

학기(Season)는 학교 운영의 핵심 단위입니다. 학년도와 학기를 기준으로 사용자 등록, 수업, 평가, 양식이 운영됩니다. 이 문서에서는 학기의 생성, 복사, 사용자 등록, 교과목/강의실 설정, 활성화 방법을 설명합니다.

## 학기 생성

> **필요 권한**: 🔵 Manager

### 학기 데이터 구조

| 필드 | 설명 | 필수 | 비고 |
|------|------|:----:|------|
| `school` | 소속 학교 ObjectId | O | 자동 설정 |
| `schoolId` | 학교 ID | O | 자동 설정 |
| `schoolName` | 학교 이름 | O | 자동 설정 |
| `year` | 학년도 | O | 예: `2026학년도` |
| `term` | 학기 | O | 예: `1학기`, `2학기` |
| `period.start` | 시작일 | - | `YYYY-MM-DD` 형식 |
| `period.end` | 종료일 | - | `YYYY-MM-DD` 형식 |

> [!IMPORTANT]
> 동일한 학교 내에서 `year`와 `term`의 조합은 유일해야 합니다. 예를 들어, `2026학년도` + `1학기`는 하나만 존재할 수 있습니다. 이는 데이터베이스 복합 인덱스(`school_1_year_-1_term_1`)로 보장됩니다.

### 생성 절차

1. Manager 계정으로 로그인합니다.
2. **관리자** > **학교 관리** 에서 해당 학교를 선택합니다.
3. **학기** 탭으로 이동합니다.
4. **학기 추가** 버튼을 클릭합니다.
5. 학기 정보를 입력합니다.
   - **학년도**: 예) `2026학년도`
   - **학기**: 예) `1학기`
   - **시작일**: 학기 시작 날짜
   - **종료일**: 학기 종료 날짜
6. **생성** 버튼을 클릭합니다.

### 생성 후 초기 상태

새로 생성된 학기는 다음과 같은 초기 상태를 갖습니다.

| 항목 | 초기값 |
|------|--------|
| `isActivated` | `false` (비활성화) |
| `isActivatedFirst` | `false` (최초 활성화 전) |
| `permissionSyllabusV2` | 교사: N, 학생: N |
| `permissionEnrollmentV2` | 교사: N, 학생: N |
| `permissionEvaluationV2` | 교사: N, 학생: N |
| `classrooms` | 빈 배열 |
| `subjects` | 빈 구조 |
| `formEvaluation` | 빈 배열 |
| `aiSettings` | 비활성화 |

## 학기 복사

> **필요 권한**: 🔵 Manager

이전 학기의 정보를 복사하여 새 학기를 빠르게 생성할 수 있습니다.

### 복사되는 항목

| 항목 | 복사 여부 | 설명 |
|------|:---------:|------|
| 교과목 (`subjects`) | O | 교과/교과목 구조 전체 |
| 강의실 (`classrooms`) | O | 강의실 목록 |
| 양식 (`formTimetable`, `formSyllabus`, `formEvaluation`) | O | 시간표, 강의계획서, 평가 양식 |
| 권한 설정 (`permission*`) | O | 수업/수강/평가 권한 |
| 사용자 등록 (`registrations`) | 선택 | 등록 정보 복사 여부 선택 가능 |
| AI 설정 (`aiSettings`) | O | AI 관련 설정 |
| 수업/수강 데이터 | X | 복사되지 않음 |
| 학기 기간 (`period`) | X | 새로 설정 필요 |

### 복사 절차

1. 학기 목록에서 복사 원본이 될 학기를 확인합니다.
2. **학기 추가** 기능에서 **이전 학기 복사** 옵션을 선택합니다.
3. 복사할 원본 학기를 지정합니다.
4. 새 학기의 학년도와 학기를 입력합니다.
5. 사용자 등록 복사 여부를 선택합니다.
6. **생성** 버튼을 클릭합니다.

> [!TIP]
> 학기 복사 기능을 사용하면 매 학기 반복되는 교과목, 강의실, 양식 설정을 처음부터 다시 하지 않아도 됩니다. 새 학년도 시작 시 이전 학기를 복사한 후 필요한 부분만 수정하는 것이 효율적입니다.

## 학기에 사용자 등록

> **필요 권한**: 🔵 Manager

학기에 사용자를 등록하면 Registration(학기 등록) 문서가 생성됩니다. Registration은 학기 내에서 사용자의 역할(학생/교사), 학년, 그룹, 담당 교사 등을 정의합니다.

### Registration 데이터 구조

| 필드 | 설명 | 필수 |
|------|------|:----:|
| `user` | 사용자 ObjectId | O |
| `userId` | 사용자 ID | O |
| `userName` | 사용자 이름 | O |
| `role` | 역할 (`student` 또는 `teacher`) | O |
| `grade` | 학년 | - |
| `group` | 그룹 | - |
| `teacher` | 담당 교사 ObjectId | - |
| `teacherId` | 담당 교사 ID | - |
| `teacherName` | 담당 교사 이름 | - |
| `subTeacher` | 부담당 교사 ObjectId | - |
| `subTeacherId` | 부담당 교사 ID | - |
| `subTeacherName` | 부담당 교사 이름 | - |

> [!IMPORTANT]
> 동일한 학기에 같은 사용자를 중복 등록할 수 없습니다 (`season` + `user` 복합 유니크 인덱스). 사용자는 하나의 학기에 학생 또는 교사 중 하나의 역할만 가질 수 있습니다.

### 개별 등록 절차

1. 학기 상세 페이지에서 **등록 정보** 탭으로 이동합니다.
2. **사용자 등록** 버튼을 클릭합니다.
3. 등록 정보를 입력합니다.
   - **사용자**: 학교에 등록된 사용자 목록에서 선택
   - **역할**: `학생` 또는 `교사`
   - **학년**: (학생의 경우) 소속 학년
   - **그룹**: (학생의 경우) 소속 그룹
   - **담당 교사**: (학생의 경우) 담임 교사 지정
   - **부담당 교사**: (학생의 경우) 부담임 교사 지정
4. **등록** 버튼을 클릭합니다.

### 일괄 등록

여러 사용자를 한 번에 학기에 등록할 수 있습니다.

1. **등록 정보** 탭에서 **일괄 등록** 버튼을 클릭합니다.
2. 학교에 등록된 사용자 목록이 표시됩니다.
3. 등록할 사용자들을 체크박스로 선택합니다.
4. 역할, 학년, 그룹 등을 일괄 설정합니다.
5. **등록** 버튼을 클릭합니다.

### 이전 학기에서 등록 복사

이전 학기의 등록 정보를 그대로 가져올 수 있습니다.

1. **등록 정보** 탭에서 **등록 복사** 버튼을 클릭합니다.
2. 복사할 원본 학기를 선택합니다.
3. 복사할 사용자 목록을 확인하고 조정합니다.
4. **복사** 버튼을 클릭합니다.

> [!TIP]
> 등록 복사 시 이전 학기의 역할, 학년, 그룹, 담당 교사 정보가 함께 복사됩니다. 학년이 변경되는 경우(진급) 복사 후 학년 정보를 수정하세요.

### Registration에 자동 설정되는 필드

Registration이 생성되면 학기의 권한 설정에 따라 다음 필드가 자동으로 설정됩니다.

| 필드 | 설명 | 설정 기준 |
|------|------|-----------|
| `isActivated` | 학기 활성화 상태 | `season.isActivated` |
| `permissionSyllabusV2` | 수업 개설 권한 | `season.permissionSyllabusV2` 기반 계산 |
| `permissionEnrollmentV2` | 수강신청 권한 | `season.permissionEnrollmentV2` 기반 계산 |
| `permissionEvaluationV2` | 평가 권한 | `season.permissionEvaluationV2` 기반 계산 |
| `formEvaluation` | 평가 양식 | `season.formEvaluation` 복사 |

## 교과목 설정

> **필요 권한**: 🔵 Manager

학기별로 교과(대분류)와 교과목(소분류)을 등록합니다. 등록된 교과목은 수업(강의계획서) 생성 시 선택할 수 있습니다.

### 교과목 데이터 구조

```json
{
  "subjects": {
    "label": ["교과", "과목"],
    "data": [
      ["국어", "현대시"],
      ["국어", "고전문학"],
      ["수학", "미적분"],
      ["영어", "영어회화"]
    ]
  }
}
```

| 필드 | 설명 |
|------|------|
| `label` | 분류 체계의 레이블 (예: `["교과", "과목"]`) |
| `data` | 교과목 데이터 배열 (각 항목은 레이블 순서에 맞는 값 배열) |

### 개별 등록

1. 학기 상세 페이지에서 **교과목** 탭으로 이동합니다.
2. **교과목 추가** 버튼을 클릭합니다.
3. 교과(대분류)를 입력합니다.
4. 교과목(소분류)을 입력합니다.
5. **추가** 버튼을 클릭합니다.

### 일괄 등록

Excel 파일을 사용하여 여러 교과목을 한 번에 등록할 수 있습니다.

1. **교과목** 탭에서 **일괄 등록** 버튼을 클릭합니다.
2. **도움말** 탭에서 파일 양식과 규칙을 확인합니다.
3. **양식 다운로드** 버튼으로 Excel 템플릿을 다운로드합니다.
4. 템플릿에 교과목 정보를 입력합니다.
5. **업로드** 탭에서 파일을 업로드합니다.
6. 데이터를 확인하고 **등록** 버튼을 클릭합니다.

> [!WARNING]
> 학기가 최초 활성화된 이후에는 교과목을 삭제하거나 레이블 구조를 변경할 수 없습니다. 교과목은 학기 활성화 전에 최종 확정하세요.

## 강의실 설정

> **필요 권한**: 🔵 Manager

학기별로 사용 가능한 강의실(교실) 목록을 등록합니다. 등록된 강의실은 시간표 설정이나 수업 장소 지정에 사용됩니다.

### 강의실 데이터 구조

```json
{
  "classrooms": ["1학년 1반", "1학년 2반", "음악실", "과학실", "체육관"]
}
```

### 개별 등록

1. 학기 상세 페이지에서 **강의실** 탭으로 이동합니다.
2. **강의실 추가** 버튼을 클릭합니다.
3. 강의실 이름을 입력합니다.
4. **추가** 버튼을 클릭합니다.

### 일괄 등록

Excel 파일을 사용하여 여러 강의실을 한 번에 등록할 수 있습니다.

1. **강의실** 탭에서 **일괄 등록** 버튼을 클릭합니다.
2. **도움말** 탭에서 파일 양식을 확인합니다.
3. **양식 다운로드** 버튼으로 템플릿을 다운로드합니다.
4. 강의실 목록을 입력합니다.
5. 파일을 업로드하고 등록합니다.

## 학기 활성화/비활성화

> **필요 권한**: 🔵 Manager

학기의 운영 상태를 전환합니다. 활성화된 학기만 일반 사용자(교사/학생)에게 노출됩니다.

### 활성화 상태

| 상태 | `isActivated` | 설명 |
|------|:-------------:|------|
| 비활성화 | `false` | 관리자만 접근 가능. 설정 변경 가능 |
| 활성화 | `true` | 모든 등록 사용자에게 노출. 수업/수강신청/평가 운영 |

### 최초 활성화 (`isActivatedFirst`)

학기가 처음 활성화되면 `isActivatedFirst`가 `true`로 변경되며, 이후부터 일부 설정이 잠깁니다.

| 항목 | 최초 활성화 전 | 최초 활성화 후 |
|------|:-------------:|:-------------:|
| 시간표 양식 변경 | O | X (잠김) |
| 강의계획서 양식 변경 | O | X (잠김) |
| 평가 양식 변경 | O | 제한적 |
| 교과목 구조 변경 | O | X (잠김) |
| 강의실 변경 | O | O |
| 권한 설정 변경 | O | O |
| 사용자 등록 | O | O |

> [!WARNING]
> 최초 활성화는 되돌릴 수 없습니다. 시간표 양식, 강의계획서 양식, 평가 양식, 교과목이 최종 확정된 후에 활성화하세요.

### 활성화 절차

1. 학기 상세 페이지에서 **기본 정보** 탭으로 이동합니다.
2. 모든 설정이 완료되었는지 확인합니다.
   - 교과목 등록 완료
   - 강의실 등록 완료
   - 양식 설정 완료
   - 권한 설정 완료
   - 사용자 등록 완료
3. **활성화** 버튼을 클릭합니다.
4. 확인 대화상자에서 **확인**을 클릭합니다.

### 비활성화 절차

운영 중인 학기를 일시적으로 비활성화할 수 있습니다.

1. 학기 상세 페이지에서 **기본 정보** 탭으로 이동합니다.
2. **비활성화** 버튼을 클릭합니다.
3. 확인 대화상자에서 **확인**을 클릭합니다.

> [!TIP]
> 학기 종료 후 비활성화하면 해당 학기의 수업, 수강신청, 평가 기능이 잠깁니다. 데이터는 삭제되지 않으며, 조회는 여전히 가능합니다.

### 학기 삭제

학기를 삭제하면 관련 데이터가 모두 삭제됩니다.

1. 학기 상세 페이지에서 **삭제** 탭으로 이동합니다.
2. 삭제 안내를 확인합니다.
3. **삭제** 버튼을 클릭합니다.
4. 확인 대화상자에서 **확인**을 클릭합니다.

> [!WARNING]
> 학기 삭제 시 해당 학기의 등록 정보(Registration), 수업(Syllabus), 수강 정보(Enrollment), 평가 데이터 등이 모두 삭제됩니다. 이 작업은 되돌릴 수 없으므로 삭제 전에 반드시 백업을 수행하세요.

## 학기 운영 체크리스트

새 학기를 시작할 때 다음 체크리스트를 참고하세요.

```
[ ] 1. 학기 생성 (또는 이전 학기 복사)
[ ] 2. 학기 기간 설정 (시작일/종료일)
[ ] 3. 교과목 등록
[ ] 4. 강의실 등록
[ ] 5. 양식 설정 (시간표, 강의계획서, 평가)
[ ] 6. 사용자 등록 (학생/교사)
[ ] 7. 권한 설정 (수업 개설, 수강신청, 평가)
[ ] 8. AI 설정 (필요 시)
[ ] 9. 학기 활성화
```
