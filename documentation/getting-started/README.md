# 시작하기

Altsis를 처음 접하는 사용자를 위한 설치 및 초기 설정 가이드입니다. 아래 문서를 순서대로 진행하면 로컬 환경에서 Altsis를 실행하고 첫 번째 아카데미를 생성할 수 있습니다.

---

## 문서 목록

| 순서 | 문서 | 설명 |
|:----:|------|------|
| 1 | [시스템 요구사항](requirements.md) | 서버 및 클라이언트 실행에 필요한 소프트웨어, 외부 서비스, 운영체제 환경 |
| 2 | [설치 가이드](installation.md) | Git 클론부터 백엔드/프론트엔드 실행까지 상세한 단계별 설명 |
| 3 | [초기 설정](initial-setup.md) | 아카데미 생성, 관리자 계정 설정, 첫 로그인까지의 과정 |
| 4 | [빠른 시작](quick-start.md) | 10분 안에 시스템을 구동하는 요약 가이드 |

---

## 권장 진행 순서

```
시스템 요구사항 확인 → 설치 가이드 → 초기 설정 → 시스템 사용 시작
```

처음 설치하는 경우 **1번부터 3번까지** 순서대로 진행하는 것을 권장합니다. 이미 요구사항을 충족하고 있고 빠르게 시작하고 싶다면 [빠른 시작](quick-start.md) 문서를 참고하세요.

> [!TIP]
> 설치 과정에서 문제가 발생하면 [GitHub Issues](https://github.com/bmrdevteam/Altsis/issues)에서 기존 이슈를 검색하거나 새로운 이슈를 등록해 주세요.
